# 小天 AI 洞察 V1 开发计划

> 版本: v1.0 | 日期: 2026-05-27
> 基于: ai-insight-design.md V2
> 状态: 开发前拆解，尚未开始编码

---

## 1. V1 开发目标

将 AI 洞察 V2 设计文档中已确认的规则，转为可开发的 V1 版本。

**核心原则**:
- 先 mock 数据跑通 UI 和交互流程
- 规则函数先写判断逻辑，不接真实数据
- 推荐动作先对接已有 workflow
- 地区/评分维度先用配置占位
- 所有布置/发布类动作必须老师确认

## 3. V1 不包含模块

| 模块 | 原因 | 计划 |
|------|------|------|
| 错题本洞察 | 错题数据结构待确认 | P2 |
| 资源推荐洞察 | 依赖资源库真实数据 | P2 |
| 阅读洞察（独立） | 已归入错题本/练习报告 | — |
| 真实地区听说规则自动判断 | 需官方来源补齐 | P2 |
| 各地区写作评分标准完整配置 | V1 使用系统写作模型输出 | P1/P2 |
| 历史使用效果分析 | 需接入数据库 | P3 |
| 真实 LLM 接入生成洞察文案 | 需后端支持 | P3 |
| 联网抓取地区考试政策 | 不允许在无官方来源时编造 | — |

## 9. 验收标准

### 首页洞察 V1

| # | 验收项 | 标准 |
|---|-------|------|
| 1 | 首页展示洞察卡片 | 最多 3 条，按优先级排序 |
| 2 | 错词洞察触发 | 课标词错误率 >= 30% 时展示 |
| 3 | 听力/听说洞察触发 | 得分率 < 60% 时展示 |
| 4 | 写作洞察触发 | 待批改 > 24h 或得分率异常时展示 |
| 5 | 考前提醒触发 | 考前一个月展示，置顶 |
| 6 | 点击"查看分析" | 打开 AIAssistantDrawer insightDetail panel |
| 7 | 点击推荐动作 | 跳转 /ai-search 或打开对应 panel |
| 8 | 不提醒规则 | 样本不足/已处理/重复 时不展示 |

### 洞察详情 V1

| # | 验收项 | 标准 |
|---|-------|------|
| 1 | 展示洞察标题 | 一句话，不含技术词 |
| 2 | 展示影响范围 | 班级/单元/题型/学生范围 |
| 3 | 展示数据依据 | 具体数字，非模糊描述 |
| 4 | 展示教研判断 | 以教研老师口吻 |
| 5 | 展示教学建议 | 可执行的具体建议 |
| 6 | 展示推荐动作 | 1-3 个可点击按钮 |
| 7 | 返回按钮 | 关闭 panel 或回到首页 |

## 10. 后续 P1 / P2 扩展

### P1（下一版）

- 练习报告页洞察完整实现
- 地区听力/听说规则配置完善（至少覆盖 top 5 省份）
- 地区写作评分维度配置完善（补充官方来源）
- 考试日历接入（期中/期末/中考/高考时间）
- 错题本洞察（错题数据结构确认后）

### P2（后续版本）

- 接入真实写作模型 API
- 接入真实练习数据
- 接入历史使用效果（布置次数、平均得分率、完成率）
- 资源推荐洞察
- 真实 LLM 接入生成洞察文案
- 更细粒度学生分层
- 个性化学生洞察
- 老师反馈闭环（"不感兴趣"）
- 洞察效果追踪（老师是否执行了推荐动作）

### P3（未来版本）

- 跨班级对比分析
- 年级趋势分析
- 教研报告自动生成
- 家长端洞察推送
