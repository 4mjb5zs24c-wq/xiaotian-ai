# 小天 AI 洞察 V2 教研设计文档

> 版本: v2.0 | 日期: 2026-05-27
> 基于: V1 文档 + 最新教研访谈反馈
> 当前阶段: 设计稿，尚未全部实现

---

## 文档定位

AI 洞察不是数据报表，而是面向初高中英语老师的"教研判断 + 教学动作建议"。

每条洞察回答三个问题：
1. 班级发生了什么？
2. 从教研角度看是什么意思？
3. 老师下一步应该做什么？

---

## 通用 Prompt 模板

```
你是一名有经验的初高中英语教研老师，请根据班级学情数据生成一条面向英语老师的教学洞察。

要求：
1. 必须基于数据，不要泛泛而谈。
2. 优先使用得分率、错误率、趋势变化、题型表现等证据。
3. 必须指出可能原因，但不要做过度判断。
4. 必须给出老师可以执行的教学动作。
5. 语言要像教研老师给一线老师的建议。
6. 不要出现 AI、模型、算法、workflow、provider、tool 等技术词。
7. 不要使用普通班、差生、低水平学生等标签。
8. 不要直接替老师布置作业，只给出推荐动作，由老师确认。
9. 文案中优先使用"掌握不牢固、掌握不扎实、需要巩固、错误较集中"等表达。
10. 如果数据样本不足，应该提示"暂不生成洞察"，不要强行输出。
```

**输出结构**:
```json
{
  "title": "一句话问题",
  "riskLevel": "高/中/低",
  "scope": "影响范围（班级/单元/题型/学生范围）",
  "evidence": "数据依据（得分率/错误率/趋势等具体数字）",
  "analysis": "教研判断（基于英语教学经验的可能原因）",
  "suggestion": "教学建议（老师下一步应该怎么处理）",
  "actions": ["推荐动作1", "推荐动作2", "推荐动作3"]
}
```

## 统一洞察结构

所有洞察模块遵循以下结构：

| 字段 | 说明 |
|------|------|
| **洞察标题** | 一句话说明问题 |
| **影响范围** | 班级 / 单元 / 题型 / 学生范围 |
| **数据依据** | 得分率、错误率、趋势变化、题型表现、练习频率等 |
| **教研判断** | 基于英语教学经验解释可能原因 |
| **教学建议** | 老师下一步应该怎么处理 |
| **推荐动作** | 1-3 个可点击动作 |

## 文案规范

**禁止使用的词汇**:
- AI、模型、算法、workflow、provider、tool、agent
- 普通班、差生、低水平学生、稳定性不足
- 作弊、偷懒、不认真

**推荐使用的表达**:
- 掌握不扎实 / 掌握不牢固 / 需要巩固
- 错误较集中 / 得分率偏低
- 建议重点讲解 / 建议安排针对性训练
- 存在异常完成情况，建议老师核实
- 适合当前班级学情

## 不提醒规则

| # | 规则 | 说明 |
|---|------|------|
| 1 | 样本量偏少不生成强提醒 | 详见下方样本量阈值 |
| 2 | 班级约 50 人时，样本 <= 15 人视为偏少 | 不生成强提醒，可展示轻提示 |
| 3 | 班级不足 45 人时，样本占比 <= 30% 视为偏少 | 不生成强提醒，可展示轻提示 |
| 4 | 样本偏少时可展示轻提示 | "当前参与人数较少，建议结合后续练习数据继续观察" |
| 5 | 数据波动不明显 | 低于预设阈值的变化不提醒 |
| 6 | 没有明确教学动作 | 如果无法给老师明确下一步动作，不推送 |
| 7 | 老师刚处理过同类问题 | 例如已生成强化训练或已布置相关练习 |
| 8 | 同一洞察一天内不重复推送 | — |
| 9 | 考试结束后 | 不再推送对应考前提醒 |
| 10 | 地区不考听力/听说 | 不主动推荐无关训练 |
| 11 | 考前提醒不受样本量限制 | 基于考试时间触发，非练习数据 |

### 样本量阈值

```
isSampleTooSmall(totalStudents, sampleCount):

  IF totalStudents >= 45:
    RETURN sampleCount <= 15

  IF totalStudents < 45:
    RETURN sampleCount / totalStudents <= 0.3
```

**样本偏少时的处理**:
- 不生成高风险（riskLevel='high'）洞察
- 可展示轻提示（riskLevel='low'，标注"样本偏少"）
- 不基于少量样本输出强判断结论
- 考前提醒不受此限制

## 一、首页 AI 洞察

### 洞察目标
首页只展示最重要的 2-3 条教学提醒。

### 首页洞察类型（仅 4 类）

| 类型 | 触发条件 | 优先级排序（非考试期） |
|------|---------|---------------------|
| 错词洞察 | 课标词错误率 >= 30% | 第 1 位 |
| 听力/听说洞察 | 听力/听说得分率 < 60% | 第 2 位 |
| 写作洞察 | 作文待批改积压或得分率异常 | 第 3 位 |
| 考前训练提醒 | 考试前一个月 | 置顶 |

**非考试期排序**: 错词 → 听力/听说 → 写作
**考试前一个月**: 考前训练提醒置顶，剩余 2 条从以上按风险排序

### 考前训练提醒规则

| 规则 | 说明 |
|------|------|
| 触发时间 | 考试日前 30 天开始提醒 |
| 结束时间 | 考试当天及考试结束后不再推送该考试的考前提醒 |
| 推荐逻辑 | 根据老师已练习过的模拟题，每天推荐不同试题 |
| 去重规则 | 已练习过的不重复推荐 |
| 多考试排序 | 多个考试临近时，按考试日期最近且影响范围最大的考试优先 |
| 置顶规则 | 考前提醒在首页 AI 洞察中置顶 |
| 首页占比 | 考前提醒占 1 条，剩余 2 条从错词、听力/听说、写作中按风险排序 |
| 样本量豁免 | 考前提醒不受样本量限制（基于考试时间触发，非练习数据） |

**时间判断**: `isExamWithin30Days(examDate, currentDate)`:
- `0 < examDate - currentDate <= 30 天` → 触发
- `examDate <= currentDate` → 考试已过，不触发
- `> 30 天` → 未到时间，不触发

### 首页不展示的洞察类型
- 阅读分析（归入错题本或练习报告）
- 错题分析（归入错题本页面）
- 资源推荐（归入资源页面）
- 完整练习报告（归入练习报告页面）

## 二、错词洞察

### 适用范围
首页 + 错词本页面

### 触发阈值
课标词错误率 >= **30%**（首页和错词本统一使用同一阈值）

### 分析维度

| # | 维度 | 说明 |
|---|------|------|
| 1 | 不会拼 | 拼写错误 |
| 2 | 不会读 | 读音混淆 |
| 3 | 不会用 | 搭配不当、语境不合适 |
| 4 | 词义混淆 | 近义词、反义词混淆 |
| 5 | 词性混淆 | 名词/动词/形容词误用 |
| 6 | 固定搭配不会 | 介词搭配、固定表达 |
| 7 | 错词对应题型来源 | 来自听写/阅读/完形/写作 |
| 8 | 是否为课标词 | 是 → 提升优先级 |
| 9 | 是否集中在某个单元或主题 | 是 → 与教学进度关联 |
| 10 | 是否多音节词或长难词 | 是 → 判断为长难词掌握不牢 |

### 判断逻辑

| # | 条件 | 教研判断 | 推荐动作 |
|---|------|---------|---------|
| 1 | 课标词错误率 >= 30% | 课标要求词汇掌握不牢固 | 生成词汇听写 |
| 2 | 一个词错的人多 | 该词为班级易错词 | 课堂重点讲解 |
| 3 | 多个长词/多音节词一起错 | 长难词/多音节词掌握不牢 | 听音拼写训练 |
| 4 | 音近词混淆 | 辨音能力需加强 | 推荐辨音训练 |
| 5 | 形近词混淆 | 词形识别需加强 | 看词选释义、语用训练 |
| 6 | 拼写错误为主 | 拼写规则掌握不牢 | 生成单词默写 |
| 7 | 语用错误为主 | 词汇运用能力需提升 | 生成语用训练 |

### 推荐动作

按错误类型推荐不同动作：

| 错误类型 | 推荐动作1 | 推荐动作2 | 推荐动作3 |
|---------|----------|----------|----------|
| 拼写错误 | 生成词汇听写 | 生成单词默写 | 错词重做 |
| 词义混淆 | 看英选中 | 看中选英 | 语用训练 |
| 不会读 | 错词生成语篇朗读 | 跟读训练 | — |
| 不会用 | 生成语用训练 | 错词生成语篇挖空 | — |
| 综合 | 生成词汇PK | 错词组卷练习 | 查看错词学生 |

**所有动作说明**:
- `vocab_dictation` — 生成词汇听写。适用：拼写错误、课标词错误率高。
- `vocab_pk` — 生成词汇PK。适用：词汇巩固、课堂趣味练习。
- `vocab_meaning_choice_en_to_cn` — 看英选中。适用：词义识别问题。
- `vocab_meaning_choice_cn_to_en` — 看中选英。适用：词义匹配问题。
- `vocab_usage_practice` — 生成语用训练。适用：不会用、固定搭配错误。需支持错词生成语篇挖空。
- `vocab_reading_aloud` — 错词生成语篇朗读。适用：不会读、读音问题。
- `wrong_word_repractice` — 错词重练。适用：高频错词、课标词错误率高。
- `wrong_word_paper` — 错词组卷练习。适用：阶段复习、错词集中。
- `view_wrong_word_students` — 查看错词学生。

## 三、练习报告洞察

### 适用范围
练习报告页面（不作为首页常规洞察）

### 核心指标

| 指标 | 说明 |
|------|------|
| 得分率 | 优先于完成率 |
| 高分段比例 | >= 85% |
| 题型得分率 | 按题型拆分 |
| 知识点得分率 | 按知识点拆分 |
| 成绩趋势 | 与历史对比 |
| 学生分层 | 高分段/中间段/待提升段 |
| 用时异常 | 用时短且得分低 / 得分异常高 |
| 空题率 | 可能不会做或作答投入不足 |

### 判断规则

| # | 条件 | 教研判断 | 推荐动作 |
|---|------|---------|---------|
| 1 | 得分率 < 60% | 该内容掌握不足 | 生成同类题、错题重练 |
| 2 | 题型或知识点得分率排序，前三项最低 | 优先重讲或补练 | 查看报告、布置强化训练 |
| 3 | 相对前两周平均下降 >= 10% | 明显下降 | 生成同类题、课堂讲解 |
| 4 | 高于历史均值 >= 5% | 表现较好 | 正面反馈（可选） |
| 5 | 完成率低 + 得分率高 | 作业管理问题 | 一键催促、查看未完成学生 |
| 6 | 完成率高 + 得分率低 | 掌握不足 | 生成同类题、错题重练 |
| 7 | 用时短 + 得分低 | 可能没有认真作答 | 建议老师核实 |
| 8 | 用时短 + 得分异常高 | 存在异常完成情况 | 建议老师核实 |
| 9 | 空题率高 | 学生可能不会做或投入不足 | 查看报告、了解原因 |
| 10 | 班级平均正常但部分学生明显低 | 需要关注风险学生 | 查看风险学生、分层布置 |

### 分层规则（第一版）

| 层级 | 得分率范围 | 说明 |
|------|----------|------|
| 高分段 | >= 85% | 掌握较扎实 |
| 中间段 | 60% - 85% | 需要巩固 |
| 待提升段 | < 60% | 需要重点关注 |

### 推荐动作

- 查看练习报告
- 一键催促未完成学生
- 生成同类题训练
- 错题重练
- 布置强化练习
- 查看风险学生
- 分层布置

## 四、错题本洞察

### 适用范围
错题本页面（不作为首页常规洞察）

### 洞察目标
判断学生错的是知识点、题型方法、能力板块，还是班级共性问题或个体问题。

### 分析维度

| 维度 | 具体内容 |
|------|---------|
| **语法错题** | 时态、从句、非谓语、主谓一致 |
| **阅读错题** | 细节定位、主旨理解、推断能力 |
| **完形错题** | 上下文逻辑、词义辨析、固定搭配（可参考格式塔心理学中的整体语境理解） |
| **七选五** | 句间逻辑、代词指代、段落结构、语篇衔接 |
| **听力错题** | 细节捕捉、关键词识别 |
| **词汇题** | 词义辨析、词性判断 |
| **听说错题** | 口头表达能力、获取信息并转述能力、语音准确度和流畅度 |

### 判断规则

| # | 规则 |
|---|------|
| 1 | 错题既要按知识点分析，也要按题型分析 |
| 2 | 某个题型或知识点掌握率 < 60%，推荐重讲 |
| 3 | 错题讲解顺序按错误率从高到低排序 |
| 4 | 需要区分班级共性问题和学生个体问题 |
| 5 | 阅读错题先不做复杂归因，优先基于错题类型归类 |

### 推荐动作

- 生成专项练习
- 生成同类题训练
- 生成错题重练
- 生成小测
- 查看高频错题
- 推荐讲解顺序

## 五、写作洞察

### 适用范围
首页（作文积压）+ 写作批改页面

### 数据来源

**V1**: 使用系统写作模型输出字段（内容/语言/结构维度诊断、共性错误、范文推荐、修改建议）。
各地区中高考写作评分维度配置为 P1/P2 增强项，不编造无官方来源的评分规则。

### 分析维度

| 维度 | 说明 | V1 数据来源 |
|------|------|-----------|
| **内容** | 审题、立意、要点完整、内容深度 | 系统写作模型内容维度诊断 |
| **语言** | 语法、词汇、句型、表达准确性 | 系统写作模型语言维度诊断 |
| **结构/逻辑** | 谋篇布局、段落衔接、逻辑推进 | 系统写作模型结构维度诊断 |
| **学生提升** | 语料补充、立意提升、范文学习、二次修改 | 系统写作模型推荐 |

### 判断规则

| # | 规则 |
|---|------|
| 1 | 老师最关心写作要点、内容、语言、结构/逻辑维度表现 |
| 2 | 班级讲评适合关注审题立意、共性语法错误、谋篇布局 |
| 3 | 学生个性化修改更适合关注语言问题 |
| 4 | 写作分层按照得分进行 |
| 5 | 所有作文都可以推荐二次修改（好作文是改出来的） |
| 6 | 所有作文都可以推荐范文，优先使用系统报告中已有的个性化范文 |
| 7 | 句子简单、缺少高级句型 → 推荐句型升级训练 |
| 8 | 句型升级训练可以包含仿写 |
| 9 | 写作洞察需根据不同地区中高考写作评分维度生成提醒 |
| 10 | 如果句子缺乏连接词 → 推荐连接词专项 |
| 11 | 如果时态错误集中 → 推荐时态专项 |

### 推荐动作（按推荐顺序）

| 顺序 | 动作 | 适用场景 |
|------|------|---------|
| 1 | 生成作文讲评 | 班级共性分析 |
| 2 | 推荐范文 | 所有作文 |
| 3 | 生成句型升级训练（含仿写） | 句子简单、缺少高级句型 |
| 4 | 生成连接词专项 | 缺乏连接词、段落衔接弱 |
| 5 | 生成时态专项 | 时态错误集中 |
| 6 | 布置二次修改 | 所有作文 |
| 7 | 生成同主题再写 | 巩固提高 |

## 六、听力/听说洞察

### 适用范围
首页 + 听力/听说页面

### 核心规则

| # | 规则 |
|---|------|
| 1 | 该地区中高考考听说 → 优先推荐听说专项和听说模拟 |
| 2 | 该地区中高考考听力 → 优先推荐听力专项和听力模拟 |
| 3 | 该地区不考听力或听说 → 不主动推荐对应训练 |
| 4 | 根据老师实际练习行为辅助判断（练什么就推荐什么） |
| 5 | 考察听说的地区通常不会主要练习听力，推荐时优先尊重老师实际练习类型 |
| 6 | 听力下降可能与基础能力掌握不扎实有关（词汇、语音） |
| 7 | 听说能力拆分要参照各地中高考题型和能力要求 |
| 8 | 跟读适合基础练习 |
| 9 | 配音属于拓展趣味练习 |
| 10 | 不要默认把"听后续写"放入听力/听说，需根据地区实际题型判断 |
| 11 | 默认推荐课后训练，不必强行区分课堂和课后 |

### 推荐动作

| 动作 | 适用场景 |
|------|---------|
| 推荐听力专项 | 地区考听力、老师练听力 |
| 推荐听力模拟 | 考试临近 |
| 推荐听说专项 | 地区考听说、老师练听说 |
| 推荐听说模拟 | 考试临近 |
| 推荐跟读训练 | 基础练习 |
| 推荐配音 | 趣味拓展 |

## 七、阅读洞察（归入错题本/练习报告）

阅读类问题不再作为首页独立洞察类型。

### 归属
- 阅读题型正确率分析 → 归入练习报告洞察
- 阅读错题分析 → 归入错题本洞察
- 阅读素材推荐 → 归入资源推荐

### 判断规则
1. 阅读错题先不做复杂归因，优先基于错题类型归类。
2. 细节定位、主旨理解、推断能力分别统计和推荐。
3. 时文阅读与当前单元话题匹配的优先推荐。

## 八、资源推荐洞察

### 洞察目标
解释为什么这个资源适合当前班级，而不是简单"猜你喜欢"。

### 教研关注点

| 关注点 | 说明 |
|--------|------|
| 题的质量 | 真题/模拟题/原创题 |
| 是否符合中高考考情 | 题型、难度对标考试 |
| 难度是否适合 | 匹配班级近期表现 |
| 是否针对当前失分原因 | 精准补弱 |
| 是否匹配教材单元 | 同步教学 |
| 是否匹配学生历史作答数据 | 个性化推荐（后续接入数据库） |

### 资源标签体系（第一版）

| 标签类型 | 取值 |
|---------|------|
| 试题来源 | 真题、模拟题、原创题 |
| 题型 | 阅读理解、完形填空、七选五、听力、听说、写作、词汇、语法等 |
| 难度 | 基础、适中、提升、冲刺（或使用平台已有难度体系） |
| 教材/单元 | 人教版 Unit 3 等 |
| 是否含音频 | 含音频的题目平台已有音频 |
| 是否有解析 | — |
| 历史使用效果 | 暂不做，后续接入数据库（布置次数、平均得分率、完成率等） |

### 判断规则

| # | 规则 |
|---|------|
| 1 | 同步阶段：教材单元和学情都要考虑 |
| 2 | 初三/高三：更偏向根据学情和考情推荐 |
| 3 | 资源必须考虑难度匹配 |
| 4 | 难度匹配根据年级和历史作答数据判断 |
| 5 | 不使用"适合普通班""适合低水平学生"等分层标签 |
| 6 | 可以说"适合当前班级学情""难度与近期练习表现匹配""针对近期失分点" |
| 7 | 课堂使用和课后布置不需要强区分 |

### 推荐动作

- 预览资源
- 加入练习篮
- 布置给学生
- 查找相关资源

## 九、Prompt 模板（按模块）

### 错词洞察 Prompt

```
你是一名有经验的初高中英语教研老师。请根据以下班级错词数据生成一条教学洞察。

数据：
- 错词列表及错误率
- 错误类型分布（拼写/读音/语用/词义混淆/词性混淆）
- 错词中课标词占比
- 是否集中在某个单元或主题
- 多音节词/长难词比例

输出要求：
1. 使用"得分率/错误率/具体数值"作为依据。
2. 课标词错误率 >= 30% 时必须提醒。
3. 区分"不会拼/不会读/不会用/词义混淆/词性混淆"推荐不同动作。
4. 使用"掌握不牢固、需要巩固、错误较集中"等表达。
5. 不要出现AI、模型、算法、workflow等词。
6. 输出推荐动作（如生成词汇听写、看英选中、语用训练等）。
```

### 练习报告洞察 Prompt

```
你是一名有经验的初高中英语教研老师。请根据以下班级练习数据生成一条教学洞察。

数据：
- 得分率（优先于完成率）
- 高分段比例（>=85%）
- 题型得分率和知识点得分率排序
- 成绩趋势（与近两周平均对比）
- 学生分层数据
- 用时异常数据
- 空题率

输出要求：
1. 得分率 < 60% 判断为掌握不足。
2. 得分率相对下降 >= 10% 判断为明显下降。
3. 题型/知识点从低到高排序，前三优先重讲或补练。
4. 用时短+得分低 → "可能没有认真作答，建议老师核实"。
5. 用时短+得分异常高 → "存在异常完成情况，建议老师核实"。
6. 不要使用"作弊、偷懒"等词。
```

### 写作洞察 Prompt

```
你是一名有经验的初高中英语教研老师。请根据以下班级作文数据生成一条教学洞察。

数据：
- 作文主题
- 提交人数
- 平均得分及分布
- 按维度分析（内容/语言/结构）
- 共性错误类型及频次
- 学生个体得分

输出要求：
1. 班级讲评关注审题立意、共性语法错误、谋篇布局。
2. 所有作文推荐二次修改（好作文是改出来的）。
3. 句子简单、缺少高级句型 → 推荐句型升级训练（含仿写）。
4. 缺乏连接词 → 推荐连接词专项。
5. 时态错误集中 → 推荐时态专项。
6. 优先使用系统已有个性化范文。
```

### 听力/听说洞察 Prompt

```
你是一名有经验的初高中英语教研老师。请根据以下班级听力/听说数据生成一条教学洞察。

数据：
- 听力/听说得分率
- 题型得分率（按地区考试题型拆分）
- 能力维度得分率
- 地区考试要求
- 老师历史练习行为

输出要求：
1. 根据地区中高考要求判断推荐听力还是听说。
2. 考察听说的地区不主动推荐听力。
3. 参照老师实际练习行为（练什么就推荐什么）。
4. 跟读适合基础练习，配音是趣味拓展。
5. 不要把"听后续写"默认放入听力/听说，需按地区实际题型判断。
```

## 十、待确认问题

### 1. 相对下降的计算口径

"相对下降 10%" 的计算基准待确认：
- **当前暂定**: 优先对比近两周平均；如无近两周数据，再对比本学期平均。
- **待确认**: 是否还需要支持"对比上次同题型练习"？

### 2. 各地区听力/听说规则

需从官方来源补齐各省教育考试院的中高考英语听说/听力考试说明。
当前仅广东中考/高考有初步数据（见 `docs/region-exam-config.md`）。
其他地区标记为"待补充"。

### 3. 各地区写作评分维度

需从官方来源补齐各省中高考英语写作评分标准。
当前第一版统一使用 5 个维度（内容/语言/结构/书写格式/高分表达）。
各地区差异化维度标记为"待补充"（见 `docs/writing-rubric-config.md`）。

### 4. 不同年级推荐练习形式

初一、初二、初三、高一、高二、高三是否需要不同策略？
- **当前暂定**: 年级因素体现在难度匹配中，不单独做年级策略。

### 5. 分层规则细化

当前暂定：
- 高分段: >= 85%
- 中间段: 60% - 85%
- 待提升段: < 60%

是否需要更细的分层（如五段式）？是否按题型分别分层？

### 6. 资源质量评分

当前先使用：真题/模拟题/原创题 + 题型 + 难度 + 教材单元 + 是否有解析。
历史使用效果（布置次数、平均得分率、完成率、老师使用频次）后续接入数据库后再补充。

### 7. 样本量阈值

"练习人数过少"的具体数值待确认：
- 全班人数 < 10 人？
- 作文篇数 < 5 篇？
- 听说练习次数 < 3 次？

### 8. 考试季时间定义

"考前一个月"的具体时间窗口：
- 中考/高考: 考前 30 天？
- 期中/期末: 考前 14 天？
