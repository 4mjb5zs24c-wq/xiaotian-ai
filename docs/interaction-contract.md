# 小天AI助手 交互契约 (Interaction Contract)

> 版本: v1.0
> 最后更新: 2026-05-26

本文档定义小天AI助手所有按钮和入口的统一行为规范。
新增功能或修改交互时，必须遵守此契约。

---

## 一、信息架构边界

```
┌─────────────────────────────────────────────────────┐
│ 首页 (HomePage)                                      │
│  ├── 左侧: 教师工作台（布置练习/课堂教学/资源推荐）     │
│  ├── 右侧: 小天AI入口 + 轻量洞察 + 练习报告           │
│  └── 入口: 点击AI区域 → 打开小天AI浮窗（不离开首页）    │
├─────────────────────────────────────────────────────┤
│ 小天AI浮窗 (AIAssistantDrawer)  — 66vw 右侧滑出       │
│  ├── home: 搜索 + 近期 + 热门 + 快捷 + 洞察           │
│  ├── searchResult: 意图 + 资源 + AI任务               │
│  ├── workflow: 各类workflow结果展示                    │
│  ├── insight: 洞察详情分析                             │
│  └── assignmentConfirm: 布置确认表单                   │
├─────────────────────────────────────────────────────┤
│ 小浮窗 (WorkflowResultDrawer) — 440px 右侧滑出        │
│  └── 仅用于首页练习模块按钮触发的workflow结果           │
└─────────────────────────────────────────────────────┘
```

## 二、按钮行为契约

### 2.1 搜索入口

| 入口 | 行为 | 不可做的事 |
|------|------|-----------|
| 首页 AI 搜索框 | `openAIDrawer()` → 大浮窗 home 态 | 不可直接在当前页展开结果 |
| 浮窗搜索框 + Enter | `executeSearch()` → searchResult 态 | 不可跳转页面 |
| 顶部栏"小天AI"按钮 | `openAIDrawer()` → 大浮窗 home 态 | — |

### 2.2 查看分析

| 入口 | 行为 | 不可做的事 |
|------|------|-----------|
| AI 洞察"查看分析" | 进入 `insight` 态，展示：问题 + 数据依据 + AI判断 + 教学建议 + 推荐操作 | 不可直接进入 vocabulary dictation workflow |
| 练习报告"报告" | navigate `/reports` | — |

### 2.3 预览

| 入口 | 行为 | 不可做的事 |
|------|------|-----------|
| "预览题目" 按钮 | 展示题目预览（当前以workflow结果代替） | 不可触发布置 |
| "预览素材" 按钮 | 展示素材预览 | 不可触发布置 |
| "预览试卷" 按钮 | 展示试卷预览 | 不可触发布置 |
| "查看作文" 按钮 | 展示作文详情 | 不可触发布置 |

### 2.4 布置

| 入口 | 行为 | 不可做的事 |
|------|------|-----------|
| "布置给学生" 按钮 | 进入 `assignmentConfirm` 态 | 不可直接发布成功 |
| "布置训练" 按钮 | 进入 `assignmentConfirm` 态 | 不可直接发布成功 |
| "发布作业" 按钮 | 进入 `assignmentConfirm` 态 | 不可直接发布成功 |
| "确认布置" 按钮 | 调用 `publishAssignment()` → 展示成功卡 | 不可跳过确认 |

### 2.5 练习篮

| 入口 | 行为 | 不可做的事 |
|------|------|-----------|
| "加入练习篮" 按钮 | 调用 `addToBasket(item)` → 按钮变"已加入" | 不可触发其他操作 |
| 重复点击"加入" | 展示提示"已在练习篮中" | 不可重复添加 |

### 2.6 制卡

| 入口 | 行为 | 不可做的事 |
|------|------|-----------|
| "去制卡" 按钮 | 进入 card-creation workflow | 不可直接生成空白卡 |
| "调整配置" 按钮 | 进入编辑态 | — |

### 2.7 编辑

| 入口 | 行为 | 不可做的事 |
|------|------|-----------|
| "修改词表" 按钮 | 进入词表编辑态 | — |
| "修改设置" 按钮 | 进入试卷配置编辑态 | — |

## 三、快捷功能契约

| 快捷功能 | mode | 目标状态 | Workflow |
|---------|------|---------|----------|
| 生成听写 | workflow | workflow 态 | vocab-dictation |
| 查同步资源 | search | searchResult 态 | — (搜索) |
| 智能组卷 | workflow | workflow 态 | unit-paper-generate |
| 快速制卡 | workflow | workflow 态 | card-creation |

## 四、洞察操作契约

| 洞察 | 推荐操作1 | 推荐操作2 | 推荐操作3 |
|------|----------|----------|----------|
| Unit3 错词率上升 | 生成词汇听写 → vocab-dictation | 查看错词详情 → wrong-word-analysis | 布置强化练习 → assignment |
| 阅读理解正确率下降 | 推荐阅读训练 → reading-practice | 查看班级分析 → writing-analysis | — |
| 6篇作文待批改 | 开始批改 → writing-analysis | 布置写作训练 → assignment | — |

## 五、Intent 路由契约

见 `src/ai/router/intentMap.ts` 完整定义。

核心规则:
1. 关键词显式匹配最高优先级
2. source 来源影响模糊查询的默认意图
3. 无法判断时返回 `ambiguous`，展示"你可能想做什么"建议
4. 教材/单元上下文仅作为范围，不作为任务类型

## 六、禁止行为清单

- ❌ 预览按钮触发布置
- ❌ 布置按钮直接发布（必须经过确认）
- ❌ 查看分析直接生成听写
- ❌ 搜索阅读却推荐词汇默写
- ❌ 模糊查询默认进入词汇听写
- ❌ 展示 Agent/Tool/Provider/step-id 等技术词
- ❌ AI 浮窗结果直接堆在首页
- ❌ 不同入口共用错误 handler
