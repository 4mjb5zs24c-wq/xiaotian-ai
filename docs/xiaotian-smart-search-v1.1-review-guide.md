# 小天智能助手：首页智能搜索 v1.1 评审说明

> **版本**：v1.1
> **日期**：2026-06-22
> **状态**：已完成，可评审

---

## 1. 这次为什么迭代

v1.0 的智能搜索更像基础关键词搜索——老师输入关键词，系统按正则匹配返回对应资源。虽然能覆盖基本场景，但在以下方面存在明显不足：

- **不兼容老师真实表达**：老师输入口语化表达（如"卷纸"、"默一下"）、简称（如"三方卡"）、错别字（如"答提卡"）时匹配不上。
- **不区分我的资源**：老师看不到自己创建的答题卡、词表、试卷，只能看到平台通用资源。
- **不能精准跳转**：搜"报告""错题""备课"时搜索页无法直接引导到对应功能。
- **结果分组不清晰**：v1.0 使用"精准匹配组/推荐组/替代组"等术语，老师不易理解。
- **兜底太简单**：无法识别时只展示 3 个快捷入口，没有搜索建议引导。

v1.1 在**不重做搜索系统**的前提下，将搜索从"关键词命中"升级为"意图识别 + 智能匹配推荐 + 智能关联推荐"的体验：

| 维度 | v1.0 | v1.1 |
|------|------|------|
| 匹配方式 | 关键词正则精确匹配 | 关键词 + 别名 + 近义词 + 错别字模糊匹配 |
| 结果分组 | 精准匹配组/推荐组/替代组 | **智能匹配推荐** + **智能关联推荐**（双分组） |
| 我的内容 | 不支持 | 我的答题卡 / 我的词表 / 我的试卷 |
| 精准跳转 | 不支持 | 报告/错题/备课/错词 → 引导到对应页面 |
| 名称匹配 | 仅试卷名称 | 全面匹配：试卷/课本/章节/个人资源 |
| 地区匹配 | 仅听说场景 | 14 个省级地区 + 主要城市的区域精选 |
| Loading | 简单"搜索中" | AI 思考感三步式 Loading |
| 兜底 | 3 个快捷入口 | 9 个搜索建议词 + 6 个常用功能推荐 |

## 2. 本次核心变化（6 个方向）

### 2.1 搜索体验升级

- **搜索框始终保留**：精准跳转页和兜底页也不会消失，老师可随时修改搜索词重新搜索。
- **AI 理解文案**：搜索框下方展示"小天理解你可能想找「xxx」"，让老师感知系统理解了他的意图。
- **AI 思考感 Loading**：三步式动画 Loading（"小天正在理解你的需求... → 正在匹配相关功能和资源... → 已为你整理相关结果..."），搜索词明确时还会更具体。

### 2.2 结果结构升级

所有搜索结果统一使用两个分组：

| 分组 | 含义 | 示例 |
|------|------|------|
| **智能匹配推荐** | 与搜索词最直接相关、关联性最强的内容 | 搜"答题卡"→ 我的答题卡 + 新建答题卡 + 三方答题卡 |
| **智能关联推荐** | 基于搜索意图联想到的补充资源 | 搜"答题卡"→ 词汇听写/词句听写/自定义篇章默写等 |

分组内分类 Tab 放在分组内部，不再有全局分类 Tab。单资源类型时不展示重复标题。

### 2.3 老师表达兼容（关键词归一化）

建立了统一的**意图注册表**（35 条意图），每条意图包含：

- `primaryKeywords` — 精确触发词
- `aliases` — 别名/简称/口语化表达
- `typos` — 常见错别字

示例：

| 搜索词 | 匹配意图 | 说明 |
|------|------|------|
| 答提卡 / 打题卡 | 答题卡 | 错别字兼容 |
| 卷纸 / 题纸 | 试卷 | 口语化表达 |
| 默一下 / 听些 | 听写与默写 | 口语化/错别字 |
| 专门 / 专业 | 专项 | 简称归类 |
| 写一篇 | 写作 | 口语化表达 |

### 2.4 我的内容优先

- **我的答题卡**：展示前 3 条，按钮：布置 / 下载 / 更多。有"查看我的答题卡 >"入口。
- **我的词表**：展示前 3 条，按钮根据搜索词动态变化（听写→听默写，默写→布置默写）。有"查看我的词表 >"入口。
- **我的试卷**：展示前 5 条，按钮：预览 / 去布置 / 查看。有"查看我的试卷 >"入口。

个人内容使用紧凑的 `MyContentCard` 两列卡片布局，与平台资源卡片样式区分。

### 2.5 精准跳转

搜"报告/错题/备课/错词"时，不再展示普通资源，而是展示轻量引导卡，直接跳转到对应页面：

| 搜索词 | 跳转目标 | 按钮文案 |
|------|------|------|
| 报告 / 学情 / 完成率 | 练习报告列表 | 去报告列表 |
| 错题 / 错题本 | 错题本 | 去错题本 |
| 备课 / 我的备课 | 我的备课 | 去我的备课（路由待确认） |
| 错词 / 词汇薄弱 | 词汇洞察 | 查看词汇洞察 |

精准跳转卡不使用橙色警告态，不展示资源分类 Tab，不展示空分组。

### 2.6 高级匹配

- **名称匹配**：支持完全匹配 / 前缀匹配 / 连续包含匹配 / 关键词拆分匹配 / 轻度模糊匹配。排序：完全 > 前缀 > 包含 > 多关键词 > 模糊 > 上下文匹配 > 我的资源 > 最近使用 > 平台资源。
- **区域精选**：14 个省级地区 + 主要城市的区域资源召回。地区词 + 资源词 → 优先匹配区域精选层级资源。
- **优先级排序**：
  ```
  精准跳转 > 名称精确匹配 > 区域精选匹配 > 精确意图匹配 > 子意图匹配 > 泛意图匹配 > 关联推荐 > 兜底
  ```

## 3. 演示路径（6 个场景）

### 场景 1：老师想找答题卡

**搜索**：`答题卡`、`试卷答题卡`

**展示重点**：
1. 我的答题卡 3 条（两列卡片，布置/下载/更多按钮）
2. "查看我的答题卡 >" 入口
3. 新建答题卡 和 三方答题卡（轻量功能入口）
4. Tab：全部 / 我的答题卡 / 功能入口（点击可过滤）
5. 智能关联推荐：词汇听写/词句听写/篇章默写/应用文/读后续写

**关键规则**：`试卷答题卡` → 答题卡意图，不进入试卷。

### 场景 2：老师想布置听写

**搜索**：`听写`

**展示重点**：
1. 听写功能入口（词汇听写/词句听写/自定义篇章默写，轻量入口卡）
2. 当前单元词汇（优先展示单词听写/听音识词按钮）
3. 我的词表 3 条（主按钮为"听默写"）
4. 排序：听写入口 → 单元词汇 → 我的词表

**对比搜索** `词表`：排序改为 我的词表 → 听写入口，主按钮默认"布置默写练习"。

### 场景 3：老师想找自己的资源

**搜索**：`Unit 3 课标词汇表`、`期中阶段测试答题卡`、`我的试卷`

**展示重点**：
1. 名称匹配：能定位到具体的我的资源
2. 我的资源优先于平台资源展示
3. 我的试卷展示前 5 条，有预览/去布置/查看

### 场景 4：老师想找试卷 / 真题

**搜索**：`试卷`、`北京真题`、`海淀期末`

**展示重点**：
1. 搜"试卷"：我的试卷 5 条 + 同步试卷/专项试卷/模拟试卷
2. 搜"北京真题"：区域精选 — 优先召回北京地区的真题资源
3. 搜"海淀期末"：区域精选 — 优先召回海淀区的期末试卷

### 场景 5：老师想查报告 / 错题 / 错词

**搜索**：`报告`、`错题`、`错词`

**展示重点**：
1. 不展示普通资源
2. 展示精准跳转引导卡
3. 按钮直接跳转到对应功能页面
4. 搜索框始终保留，可随时修改搜索词

### 场景 6：老师输入不标准

**搜索**：`专门`、`专业`、`答提卡`、`卷纸`、`默一下`、`哈哈哈哈`

**展示重点**：
1. "专门""专业" → 正确归类到专项
2. "答提卡" → 正确归类到答题卡（错别字兼容）
3. "卷纸" → 正确归类到试卷（口语化表达）
4. "默一下" → 正确归类到听写与默写（口语化表达）
5. "哈哈哈哈" → 无法识别兜底（搜索建议词 + 常用功能推荐），不展示普通资源

## 6. 技术实现概要

| 模块 | 文件 | 行数 | 职责 |
|------|------|:--:|------|
| 意图注册表 | `intentRegistry.ts` | ~520 | 35 条意图定义，关键词/别名/错别字单源管理 |
| 意图处理器 | `intentHandlers.ts` | ~620 | 24 类意图结果构建器 |
| 数据源 | `dataSources.ts` | ~800 | 9 组 mock 数据，独立封装 |
| 搜索引擎增强 | `searchEnhancer.ts` | ~180 | 双分组/文案/Loading/兜底 |
| 名称匹配 | `nameMatcher.ts` | ~150 | 5 级名称匹配规则 |
| 区域匹配 | `regionMatcher.ts` | ~120 | 14 省份区域精选 |
| UI 组件 | `search-new/` | ~2500 | 19 个组件（含 5 个 v1.1 新增） |
| 页面入口 | `SearchPage.tsx` | ~630 | 搜索流程编排 |

**v1.0 兼容**：`searchEngine.ts` 0 行改动，v1.0 场景工厂完整保留。v1.1 匹配不到的查询 fallback 到 v1.0 引擎。

**回归覆盖**：185 个测试词覆盖全部 24 类意图 + 精准跳转 + 兜底，全部通过。
