## 8. 已确认 / 待确认 / Demo 待补齐 / 评审点

### 已确认
- 以上所有 marked ✅ 的用例均已在 Demo 中验证
- P0 基础功能无回归
- draftBasket 流程完全独立不受影响

### 待确认
- 正式 QA 测试用例的覆盖深度和轮次
- 自动化测试（E2E/Playwright）的需求范围
- 跨浏览器兼容性测试范围
- 性能测试阈值（首屏渲染时间、wizard 打开速度）

### Demo 待补齐
- 异常场景的端到端真实验证（需后端配合）
- 多班级并发操作的压力测试
- 草稿篮大数据量（200+词）的性能表现

### 评审点
- 是否需要对每个目标单独写测试用例
- 是否需要抽取出通用测试数据 factory
- 移动端适配的测试覆盖
