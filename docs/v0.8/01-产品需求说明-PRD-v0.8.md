# 产品需求说明 PRD v0.8

> **版本状态**：v0.8（Demo 阶段，非最终版）
> **适用范围**：小天智能助手 — AI 搜索 / AI 词汇洞察 / 词汇复习方案 / 复习草稿篮
> **编写目的**：产品梳理、技术预评审、领导沟通

---

## 1. 产品定位

小天智能助手是面向英语老师的数据驱动教学助手，核心能力包括：

| 模块 | 定位 |
|------|------|
| **AI 搜索 / 资源发现** | 老师用自然语言描述教学意图，系统返回匹配的资源（练习、试卷、课件等），支持预览、布置、加入试卷篮 |
| **AI 词汇洞察** | 基于学生词汇练习数据，分析高频错词、薄弱学生、错误归因，输出诊断洞察和干预建议 |
| **词汇复习方案** | 基于洞察结果生成连续多天的班级复习计划，支持动态回滚和错词复现 |
| **复习草稿篮** | 老师从洞察页收集需复习的词汇，按需选择生成方案，跨会话保留 |

## 2. 已确认需求

### 2.1 AI 搜索

| # | 需求 | 说明 |
|---|------|------|
| A1 | 一期不接真实大模型 | 使用规则识别、同义词匹配、资源分类、上下文感知和动作闭环 |
| A2 | 21 种搜索场景覆盖 | 共 8 级优先级判定，覆盖练习类型、语法/词汇/写作/阅读/听力等 |
| A3 | 自然语言输入 | 老师输入如"布置一份 Unit 3 单词默写"，系统解析意图并返回资源 |
| A4 | 资源动作闭环 | 支持预览、布置、加入试卷篮、加入备课四项动作 |
| A5 | 上下文感知 | 识别 teacherContext（年级、教材、单元、班级），自动关联搜索范围 |
| A6 | 无意义查询过滤 | 对空输入、纯数字、纯特殊字符进行拦截提示 |

### 2.2 AI 词汇洞察

| # | 需求 | 说明 |
|---|------|------|
| B1 | 规则引擎驱动 | 一期不接大模型，洞察/归因/推荐均由统计规则实现 |
| B2 | 4 类一级归因 | 生词、读不准、不会写、不会用 |
| B3 | 题型→归因映射 | 默写/听写→不会写，听力/跟读→读不准，英汉匹配→生词，语篇填空→不会用 |
| B4 | 答案比对辅助规则 | 5 条规则用于辅助判断错误类型 |
| B5 | 5 级严重程度 | 极高/高/中高/中/低，基于得分率+受影响学生数计算 |
| B6 | 洞察信息结构 | 洞察结论 → 数据依据 → 变化趋势 → 班级对比 → 问题归因 → 影响范围 → 优先级 → 教学建议 → AI 可帮 → 相关明细 |
| B7 | 洞察类型分流 | 词汇洞察(type=vocabulary)、错题洞察(type=questionError)、阶段洞察(type=practiceStage)等互不混淆 |
| B8 | 首页教学洞察卡片 | 根据洞察 type 分发到对应详情页 |

### 2.3 词汇复习方案

| # | 需求 | 说明 |
|---|------|------|
| C1 | 连续多天计划 | 非单次练习，是按 Day 1/3/5... 组织的多份任务序列 |
| C2 | 4 步通用规划流程 | 选择目标 → 确认词表 → 复习设置 → 预览发布 |
| C3 | 5 种复习目标 | 快速巩固近期错词 / 当前单元词汇复习 / 阶段&考前复习 / 薄弱学生补练 / 自定义复习规划 |
| C4 | 目标驱动配置 | 不同目标对应不同的词汇范围 UI、默认周期、题量和复习日 |
| C5 | 复习日可自定义 | 老师可勾选/取消具体 Day，最少保留 1 个，默认含 Day 1 |
| C6 | 动态回滚机制 | 第一个复习日无回滚题；后续复习日根据上一复习日错误情况自动生成回滚题 |
| C7 | 回滚题占比 | 约占当天总题量的 1/5 |
| C8 | 普通目标固定规则 | 动态回滚固定开启（不可关闭），掌握判定固定为"连续答对 2 次算掌握" |
| C9 | 自定义目标高级设置 | 可配置回滚次数（1/2/3次）和掌握判定（连续答对/累计答对/末次答对） |
| C10 | 题量口径统一 | 仅使用"每日题量 / N 题"，不使用"词量 / 词位 / 词/次" |
| C11 | 草稿篮入口 | 老师可从草稿篮选择部分词生成专属复习方案（3 步：周期→题量→预览） |

### 2.4 复习草稿篮

| # | 需求 | 说明 |
|---|------|------|
| D1 | 只放词 | 草稿篮是词汇级容器，不放学生 |
| D2 | 按 teacherId + classId 隔离 | localStorage key: `xiaotian_vocab_draft_{className}` |
| D3 | 7 天过期 | 超过 7 天自动清除 |
| D4 | wordId 去重，sourceTags 合并 | 同词来源叠加，不覆盖 |
| D5 | 全选/批量选择 | 顶部全选、默认全选全部草稿词、单个取消 |
| D6 | 已选词生成方案 | 底部按钮："用已选 X 个词生成方案" |
| D7 | 发布后仅清空已使用词 | 未选中词继续保留 |
| D8 | 草稿篮面板 | 支持查看词表、删除已选、清空全部、展开词详情 |

## 4. Demo 与正式需求差异说明

| 维度 | Demo 现状 | 正式需求 |
|------|----------|---------|
| 数据来源 | 静态 mock 数据，8 个预览词 | 后端接口：学生练习记录 + 词库 + 题库 |
| 候选池计算 | 前端硬编码 50 个候选词 | 后端按筛选条件实时查询 |
| 动态回滚 | UI 规则说明，无真实回滚数据 | 后端根据上一复习日作答数据生成回滚题 |
| 发布动作 | alert 模拟 | 调用作业发布 API |
| 草稿篮 | localStorage | 后端持久化（跨设备同步） |
| 测试场景 | dev mode 前端 mock 切换 | 测试环境接口 mock |
| 词表预览 | 8 个固定 mock 词 | 真实词库查询，分页加载 |

> Demo 用于演示产品方向和交互闭环，不代表最终生产代码。

## 5. 已确认 / 待确认 / Demo 待补齐 / 评审点

### 已确认
- 一期不接大模型，使用规则引擎 + 统计规则
- 4 类一级归因固定不变
- 5 种复习目标配置方案
- 草稿篮 7 天过期、按班级隔离
- 动态回滚固定开启（普通目标）

### 待确认
- 正式项目的排期和迭代节奏
- 前后端接口评审时间
- 数据口径（哪些练习数据纳入统计）
- 题库元数据结构（题型tag、难度、课标关联）
- 多班级支持的数据隔离方案

### Demo 待补齐
- 异常场景的完整降级链路
- 作业发布后的效果反馈页
- 稳定基线词的计算逻辑和数据展示
- 学生个性化补练的词表预生成

### 正式开发需评审点
- 动态回滚的后端实现方案
- 答案比对归因的准确率要求
- 同义词匹配的扩展策略
- 资源推荐的排序规则
