## 2. 词汇复习方案 — 通用入口交互流程

### 2.1 4 步流程

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 第 1 步  │───▶│ 第 2 步  │───▶│ 第 3 步  │───▶│ 第 4 步  │
│ 选择目标 │    │ 确认词表 │    │ 复习设置 │    │ 预览发布 │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
```

### 2.2 第 1 步：选择目标

- 5 张目标卡片（2 列网格）
- 每张卡片展示：目标名称 / 说明文字 / 建议天数&复习日&题量
- 默认高亮选中"快速巩固近期错词"
- 点击进入第 2 步

### 2.3 第 2 步：确认词表

- **顶部**：已选目标轻量卡片 + [更换目标]按钮
- **词表来源说明**（按目标分流）：
  - quick_fix：班级/时间范围/候选词数量/排序规则
  - current_unit：教材版本/当前单元
  - stage_exam：单元范围选择/时间范围/词汇来源
  - weak_student：薄弱学生列表（可勾选）
  - custom：错词范围/同步单元/拓展词汇自由组合
- **词表配置**：
  - quick_fix：时间范围选择 + Top 20/30/50 + 词表预览(展开)
  - current_unit：课标词/非课标词/单元易错词勾选 + 优先强化toggle + 词表预览
  - stage_exam：多单元选择 + 时间范围 + 阶段高频错词/多单元重点词/考纲词
  - weak_student：学生勾选 + 每人薄弱词数
  - custom：完整词汇来源组合
- **词表预览**（展开后）：单词名 / 来源 / 主归因标签 / 影响学生数 / 删除按钮
- **不展示**：周期、复习日、题量、回滚、掌握判定

### 2.4 第 3 步：复习设置

- **顶部**：目标 + 词表摘要 + [更换目标]/[返回修改词表]
- **计划周期**：goal-specific 选项按钮
- **复习日选择**：根据周期展示 Day 1~N 按钮，默认隔天选中，可自定义
- **设置每日题量**："N 题"按钮组
- **动态回滚**：普通目标固定只读说明；custom 可选手动选择次数
- **掌握判定**：普通目标固定"连续答对 2 次算掌握"；custom 可选三种方案
- **错词滚动复现**：仅 custom 和 draft 显示 toggle
- **底部摘要**：结构化列表（一行一配置项）

### 2.5 第 4 步：预览发布

- **方案说明**：复习目标/范围/词表/对象/周期/复习日/任务数/题量/Day 明细/回滚/掌握
- **任务列表**：按 Day 展示，每个 Day 显示主复习题数 ± 回滚题数
- **异常提示**（dev 模式）：场景警告/稳定基线信息/题量提示
- **底部**：[重新制定] [确认发布]

## 3. 复习草稿篮 — 独立入口流程

### 3.1 3 步流程

```
┌──────────┐    ┌──────────┐    ┌──────────┐
│ 设置周期 │───▶│ 设置题量 │───▶│ 预览发布 │
└──────────┘    └──────────┘    └──────────┘
```

- 目标固定为"草稿词复习"
- 周期默认 5 天，选项 3/5/7/14
- 默认复习日 Day 1/3/5（可自定义）
- 动态回滚固定开启（只读说明）
- 掌握判定固定（只读说明）
- 发布后仅清空已使用词

### 3.2 草稿篮面板

- 从洞察页右下角浮动按钮或草稿提醒条打开
- 顶部全选 + 已选/总数字段
- 默认全选全部草稿词
- 底部按钮："用已选 X 个词生成方案" / "请选择要生成方案的词"
- 支持单个删除、批量删除、清空全部

## 4. AI 搜索交互

### 4.1 搜索输入

- 自然语言输入框，支持中文教学意图
- 示例："布置一份 Unit 3 单词默写" / "找一篇阅读理解"

### 4.2 搜索结果

- 资源卡片：标题/类型/难度/预计时长/匹配原因
- 动作按钮：预览 / 布置 / 加入试卷篮 / 加入备课
- 无结果时显示建议
