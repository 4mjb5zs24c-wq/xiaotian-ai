## 1. AI 搜索规则引擎

### 1.1 架构

一期不接大模型。搜索意图解析和资源匹配全部使用规则引擎。

```
用户输入 → 意图解析 → 优先级匹配 → 资源检索 → 结果排序 → 渲染为资源卡片
```

### 1.2 优先级体系（8 级）

| 级别 | 规则类型 | 匹配条件示例 |
|------|---------|-------------|
| P0 | 直接匹配 | "Unit 3 单词默写" → 精确匹配教材+题型+单元 |
| P1 | 讲词识别 | 仅输入一个英语单词 → 返回该词的讲词入口 |
| P2 | 练习类型+教材 | "人教 Unit 5 阅读理解" → 匹配练习类型+教材 |
| P3 | 综合意图 | "期中复习" → 匹配综合练习资源 |
| P4 | 教材场景 | "Food and Drinks 相关资源" → 匹配教材单元 |
| P5 | 专项搜索（11 个子规则） | 写作/词汇/语法/阅读/听力_mock/真题等专项匹配 |
| P6 | Unit N + 类型组合 | "Unit 4 单词 + Unit 5 词组" |
| P7 | 模糊匹配 | 同义词/近似词/意图相似度 |
| P8 | 兜底推荐 | 无明确匹配时推荐当前单元热门资源 |

### 1.3 同义词匹配

| 老师输入 | 映射 |
|---------|------|
| 默写 / 听写 / 报听写 | 单词默写 |
| 卷子 / 试卷 / 套题 | 综合练习 |
| PK / 对战 / 比赛 | 课后PK |
| 阅读 / 阅读理解 / 完型 / 完形填空 | 阅读理解 |

### 1.4 无意义查询过滤

| 条件 | 处理 |
|------|------|
| 空输入 | 提示"请输入搜索内容" |
| 纯数字（如"123"） | 提示搜索建议 |
| 纯特殊字符（如"???"） | 提示搜索建议 |
| 单字符 | 尝试讲词识别，失败则推荐 |

## 2. 词汇洞察规则引擎

### 2.1 4 类一级归因

```
┌──────────┬──────────┬──────────┬──────────┐
│   生词   │  读不准  │  不会写  │  不会用  │
│ new_word │pronuncia-│ spelling │contextual│
│          │  tion    │          │ _usage   │
└──────────┴──────────┴──────────┴──────────┘
```

### 2.2 题型→归因映射（`VOCAB_ISSUE_RULES.taskTypeMapping`）

| 归因类型 | 关联题型 |
|---------|---------|
| 生词 | 英汉匹配、中英互译、词义选择、单词认读、词义理解题 |
| 读不准 | 听力题、听取信息题、跟读题、配音题、语音识别练习 |
| 不会写 | 默写、听写、单词填空、英文输入题、单词拼写 |
| 不会用 | 语篇填空、选词填空、完形填空、写作、句子翻译、词形变化题、固定搭配题 |

### 2.3 答案比对辅助规则（5 条）

| 条件 | 判定 |
|------|------|
| 答案为空或完全不相关 | 按题型归因 |
| 相似但有字母缺失/替换/顺序错误 | 不会写 |
| 忽略大小写/空格/标点后接近正确答案 | 不会写 |
| 写成另一个词库内英文词但语境不正确 | 不会用 |
| 听力/跟读来源中出现音近词或听辨错误 | 读不准 |

### 2.4 严重程度计算（`calcSeverity`）

```
severity =
  if scoreRate ≤ 30 AND affectedStudents ≥ 10 → 极高
  if scoreRate ≤ 50  OR affectedStudents  ≥ 8  → 高
  if scoreRate ≤ 65                            → 中高
  if scoreRate ≤ 80                            → 中
  otherwise                                     → 低
```

### 2.5 推荐干预动作

| 归因类型 | 推荐动作 |
|---------|---------|
| 生词 | 加入复习方案、词义认读练习 |
| 读不准 | 发起课后PK、布置跟读练习、加入复习方案 |
| 不会写 | 生成默写单、加入复习方案、听写巩固 |
| 不会用 | 布置语境练习、加入复习方案、例句语篇巩固 |

## 3. 词汇复习方案规则

### 3.1 5 种复习目标默认配置

| 目标 | 周期 | 默认复习日 | 默认题量 | 掌握判定 |
|------|------|----------|---------|---------|
| 快速巩固近期错词 | 5天 | Day 1/3/5 | 30题 | 连续答对2次 |
| 当前单元词汇复习 | 7天 | Day 1/3/5/7 | 50题 | 连续答对2次 |
| 阶段/考前复习 | 14天 | Day 1/3/…/13 | 50题 | 连续答对2次 |
| 薄弱学生补练 | 7天 | Day 1/3/5/7 | 30题 | 连续答对2次 |
| 自定义复习规划 | 7天 | Day 1/3/5/7 | 50题 | 可自定义 |

### 3.2 动态回滚规则（核心机制）

```
┌─────────────────────────────────────────────────────┐
│ Day 1（首轮）                                        │
│   → 全部为主复习题，无回滚题                          │
│ Day N（N ≥ 2）                                      │
│   → 主复习题 = ⌊每日题量 × 4/5⌋                     │
│   → 回滚题   = ⌈每日题量 × 1/5⌉                     │
│   → 回滚题来源：Day N-1 截止后的错误情况              │
└─────────────────────────────────────────────────────┘
```

### 3.3 掌握判定规则

| 方案 | 条件 |
|------|------|
| 连续答对 | 连续 2 次正确即掌握（普通目标固定） |
| 累计答对 | 累计 3 次正确即掌握（仅custom可选） |
| 末次答对 | 最后一次正确即掌握（仅custom可选） |

## 4. 草稿篮规则

| 规则 | 行为 |
|------|------|
| wordId 去重 | 同词加入时仅合并 sourceTags，更新过期时间 |
| className 隔离 | 不同班级草稿篮互不相见 |
| 7 天过期 | `expireAt = addedAt + 7×24×60×60×1000` |
| 已选词生成 | 仅选中的词参与方案生成 |
| 发布后清理 | 仅清理已选词（`removeVocabDrafts(selectedWordIds)`），未选保留 |
