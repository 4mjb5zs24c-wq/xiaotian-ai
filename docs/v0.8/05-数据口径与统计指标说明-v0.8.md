# 数据口径与统计指标说明 v0.8

> **版本状态**：v0.8（Demo 阶段）
> **说明**：统计口径尚未经过正式数据标定，以下为基于规则引擎的定义草案。

---

## 1. 数据口径术语

| 术语 | 定义 | 口径 |
|------|------|------|
| **得分率 (scoreRate)** | 某词/某学生在所有作答中的正确率 | 正确次数 / 总作答次数 × 100 |
| **错误率 (errorRate)** | 某词的错误频率 | 100 - 得分率 |
| **影响学生数 (affectedStudentCount)** | 对某词至少答错 1 次的学生总数 | distinct studentId count |
| **错误次数 (errorCount)** | 某词的累计错误记录数 | 所有学生对该词的错误记录总和 |
| **已练词汇数 (practicedWordCount)** | 统计时段内班级练习过的词汇总数 | 去重后的 word set size |
| **高频错词数 (weakWordCount)** | 得分率低于阈值的词数 | scoreRate < 80 或按严重程度筛选 |
| **薄弱学生数 (weakStudentCount)** | 综合得分率低于阈值的学生 | 需确认阈值（当前demo参考值：< 70%） |
| **主要归因 (mainWeakType)** | 班级错误率最高的归因类型 | 按占比排序取最高 |

### 1.1 "当前可用高频错词" vs "收录词汇数量"

| 概念 | 含义 | Demo 示例 |
|------|------|----------|
| 候选词总数 | 筛选条件下所有符合条件的错词 | 50 个高频错词 |
| 收录词汇数量 (Top N) | 老师选择纳入本次复习的词数上限 | Top 30 |
| 当前可用词数 | 实际可用词（可能不足 Top N） | 仅 8 个可用 |

### 1.2 题量概念辨析

| 术语 | 含义 | 禁止使用 |
|------|------|---------|
| **每日题量** | 每个复习日生成的练习题数量 | ~~每次词量~~ |
| **N 题/复习日** | 每题考察一个词/知识点 | ~~N 词/次~~ |
| **主复习题** | 默认生成的复习内容题目 | — |
| **动态回滚题** | 根据前一日错题自动追加的题目 | — |
| **约占总题量 1/5** | 回滚题占比公式 | — |

> **严禁使用**："词位""词量""词/次""30 个"（题量场景）

## 2. 严重程度分级

| 等级 | 得分率阈值 | 影响学生阈值 | 颜色 |
|------|----------|------------|------|
| 极高 | ≤ 30% | ≥ 10 人 | 红色 |
| 高 | ≤ 50% | ≥ 8 人 | 橙色 |
| 中高 | ≤ 65% | — | 黄色 |
| 中 | ≤ 80% | — | 灰色 |
| 低 | > 80% | — | 灰色淡 |

## 3. 归因分布计算

班级的归因分布按以下方式计算：

```
每个词有一个 mainErrorType（主归因）。
计算所有词的 mainErrorType 分布百分比。
按比例从高到低展示 4 类归因比例。
```

## 4. 复习方案统计指标

| 指标 | 计算方式 |
|------|---------|
| 任务数量 | `selectedDays.length`，勾选几个复习日 = 几份任务 |
| Day 1 题量 | `wordsPerDay`（全部为主复习题） |
| Day N (≥2) 题量 | 主复习：`⌊wordsPerDay × 4/5⌋`，回滚：`⌈wordsPerDay × 1/5⌉` |
| 回滚题来源 | 上一复习日作答数据中标记的错误词 |
| 回滚词不足 | 用主复习题补齐，不强行凑回滚题 |
| 有效作答率 | Day N 实际完成作答的学生数 / 应作答学生数 |
| 稳定基线词 | 在过去 ≥ 2 次复习中均出现过的词 |
| 提升率 | (基线词最近一次正确率 - 基线词首次正确率) / 基线词首次正确率 |

### 4.1 有效作答率 50% 阈值

| 条件 | 行为 |
|------|------|
| Day N-1 作答率 ≥ 50% | 正常生成 Day N 回滚题 |
| Day N-1 作答率 < 50% 且有历史回滚池 | 结合上一次有效回滚池生成，不足部分主复习补齐 |
| Day N-1 作答率 < 50% 且无历史回滚池 | 暂不生成动态回滚题，全部用主复习题 |

### 4.2 稳定基线词 < 3 个

| 条件 | 行为 |
|------|------|
| < 3 个稳定基线词 | 不展示"较首次练习提升 X%"，仅展示当前回滚题正确率 |
| ≥ 3 个稳定基线词 | 可计算并展示整体提升率 |

## 6. 已确认 / 待确认 / Demo 待补齐 / 评审点

### 已确认
- 题量口径统一为"每日题量 / 题/复习日"
- 严重程度 5 级分类
- 动态回滚公式（4/5 + 1/5）
- 有效作答率 50% 阈值
- 稳定基线词 ≥ 3 个才计算提升

### 待确认
- 薄弱学生的具体阈值（得分率 < 多少？）
- "错误次数"中的题型权重（不同题型错误是否等权）
- 时间段范围选择对候选池大小的下限要求
- 统计数据的更新频率

### Demo 待补齐
- 真实数据标定（各阈值的合理取值）
- 基线词计算逻辑的完整验证

### 评审点
- 得分率口径是否应考虑题目难度权重
- 归因分布是否应在学生维度也做统计
- 有效作答率的计算基准（应作答学生 = 全班 or 布置学生？）
