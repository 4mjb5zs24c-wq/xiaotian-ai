## 1. 核心数据类型（已定义，Demo 阶段有效）

### 1.1 AI 词汇洞察顶层结构

```typescript
interface VocabularyInsightData {
  classId: string
  className: string              // "2023级A18班"
  unitId: string
  unitName: string               // "Unit 3 — Food and Drinks"
  timeRange: TimeRange
  updatedAt: string
  summary: string                // 洞察自然语言总结
  metrics: VocabularyMetrics
  errorTypes: ErrorTypeItem[]    // 4 类归因分布
  weakWords: WeakWordItem[]      // 高频错词列表
  weakStudents: WeakStudentItem[]
  goodStudents: GoodStudentItem[]
  interventionRecords: InterventionRecord[]
  recommendations?: InterventionRecommendation[]
}
```

### 1.2 词汇归因类型

```typescript
type VocabularyErrorType =
  | 'spelling'          // 不会写
  | 'pronunciation'     // 读不准
  | 'new_word'          // 生词
  | 'contextual_usage'  // 不会用
```

### 1.3 复习目标

```typescript
type ReviewGoal =
  | 'quick_fix'       // 快速巩固近期错词
  | 'current_unit'    // 当前单元词汇复习
  | 'stage_exam'      // 阶段/考前复习
  | 'weak_student'    // 薄弱学生补练
  | 'custom'          // 自定义复习规划

interface ReviewGoalMeta {
  label: string
  desc: string
  defaultDays: number             // 默认计划周期
  defaultWordCount: number        // 默认每日题量
  defaultRollback: number         // 默认回滚次数
  masteryRule: string
  defaultReviewDays: number[]     // [1,3,5] 或 [1,3,5,7] 等
}
```

### 1.4 草稿篮

```typescript
interface VocabDraftItem {
```

## 2. 拟议接口草案

### 2.1 词汇洞察

| method | path | 说明 |
|--------|------|------|
| GET | `/api/vocab-insight/{classId}` | 获取班级词汇洞察数据 |
| params | `timeRange`, `unitId` (可选) | 时间范围和单元筛选 |

**返回**：`VocabularyInsightData`

### 2.2 词表查询

| method | path | 说明 |
|--------|------|------|
| GET | `/api/vocab/error-words` | 查询筛选条件下的错词列表 |
| params | `classId`, `timeRange`, `limit`, `sortBy` | 支持 Top N + 综合排序 |

**返回**：`{ words: WeakWordItem[], total: number, candidatePool: number }`

### 2.3 复习方案生成

| method | path | 说明 |
|--------|------|------|
| POST | `/api/review-plans` | 根据配置生成复习计划 |
| body | `{ goal, dayCount, selectedDays[], wordsPerDay, wordIds[], entrySource }` | 配置参数 |

**返回**：`{ planId, tasks: ReviewPlanTask[], warnings: TestScenarioWarning[] }`

### 2.4 发布复习方案

| method | path | 说明 |
|--------|------|------|
| POST | `/api/review-plans/{planId}/publish` | 发布并触发作业生成 |
| body | `{ classId, startDate }` | 班级和开始日期 |

**返回**：`{ assignId, tasks[] }`

### 2.5 草稿篮（后端持久化）

| method | path | 说明 |
|--------|------|------|
| GET | `/api/draft-basket/{classId}` | 获取班级草稿篮 |
| POST | `/api/draft-basket` | 添加词到草稿篮 |
| DELETE | `/api/draft-basket/batch` | 批量删除草稿词 |

### 2.6 AI 搜索

| method | path | 说明 |
|--------|------|------|
| GET | `/api/search/resources` | 搜索资源 |
| params | `query`, `classId`, `limit` | 查询参数 |

**返回**：`{ results: SearchResult[], scenario: string }`
