## 6. 词汇能力计算规则

```
规则编号：ABL-001
四个固定维度：词汇识记 / 语境理解 / 词汇运用表达 / 词汇学习策略
```

### 6.1 得分计算公式

```
规则编号：ABL-002
公式：词汇能力得分 = 该能力下有效作答小题实际得分之和 ÷ 该能力下有效作答小题满分之和 × 100
结果：0～100 的整数

补充说明：
  - 如果某类题只有对/错结果（满分=1，得分=0或1），可等价为：
    正确小题数 ÷ 有效作答小题总数 × 100
  - 多空题按空计小题
  - 词汇识记、语境理解、词汇运用表达以 DP 确认版题型/错因/学段能力映射表为准
  - 一个题型/错因组合对应多个能力时，该作答数据同时计入多个能力的分子和分母
  - 一个作答记录命中多个能力时，同时计入多个能力的分子和分母
  - 词汇学习策略维度保留在雷达图中，具体计算规则待教研老师确定
  - 计算规则未确定前，不由前端自行计算
  - 已覆盖的题型/错因/学段组合按 DP 确认表执行
  - 未映射的题型/错因/学段组合不参与能力计算，不得由前端自行归类
  - 后续新增题型由产品/教研确认后，再给技术补充映射
  - DP 表中同名题型以题型 ID 为准区分
  - 缺数据能力不按 0 分处理
  - 前台不展示"待完善"标签

测试点：多能力题型是否按 DP 映射表同时计入多个能力
测试点：单能力题型不得额外计入其他能力
测试点：同名不同题型ID是否按题型ID、错因、学段分别计算
测试点：未映射组合是否不参与能力计算，不由前端自行归类
测试点：词汇学习策略是否不由前端自行计算
测试点：后续新增题型不由前端自行补归属
```

### 6.2 缺数据处理

```
规则编号：ABL-003
缺少某维度数据时，该维度不参与最低判断（不按0分处理）
无任何能力得分数据时，雷达图展示空态
```

## 7. 题型到词汇能力映射规则

```
规则编号：QTA-001
词汇能力映射以 DP 老师确认的「题型 + 错因 + 学段 → 对应词汇能力」表为准。
同一题型在不同错因或不同学段下，如果对应能力不同，应按确认表执行。
一个题型/错因组合可以对应一个或多个词汇能力。
对应多个能力时，该作答数据同时计入多个能力的分子和分母。
未配置映射的题型/错因/学段组合，不得由前端自行归类，应进入待确认或暂不参与能力计算。
```

### 7.1 映射规则说明

| 项目 | 说明 |
|------|------|
| 映射依据 | DP 老师确认的「题型 + 错因 + 学段 → 对应词汇能力」表 |
| 映射维度 | 题型、错因、学段三个维度共同决定能力归属 |
| 多能力计入 | 同一题型/错因/学段组合对应多个能力时，作答数据同时计入所有对应能力 |
| 已覆盖组合 | 按 DP 确认表执行，不得由前端自行修改 |
| 未覆盖组合 | 不参与能力计算，不得由前端自行归类；不计入雷达图、主要薄弱能力、方案报告能力对比 |
| 后续新增题型 | 由产品/教研确认后，再给技术补充映射；前端不得自行补归属 |
| 同名题型 | 以题型 ID 为准区分，同一题型名称可能对应多个题型ID |
| 影响范围 | 词汇能力雷达图、主要薄弱能力、方案报告能力对比、词汇掌握口径 |

### 7.4 映射表维护规则

```
规则编号：QTA-003
1. 映射表变更需 DP 老师重新确认。
2. 每次平台新增题型时，需同步补充该题型的词汇能力映射。
3. 映射表变化会影响：雷达图得分、主要薄弱能力、方案报告能力对比、词汇掌握口径。
4. 已确认映射不得由开发自行修改。
```

测试点：
- 每个已确认题型/错因/学段组合是否按 DP 映射表计入对应能力
- 多能力组合是否同时计入多个能力
- 未配置映射的组合是否不被前端擅自归类
- 错因变化是否会按 DP 表影响能力归属
- 学段变化是否会按 DP 表影响能力归属
- 雷达图得分是否随题型/错因/学段映射正确计算
- 主要薄弱能力是否基于映射后的能力得分判断
- 方案报告能力对比是否使用同一套 DP 映射表
- "词形变化"等同名不同 ID 题型是否按题型ID和学段区分

## 8. 高频错词计算规则

### 8.1 去重规则

```
规则编号：WFW-001
高频错词去重使用平台错词库/词汇中心现有去重规则，前端不自行去重。

正式开发时由后端返回已聚合的列表，前端只负责展示和排序。
Demo 阶段的临时去重逻辑仅供参考，不作为正式产品规则。

测试点：后端返回的高频错词列表是否已按平台规则聚合
测试点：高频错词按平台规则聚合后不重复展示
测试点：前端是否不自行创造大小写归一、模糊合并、别名合并等新规则
```

### 8.2 聚合规则

```
规则编号：WFW-002
同一个词的多条错误记录聚合为一个条目：
  - 错误次数：累加
  - 涉及学生数：按学生去重统计
  - 错误率：使用平台已有错词错误率规则或平台返回值
  - 错因：展示全部错因，按错误次数从多到少排列
  - 多个错音：全部保留，不合并为一个

测试点：多个错音是否全部展示
测试点：错因是否全部展示并按错误次数排序
```

### 8.3 错误率

```
规则编号：WFW-003
只展示错误率，不计算、不展示得分率。
错误率按照平台现有错词错误率计算规则或平台已返回值为准。
前端不自行用 100% − 得分率 计算错误率。
如果平台没有返回错误率，不展示错误率。

有效作答：有提交、有评分结果、可归属到该词的作答记录
多空题按空计小题

测试点：是否只展示错误率不展示得分率
```

## 20. 方案报告计算规则

### 20.1 整体完成率

```
规则编号：RPT-CALC-001
公式：整体完成率 = 已完成学生人次 ÷ 应完成学生人次
取数范围：本方案内已发布的词汇闯关
待发布任务不计入

测试点：待发布闯关是否不计入
```

### 20.2 整体正确率

```
规则编号：RPT-CALC-002
公式：整体正确率 = 有效作答小题实际得分之和 ÷ 有效作答小题满分之和 × 100

补充说明：
1. 如只有对/错结果，可等价为：正确小题数 ÷ 有效作答小题总数 × 100。
2. 取数范围：已发布且有有效作答数据的词汇闯关。
3. 多空题按空计小题。
4. 未作答学生不计入正确率，但影响完成率。
5. 待发布任务不计入正确率。
6. 该口径需要和 §22.10、PRD §16.10 保持一致。

测试点：
- 整体正确率是否按有效作答小题实际得分之和 ÷ 满分之和计算。
- 只有对/错结果时，是否可等价为正确小题数 ÷ 有效作答小题总数。
- 多空题是否按空计小题。
- 未作答学生是否不计入正确率，但影响完成率。
- 待发布任务是否不计入正确率。
```

### 20.3 正确率变化

```
规则编号：RPT-CALC-003
有历史基线：正确率变化 = 当前整体正确率 − 方案前基线正确率
无历史基线：正确率变化 = 当前整体正确率 − 首次闯关正确率

变化判断：
  > +2pp → 提升X个百分点
  -2pp ~ +2pp → 基本持平
  < -2pp → 降低X个百分点

测试点：无基线时是否对比首次闯关
测试点：变化阈值是否正确
```

### 20.4 主要薄弱能力

```
规则编号：RPT-CALC-004
取数范围：本方案内已发布且有有效作答数据的词汇闯关
计算：从四个能力维度得分中取最低的一个
缺数据维度不按0分处理，不参与最低判断

测试点：缺数据维度是否正确处理
```

### 20.5 待关注学生

```
规则编号：RPT-CALC-005
判定条件（满足任一即进入）：
  1. 未完成任一已发布词汇闯关
  2. 整体正确率低于所在班级平均正确率

排序：
  1. 未完成且正确率低优先
  2. 正确率越低越靠前
  3. 未完成次数越多越靠前

多班级场景按学生所在班级平均判断

测试点：判定条件和排序是否正确
```

### 20.10 回滚词掌握变化

```
规则编号：RPT-CALC-010
展示内容：
  1. 回滚词数量
  2. 回滚词当前错误率
  3. 回滚词较前次练习的错误率变化
  4. 掌握改善词数
  5. 掌握未改善词数
  6. 样本不足提示

计算规则：
  1. 回滚词指第2份及以后练习中重复考查的前序词
  2. 单个回滚词掌握变化 = 前序练习该词错误率 − 当前回滚练习该词错误率
  3. 变化值 > 0：错误率下降，掌握改善
  4. 变化值 = 0：持平
  5. 变化值 < 0：错误率上升，掌握变差
  6. 只统计有前序基线和当前有效作答的回滚词
  7. 有效回滚词数量 < 3个：不展示整体变化值，只展示样本不足
  8. 有效回滚词数量 ≥ 3个：展示整体回滚词错误率变化
  9. 整体回滚词错误率变化 = 前序基线回滚词平均错误率 − 当前回滚词平均错误率
  10. 缺数据时展示空态，不按0计算

测试点：回滚词掌握变化展示是否正确
测试点：有效回滚词<3时是否提示样本不足
测试点：缺数据时是否不按0计算
```

### 22.7 词汇掌握口径

> 「词汇掌握」不能作为泛化文案使用，必须对应明确口径。

| 口径名称 | 定义 | 计算公式 | 缺数据处理 |
|---------|------|---------|----------|
| 单个词掌握情况 | 用该词的错误率表示 | 错误率使用平台已有错词错误率规则或平台返回值 | 无有效作答时不展示或展示「-」 |
| 班级词汇能力掌握 | 用四个词汇能力维度得分表示 | 各维度得分 = 该维度有效作答小题实际得分之和 ÷ 该维度有效作答小题满分之和 × 100；如只有对/错结果可等价为正确小题数÷有效作答小题总数×100 | 缺数据维度不按0分处理，展示空态 |
| 学生词汇掌握 | 用学生在当前范围内词汇相关错误率表示 | 学生错误率使用平台已有错词错误率规则或平台返回值 | 无有效作答时不展示或展示「-」 |
| 方案报告整体掌握 | 用整体正确率、正确率变化、主要薄弱能力表示 | 参见 RPT-CALC-002、RPT-CALC-003、RPT-CALC-004 | 无有效作答时展示空态 |

使用约束：
1. 如果页面使用「掌握率」「词汇掌握情况」「掌握水平」等文案，必须对应上述口径之一
2. 缺数据时不按0分处理，展示「暂无数据」或不参与判断
3. 同一页面内多处出现同一文案时，口径必须一致

## 26. 后台规则不展示清单

6. 教材版本的自动匹配逻辑
7. 词汇学习策略的"待完善"标记
8. 练习数量的计算公式
9. 高三 1–6 月仅推送培优版的规则

## 28. 后端/平台能力支持说明

SPEC 不定义接口字段，但开发需要知道依赖哪些平台能力。

### P0（核心数据与生成能力）

1. **词汇洞察汇总数据**：按时间范围和班级返回总结文案、关键指标和数据更新时间
2. **高频错词聚合数据**：已聚合的高频错词列表，去重规则沿用平台现有规则
3. **词汇能力得分计算**：按题型到能力维度的映射规则返回四个维度的得分
4. **学生洞察数据**：按时间范围和班级返回薄弱学生和较好学生列表
5. **词汇提升方案生成**：基于高频错词和薄弱学生数据生成方案，内部处理回滚、补题等逻辑
