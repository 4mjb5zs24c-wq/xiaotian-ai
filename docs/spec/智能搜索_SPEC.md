## 2. 术语表

| 术语 | 说明 |

| 智能匹配 | 与搜索查询最匹配的结果组，优先级最高 |

## 3. 全局上下文规则

### 规则 3.1：上下文获取

```
规则编号：CTX-001
规则说明：搜索时使用老师的当前教学上下文
上下文内容：教材版本、当前单元、年级、班级名称、地区、学生数
数据来源：老师账号信息 / 当前使用的教材和单元
```

### 规则 3.2：上下文优先级

```
规则编号：CTX-002
规则说明：老师未明确指定范围时，优先使用当前上下文
明确指定时使用指定范围
上下文不足时降级到通用匹配（不按单元过滤）
```

### 规则 3.3：上下文标注

```
规则编号：CTX-003
规则说明：匹配当前单元的搜索结果标注"当前单元"
非当前单元的标注对应单元或年级信息
```

规则编号：INT-001
规则说明：搜索查询按以下优先级匹配意图
输入条件：老师输入的自然语言查询
输出结果：识别到的意图名称或候选意图；无匹配时进入兜底

```

### 4.4 功能入口二级匹配规则

```
规则编号：INT-003
规则说明：当搜索被识别为"功能入口"类意图时，需要进一步区分具体入口
输入条件：已识别为某一类功能入口意图的查询
输出结果：一个或多个具体功能入口的推荐列表
```

当老师搜索的是平台功能而不是资源时，需要在功能入口类别内做二级匹配，决定展示哪些具体入口。

#### 答题卡相关

| 搜索词模式 | 推荐入口（按优先级） |
|-----------|-----------------|
| 三方卡、第三方答题卡 | 第三方答题卡入口 |
| 答题卡、制卡、纸质答题卡、纸质练习、快速制卡 | 答题卡制作入口 |

#### 词表相关

| 搜索词模式 | 推荐入口（按优先级） |
|-----------|-----------------|
| 词表、我的词表、单词表、词汇表（不含"导入"） | 我的词表（在前）→ 导入词表 |
| 导入词表 | 导入词表（在前）→ 我的词表 |

#### 听写/默写相关

| 搜索词模式 | 推荐入口（按优先级） |
|-----------|-----------------|
| 词句听写、句子听写、词句 | 词句听写入口 |
| 词汇听写、词汇批改 | 词汇听写入口 |
| 听写（泛指，不含"句子"） | 词汇听写入口（在前）→ 词句听写入口 |
| 篇章默写 | 篇章默写入口 |

#### 写作相关

| 搜索词模式 | 推荐内容 / 入口 |
|-----------|-----------------|
| 应用文 | 自定义应用文入口 + 应用文写作专项试卷 |
| 读后续写 / 续写 | 自定义读后续写入口 + 读后续写专项试卷 |
| 作文 / 写作 / 书面表达 | 应用文、读后续写相关入口 + 当前学段可用的写作专项试卷 |

**规则说明**：
1. 不要只写"批改入口"；
2. 应用文和读后续写既可以展示自定义入口，也可以展示写作专项中的专项试卷；
3. 如果当前学段有对应写作专项资源，应展示对应专项试卷；
4. 如果当前学段无对应写作专项资源，则展示自定义入口或兜底推荐。

#### 批改泛搜

| 搜索词模式 | 推荐入口（按优先级） |
|-----------|-----------------|
| 批改（泛指，不明确指定子类） | 展示所有批改类入口（自定义批改 / 自定义练习入口，不限于听写批改、写作批改、默写批改等） |

#### 听说相关

| 搜索词模式 | 推荐入口（按优先级） |
|-----------|-----------------|
| 听说、听说练习、口语听说 | 优先展示听说资源；如果老师没有听说资源，则展示听力资源作为替代推荐 |
| 听说专项 | 展示听说专项资源（非普通听说）；如果老师没有听说专项资源，则展示听力专项或听力练习作为替代推荐 |

**听说/听力资源替代规则**：
1. 搜索"听说/听说练习/口语听说"时：如果老师有听说资源，优先展示听说资源；如果老师没有听说资源，则展示听力资源作为替代推荐；替代推荐需要说明"当前未找到听说资源，已为你推荐听力相关资源"；
2. 搜索"听说专项"时：如果老师有听说专项资源，返回听说专项资源；如果没有听说专项资源，则展示听力专项或听力练习作为替代推荐；
3. 搜索"听力/听力练习"时：如果老师有听力资源，优先展示听力资源；如果老师没有听力资源，但有听说资源，则展示听说资源作为替代推荐；替代推荐需要标注为替代资源，不能误认为是精确听力结果；
4. 不再根据地区预先判断听说/听力；
5. 是否有听说/听力资源，以平台资源可见性和资源检索结果为准。

#### 导入试卷

| 搜索词模式 | 推荐入口（按优先级） |
|-----------|-----------------|
| 导入试卷、导入考卷、导入试题 | 导入试卷入口 → 我的试卷资源（默认展示前 10 条） → 提供"更多"入口，支持跳转到平台现有我的试卷页面 |

#### 英文单词 → 讲词入口

| 搜索词模式 | 推荐入口（按优先级） |
|-----------|-----------------|
| 英文单词或英文单词组合（如 restaurant、apple banana 等） | 推荐"讲词/单词教学"入口，同时保留词汇资源相关结果；不限制只能输入一个英文词，多个英文词也按词汇查询处理 |

#### 无命中（default）

当功能入口意图已识别但无法进一步匹配具体子类时，展示全部可用功能入口（按功能分类排序）。

**要求**：
1. 二级匹配只写中文业务名称，不涉及技术实现字段；
2. 如果与 §4 意图优先级冲突，以意图优先级为准；
3. 同一搜索词命中多个入口时，按上述优先级排序展示。

测试点：搜索"三方卡"是否正确展示第三方答题卡入口
测试点：搜索"导入词表"是否导入词表入口排在"我的词表"之前
测试点：搜索"听写"是否正确展示词汇听写+词句听写
测试点：搜索"restaurant"是否正确推荐讲词入口和词汇资源

## 5. 搜索输入处理规则

### 规则 5.1：语义有意义性检查

```
规则编号：INP-001
规则说明：输入需通过语义有意义性检查
输入条件：老师的查询文本
检查方式：
  - 匹配意图关键词
  - 特殊处理：纯英文单词（≥2个字母）视为"词汇"意图
  - 特殊处理：Unit N / 第N单元 视为"单元"意图
  - 特殊处理："有没有/帮我找/有什么/找...资源/看看/搜索" 视为辅助搜索意图
输出结果：true（可识别）/ false（不可识别，进入兜底）
```

### 规则 5.2：空输入处理

```
规则编号：INP-002
规则说明：空查询不触发搜索
输入条件：trim 后为空字符串
输出结果：不执行搜索，保持当前页面状态
```

### 规则 5.3：意图标签推导

```
规则编号：INP-003
规则说明：从查询中推导用于 Loading 文案的意图标签
输入条件：老师的查询文本
输出结果：匹配到的意图标签，或截断后返回原查询的前10个字
```

### 规则 5.4：查询文本预处理

```
规则编号：INP-004
规则说明：在意图识别前，系统先对用户输入做基础预处理

处理内容：
  1. 去除首尾空格
  2. 统一中英文大小写
  3. 统一常见空格形式
  4. 保留中文、英文、数字和常见教学表达
  5. Unit 表达标准化：Unit3 / unit 3 / U3 / u3 / 第三单元 / 第3单元 等可归一到单元意图

测试点：Unit3 / unit 3 / U3 / u3 等变体是否均能识别为单元意图
```

### 规则 5.5：别名与简称识别

```
规则编号：INP-005
规则说明：同一功能或资源存在多个老师常用说法时，需要归一到同一个搜索意图

示例映射：

| 输入表达 | 归一化目标 |
|---------|----------|
| 答题纸 / 制卡 / 批卡 / 扫卡 / 三方卡 | 答题卡 |
| 单词表 / 词表 / 生词表 | 我的词表 / 词汇 |
| 作文 / 写作 / 书面表达 | 写作 |
| 读后续写 / 续写 | 写作-读后续写 |
| 报告 / 练习报告 / 学情 / 完成率 / 未完成 | 本期不作为智能搜索意图；不触发报告跳转；按通用兜底处理，可提示使用平台原有报告入口 |
| 错题 / 错题本 / 错词 / 错词本 | 错题/错词相关 |
| 听默 / 默写 / 听写 / 默单词 | 听写/默写 |
| 卷子 / 试卷 / 套卷 | 试卷/套题 |

测试点：每个别名输入是否映射到正确的归一化目标
```

### 规则 5.6：常见错别字与近音字识别

```
规则编号：INP-006
规则说明：对高频功能词和核心资源词，需要维护常见错别字、近音字、输入误差的归一化规则

示例映射：

| 用户输入 | 识别目标 | 备注 |
|---------|---------|------|
| 答题咔 | 答题卡 | 近音字/错别字 |
| 达题卡 | 答题卡 | 近音字/错别字 |
| 听谢 | 听写 | 近音字/错别字 |
| 连习报告 | 本期不作为智能搜索意图 | 错别字，不触发报告跳转 |
| 词会 / 词灰 | 词汇 | 近音字/错别字 |
| 做文 | 作文 | 错别字 |
| 备棵 | 备课 | 近音字/错别字 |

要求：
  1. 优先覆盖高频功能和核心资源
  2. 不需要覆盖所有汉字错别字
  3. 无法高置信识别时，不要强行匹配，进入兜底或推荐
  4. demo 阶段可用 mock 词典维护
  5. 正式版本建议结合历史搜索日志持续补充

测试点：每个错别字/近音字输入是否映射到正确的识别目标
```

### 规则 5.7：归一化后的意图优先级

```
规则编号：INP-007
规则说明：归一化只负责把用户输入映射到候选意图，不直接决定最终展示结果
最终意图仍按「意图识别优先级」（§4）执行

示例：
  1. "试卷答题咔" 先归一化为 "试卷答题卡"
  2. 命中"答题卡"和"试卷"两个候选
  3. 按优先级识别为"答题卡"

测试点："试卷答题咔"是否最终识别为答题卡而非试卷
```

### 规则 5.8：低置信度处理

```
规则编号：INP-008
规则说明：当输入存在错别字但无法明确判断目标时，不要强行命中某个功能

处理方式：
  1. 展示兜底推荐
  2. 或展示多个可能相关入口

### 规则 5.9：Unit + 资源类型组合

```
规则编号：INP-009
规则说明：当搜索词明确包含 Unit/单元编号时，结合资源类型关键词匹配对应资源
输入条件：包含 "Unit N" / "unit N" / "U + 数字" / "u + 数字" / "第N单元" 等单元变体的查询
```

#### 单元编号识别

系统从搜索词中提取单元编号：
- `Unit 3`、`unit 3`、`U3`、`u3` → 识别为单元 3
- `第3单元`、`第三单元` → 识别为单元 3
- 单元编号可以是数字 1-N

#### 单元 + 资源类型组合规则

老师明确指定单元时，优先使用指定单元（覆盖当前教学上下文）。

| 搜索词模式 | 处理规则 |
|-----------|---------|
| Unit N + 听力/听说 | 返回指定单元的听力/听说资源 |
| Unit N + 词汇/单词/词表 | 返回指定单元的词汇资源 |
| Unit N + 课文 | 返回指定单元的课文资源 |
| Unit N + 作文/写作 | 返回指定单元的写作相关资源 |
| Unit N + 阅读 | 返回指定单元的阅读资源 |
| Unit N + 语法 | 返回指定单元的语法资源 |
| Unit N + 模拟/检测/测试/考试 | 返回指定单元的模拟/检测资源 |
| Unit N + 真题 | 返回指定单元关联的真题资源 |
| Unit N + 专项 | 返回指定单元的专项资源 |
| Unit N + 练习/资源/综合 | 返回指定单元的综合资源 |
| 仅 Unit N（无资源类型关键词） | 返回指定单元的综合资源或单元资源总览 |

#### 单元判定规则

1. 用户明确指定 Unit 时，优先使用用户指定的单元；
2. 用户未指定 Unit 但指定了资源类型（如"听力练习"），使用当前上下文单元；
3. 用户指定 Unit + 资源类型时，两者结合匹配；
4. 指定单元无对应资源时，降级到替代推荐（参见 FAL-002）。

#### 与意图优先级的关系

当搜索词同时包含 Unit 编号和意图关键词时：
- 先通过意图优先级识别资源类型
- 再叠加单元编号进行精准匹配
- 例如 "Unit 3 听力专项" → 意图为"专项资源"（优先级高于"听力"），叠加 Unit 3 过滤

测试点：搜索"Unit 3 听力"是否正确返回 Unit 3 听力资源
测试点：搜索"U3 词汇"是否正确识别单元编号
测试点：搜索"第三单元 写作"是否正确返回对应单元写作资源
测试点：指定单元无资源时是否正确展示替代推荐
测试点：指定单元搜索是否覆盖当前上下文单元

### 规则 5.10：搜索结果统一展示规则（RES-001）

```
规则编号：RES-001
规则说明：无论老师从哪个入口发起搜索，搜索完成后的结果展示规则必须统一
适用入口：首页输入框、搜索全屏页输入框、引导卡、历史搜索记录、兜底建议标签、其他触发智能搜索的入口
```

**统一规则**：

1. 所有入口提交搜索后，必须走同一套智能搜索意图识别、资源匹配、排序、分组和兜底规则；
2. 同一搜索词在不同入口得到的意图识别结果、资源排序、结果分组必须一致；
3. 不允许首页搜索结果使用一套简化结果页，搜索全屏页使用另一套完整结果页；
4. 首页输入搜索后，跳转到搜索全屏页 / 独立搜索结果页，并自动执行搜索（携带搜索词和自动搜索标识）；
5. 搜索结果统一包含：搜索理解文案、智能匹配区、推荐关联区、分类筛选、资源卡片操作、兜底或替代推荐、历史记录更新；
6. 如果某个入口为了空间限制只展示简化摘要，也必须提供「查看完整结果」入口，且不能替代正式搜索结果页；
7. 如果结果为空，统一使用 FAL-001 兜底规则；
8. 如果命中精准跳转，统一使用 JMP-001 精准跳转卡规则；
9. 如果命中听写，统一使用 DIC-001 听写排序规则；
10. 本期 demo 中首页搜索后直接展示完整智能搜索结果，不单独做简化版搜索结果页。

**禁止行为**：

1. 不允许首页搜索后只展示两个入口卡片；
2. 不允许首页搜索使用独立的简化搜索逻辑；
3. 不允许跳过智能匹配区 / 推荐关联区；
4. 不允许只返回功能入口而不展示关联资源；
5. 不允许结果排序和文档规则不一致。

测试点：首页输入"听写"后，结果是否与搜索全屏页输入"听写"一致
测试点：首页输入"作文"后，结果是否与搜索全屏页输入"作文"一致
测试点：同一搜索词通过首页、搜索页、历史记录、建议标签触发时，结果是否一致
测试点：首页搜索后是否跳转到完整搜索结果页（不打开抽屉/弹层）
测试点：首页搜索结果是否包含搜索理解文案、智能匹配区、推荐关联区、分类筛选

## 12.8 卷库标签命中搜索规则

```
规则编号：TAG-001
规则说明：如果老师输入的内容命中了卷库标签，则推送该标签下的资源
卷库标签命中搜索是独立于关键词搜索的资源召回方式
```

### 12.8.1 标签命中规则

1. 老师输入内容如果命中卷库标签，应返回该标签下的资源；
2. 卷库标签包括平台卷库中已配置的标签，例如题型、资源类型、考试类型、地区、年级、专题、专项、同步、模拟、真题等，具体标签范围以平台卷库配置为准；
3. 标签命中可以作为普通关键词搜索之外的资源召回方式；
4. 标签精确命中时，标签下资源可进入智能匹配区；
5. 标签部分命中或弱命中时，标签下资源进入推荐关联区；
6. 如果同时命中多个标签，应按意图优先级、标签匹配度和资源相关性综合排序；
7. 如果标签下无资源，进入无结果替代推荐或兜底；
8. 不要把卷库标签写成固定前端枚举，正式范围以平台卷库标签配置为准。

### 12.8.2 标签命中示例

| 老师输入 | 命中标签 | 处理 |

| 语法填空 | 语法填空 / 题型 | 返回该题型标签下资源 |

### 12.8.3 与意图识别的关系

1. 卷库标签命中不作为独立的意图类型，而是作为资源召回的补充方式；
2. 标签命中的资源与意图识别结果合并后，按搜索排序规则（§20.2）统一排序；
3. 标签精确命中时，标签下资源可进入智能匹配区；
4. 标签部分命中或弱命中时，标签下资源进入推荐关联区；
5. 标签命中不改变原有意图识别优先级规则（§4）。

### 规则 16.2：无结果替代推荐层级

```
规则编号：FAL-002
规则说明：当有教学上下文但精确资源为空时，按层级展示替代推荐
触发条件：
  - 搜索词可识别为有效资源意图
  - 但当前范围内无精确匹配的资源
  - 不等同于"完全无法识别"（后者走 FAL-001 的兜底建议标签）
```

替代推荐按以下层级展示：

| 层级 | 推荐类型 | 展示规则 | 说明 |
|------|---------|---------|------|
| 第 1 层 | 当前单元可替代资源 | 默认展开 | 当前单元内的关联资源（综合练习、词汇练习、阅读练习等），虽然不是精确匹配但仍在当前单元范围内 |

| 第 3 层 | 非当前单元相关资源 | 默认折叠 | 其他单元或年级的相关资源，必须标注单元或年级信息，避免老师误以为是当前单元资源 |
| 第 4 层 | 常用功能入口和搜索建议标签 | 始终展示 | 提供功能入口和搜索建议，供老师快速跳转或重新搜索 |

1. 当前单元替代资源优先展示；
2. 同年级资源作为补充；
3. 非当前单元资源必须标注单元或年级信息，避免老师误以为是当前单元；
4. 完全无法识别时（FAL-001）仍走现有兜底建议标签，不强行展示资源结果；
5. 替代推荐不替代精确匹配结果，精确匹配为空时才使用；
6. 替代推荐中的资源同样遵循资源可见性规则（参见 §28）。
7. 4 层替代推荐均为空时（即当前单元、同年级、非当前单元均无可替代资源），降级到 FAL-001 兜底展示（搜索建议标签 + 常用功能入口），不强行展示资源结果。

### 20.1 搜索结果数量

## 28. 权限与资源可见性规则

```
规则编号：PERM-001
规则说明：搜索结果需要按老师的可见范围过滤
正式环境中，不是所有平台资源对每位老师都可见
```

### 28.1 过滤维度

| 过滤维度 | 说明 | Demo 阶段 | 正式阶段 |
|---------|------|----------|---------|
| 教师账号 | 老师只能访问自己有权限的资源 | 不区分 | 按教师账号过滤 |
| 学校资源授权 | 学校购买版权的资源才可见 | 不区分 | 按学校授权过滤 |
| 地区限定 | 地区限定资源需按老师所在地区展示 | 不区分 | 按地区过滤 |
| 教材版本 | 按老师当前使用的教材版本匹配资源 | 固定上下文 | 按教材版本过滤 |
| 年级 | 按老师当前教授的年级匹配资源 | 固定上下文 | 按年级过滤 |
| 班级 | 班级维度的数据隔离 | 单班级 | 按班级隔离 |
| 资源上下架状态 | 已下架资源不展示或标注不可用 | 不区分 | 按状态过滤 |
| 资源可布置/可预览状态 | 不可布置/不可预览的资源按状态展示对应操作按钮 | mock 数据 | 按资源属性展示 |

### 28.2 可见性规则

```
规则编号：PERM-002
规则说明：资源可见性按以下规则处理
```

1. **无权限资源**：不展示。老师账号无权限的资源在搜索结果中不出现。
2. **已下架资源**：不展示。如平台支持展示不可用状态，可展示但标注不可用，且隐藏操作按钮。
3. **地区限定资源**：按老师所在地区展示。非老师所在地区的限定资源不出现。
4. **班级隔离资源**：按当前选中的班级展示。其他班级的数据不出现。
5. **教材版本不匹配资源**：不优先展示。与当前教材版本不匹配的资源可降级到推荐关联区，或标注版本信息。

### 28.3 平台能力依赖

```
规则编号：PERM-003
规则说明：权限过滤依赖平台能力
```

1. 权限与资源可见性规则依赖平台的账号、授权和资源管理系统；
2. 如果平台权限能力暂未接入，搜索结果不做前端自行判断的权限过滤；
3. 权限过滤的具体实现由后端和平台团队负责；
4. Demo 阶段可使用全量 mock 数据，不按权限过滤；
5. 正式阶段必须接入平台权限能力；
6. 本文档定义的是业务规则，不是技术实现方式。

| 当前上下文 | 固定上下文（人教版·七年级上·Unit 3） | 老师可切换教材/年级/班级 |
