## 首页智能搜索 — 版本记录

### v1.0（当前稳定基线）

- **基准日期**：2026-06-16
- **文档**：[`v1.0/06_AI搜索与智能助手资源匹配规则说明.md`](./v1.0/06_AI搜索与智能助手资源匹配规则说明.md)
- **代码位置**：
  - 搜索引擎：`src/ai/search-new/searchEngine.ts`
  - 类型定义：`src/ai/search-new/types.ts`
  - 场景工厂：`src/ai/search-new/mock/scenarios/`
  - UI 组件：`src/ai/components/search-new/`（15 个组件）
  - 页面入口：`src/pages/SearchPage.tsx`
  - 路由：`/ai-search`（App.tsx 中定义）

#### v1.0 主要能力

**1. 双态布局**
- 首页态：上下文条 + 搜索卡片（"小天智能助手"）+ 4 个快捷入口 + 近期使用标签
- 搜索结果态：上下文条 + 精简搜索栏 + 意图说明条 + 筛选标签 + 结果分组列表
- 状态切换：执行搜索 → 结果态；清空搜索词 → 首页态

**2. 搜索入口**
- 首页搜索框（首页右侧「小天AI智能助手」卡片）
- AI 搜索页（`/ai-search` 路由）
- 首页「小天AI」按钮（顶部栏右侧）
- 4 个快捷入口点击（当前单元资源/同步词汇/听力练习/快速制卡）
- 近期使用标签点击
- URL 参数自动搜索（`?query=xxx&autoRun=1`）

**3. 意图识别与路由（8 级优先级）**

| 优先级 | 场景 | 说明 |
|:--:|------|------|
| 1 | 功能入口关键词 | 答题卡/词表/听写/批改/导入/讲词/自定义 |
| 2 | 试卷名称精确搜索 | 省份+年份+考试类型解析，精确/相近两级匹配 |
| 3 | 同步词汇搜索 | 触发词：同步词汇/词汇表/单词表/课标词汇 |
| 4 | 同步课文搜索 | 触发词：同步课文/课文内容/课文原文/课文跟读 |
| 5 | 资源类型搜索（12 子优先级） | 5a 写作→5b 词汇→5c 语法→5d 阅读→5e 听力模拟→5f 听力→5g 听说→5h 同步练习→5i 真题→5j 专项→5k 模拟→5l 配音 |
| 6 | Unit N + 资源类型组合 | 识别 Unit 编号+资源类型关键词 |
| 7 | 模糊/默认/对话式查询 | "有没有"/"帮我找"/中文短词 2-4 字 |
| 8 | 完全无法识别 | 返回 3 个快捷入口建议 |

**4. 上下文感知**
- 自动感知教师当前教材版本、单元、年级、班级
- 搜索结果优先匹配当前教学上下文
- 用户显式指定优先级高于当前上下文
- 试卷名称搜索不受教学上下文限制

**5. 资源卡片与动作**
- 资源卡片：标题/标签/元数据行/推荐理由条/操作按钮行
- 支持动作：预览/布置/加入试卷篮/加入备课
- 功能入口卡片：「立即进入」跳转到功能页面

**6. 同步词汇/课文特殊交互**
- 结构化词汇表：课标词/非课标词/语块三区，支持全选/部分选择
- 6 种词汇练习形式：口语跟读/看英选中/单词默写/看中选英/单词听写/听音识词
- 课文层级树：Section→Passage，支持逐句跟读/整篇跟读/整篇背诵
- 生成练习：选中内容 × 练习形式 → 生成作业草稿

**7. 搜索异常处理**
- 搜索无结果：3 层替代推荐（当前单元/同年级/非当前单元）
- 结果过多（>50 条）：分组折叠+筛选收敛，无传统分页
- 完全无法识别：快捷入口引导

**8. 试卷篮**
- Demo 阶段本地存储
- 支持去重、数量角标、面板查看

**9. 技术实现方式**
- 规则引擎匹配（关键词正则匹配+优先级路由）
- 本地 mock 数据（20+ 预设搜索场景）
- Demo 阶段不接入真实大模型

#### v1.0 限制说明

- 不支持口语化表达、简称、近义词、错别字（仅精确关键词匹配）
- 不支持资源名称模糊匹配（仅试卷名称支持省份+年份+考试类型解析）
- 不支持地区词匹配（仅听说场景有简单地区检查）
- 不支持"已识别但当前入口不承接"的精准跳转（如报告/错题本）
- 无法识别时仅展示 3 个快捷入口，无"搜索建议词"或"常用功能推荐"
- 搜索结果仅一个分组维度，无"智能匹配推荐/智能关联推荐"双分组
- 搜索 Loading 为简单状态，无 AI 思考感文案
- 不支持套题意图、微技能意图、选题组卷意图等细分场景
- 部分场景覆盖不完整（如"答题卡"仅匹配制作入口，未关联"我的答题卡"列表）

### v1.1（规划中）

- **规则文档**：[`xiaotian-smart-search-v1.1-rules.md`](./xiaotian-smart-search-v1.1-rules.md)
- **定位**：在 v1.0 规则引擎基础上增强，不重做搜索系统

  2. 我的内容推荐：我的答题卡、我的词表、我的试卷
  3. 资源名称匹配：试卷名称、课本名称、章节名称等
  4. 地区词匹配：区域精选资源召回
  5. 精准跳转：报告/错题本/备课等"已识别但不承接"场景
  6. 双分组结构：智能匹配推荐 + 智能关联推荐
  7. AI 理解文案与 Loading：搜索过程包装为 AI 思考感
  8. 兜底增强：搜索建议词 + 常用功能推荐组合

## 词汇洞察与复习方案 — 版本记录

### v1.0（当前稳定基线）

- **基准日期**：2026-06-16
- **文档**：[`v1.0/04_词汇洞察与复习方案规则口径说明.md`](./v1.0/04_词汇洞察与复习方案规则口径说明.md)
- **代码位置**：
  - 洞察组件：`src/ai/components/vocabulary-insight/`
  - 页面入口：`src/pages/VocabularyInsightPage.tsx`
  - 路由：`/vocabulary-insight`
  - 复习方案弹窗：`ReviewPlanWizard.tsx`
  - 草稿篮面板：`DraftBasketPanel.tsx`

#### v1.0 主要能力

1. **首页词汇洞察卡片**：单张完整宽度卡片，展示洞察结论+数据依据+风险提示
2. **词汇洞察详情页**：诊断总览/高频错词工作台/错误类型洞察/学生洞察/干预记录
3. **复习草稿篮**：跨页面收集词汇，7 天保留期，发布后自动清理
4. **复习方案生成**：5 种复习目标，多天连续复习计划，题型按归因推荐
5. **动态回滚**：后续复习日根据前日错词数据自动生成回滚题
6. **练习报告集成**：复习计划作为聚合卡片混入练习报告列表
7. **数据概览**：覆盖词汇/累计完成率/词汇掌握率提升/回滚题正确率
