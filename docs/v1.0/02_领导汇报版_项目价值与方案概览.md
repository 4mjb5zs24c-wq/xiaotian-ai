## 1. 项目一句话目标

**为英语教师建设一套从"数据洞察 → 诊断归因 → 复习干预 → 效果跟踪"的 AI 教学闭环，让老师从繁重的数据分析中解放出来，专注教学本身。**

---

## 2. 当前问题

### 问题 1：资源查找效率低

教师每天需要花大量时间查找合适的教学资源。当前平台资源分布在多个模块，教师需要：

- 记住每个功能的入口路径
- 手动比对资源是否匹配当前教学进度
- 逐个判断资源是否适合班级水平

**影响**：备课效率低，一线教师反馈"找资源比备课还累"。

### 问题 2：学情分析靠人脑

练习完成后，平台产生大量词汇错误数据，但教师需要：

- 手动翻阅练习报告才能了解整体情况
- 自己归纳"哪些词错得多"
- 自己判断"为什么错"
- 自己设计复习方案

**影响**：数据分析工作量大，教师往往放弃深入分析，导致错词持续累积。

### 问题 3：洞察与行动割裂

即使教师发现了问题，从"发现"到"行动"仍有很长距离：

- 需要从洞察回到其他模块手动布置练习
- 无法系统化地制定多天连续复习计划
- 缺乏动态回滚机制，学过的词反复出错

**影响**："发现问题"但"来不及解决问题"。

---

## 3. 解决方案

### 3.1 小天智能助手：统一搜索入口

一个搜索框解决资源查找问题：

```
教师输入"听力练习"
    ↓
系统理解上下文（人教版 · Unit 3 · 2023级A18班）
    ↓
返回 Unit 3 相关听力资源（而非无关的 Unit 1 内容）
    ↓
教师一键预览 / 布置 / 加入备课
```

### 3.2 词汇洞察：系统化学情分析

从数据到洞察的自动化：

```
2117 条词汇错误记录
    ↓
系统自动分析
    ↓
"2023级A18班不会写类错误较集中"
识别出 50 个高频错词、27 名薄弱学生
    ↓
一键生成复习方案
```

### 3.3 复习方案生成：从洞察到行动

一键自动生成多天连续复习计划：

| 教师操作 | 系统自动完成 |
|------|------|
| 选择复习目标 | 自动筛选词表 |
| 设置周期和题量 | 自动生成 Day 任务 |
| 确认发布 | 自动计算时间、回滚规则 |
| 查看报告 | 自动跟踪掌握率变化 |

## 4. 核心价值

### 4.1 对教师的价值

| 价值点 | 具体表现 |
|------|------|
| **省时间** | 资源查找从 5-10 分钟缩短为 10 秒 |
| **省心** | 自动归因分析 + 智能推荐 |
| **省力** | 一键生成多天复习计划，不需要手动逐条布置 |
| **有效果** | 动态回滚机制持续巩固薄弱词 |

| 价值点 | 具体表现 |
|------|------|
| **增强粘性** | 教师从"用平台布置作业"变为"依赖平台做学情分析" |
| **提升体验** | 统一的搜索 + 洞察入口降低学习成本 |
| **差异化** | 连续复习计划 + 动态回滚是竞品较少覆盖的能力 |

## 5. 一期交付内容

### 5.1 功能全景

```
小天智能助手
├── AI 搜索页（首页态 + 搜索结果态）
│   ├── 上下文感知的资源搜索
│   ├── 快捷入口（单元资源/词汇/听力/制卡）
│   └── 资源卡操作（预览/布置/加入试卷篮）
│
├── 词汇洞察页
│   ├── 诊断总览（指标 + 推荐动作）
│   ├── 高频错词工作台（左列表 + 右详情）
│   ├── 错误类型分析（4 类归因）
│   ├── 学生洞察（薄弱/掌握较好）
│   └── 复习草稿篮（跨页面词汇收集）
│
├── 词汇复习方案
│   ├── 通用入口（4 步：目标→词表→设置→预览）
│   ├── 草稿篮入口（3 步：周期→题量→预览）
│   ├── 5 种复习目标 + 自定义
│   ├── 动态回滚规则
│   └── 发布到练习报告列表
│
└── 练习报告列表
    ├── 复习计划聚合卡片
    ├── Day 子任务展开
    └── 数据概览弹层
```

### 5.2 一期技术方案

- **前端**：React 19 + TypeScript + Tailwind CSS v4
- **数据**：一期使用浏览器本地存储模拟持久化，规则引擎模拟 AI 逻辑
- **不接入**：真实 LLM 大模型、真实后端 API
- **意图**：验证业务流程 + 交互方案 + 规则合理性

## 8. 汇报话术

### 8.1 一句话版本

"我们为英语老师做了一个 AI 助教，它能自动分析班级错词、告诉老师问题在哪、还能一键生成一系列复习任务，老师只需要确认和发布。"

### 8.2 30 秒电梯演讲

"英语老师最头疼两件事：找资源和分析学情。小天智能助手用一个搜索框解决了资源查找问题，用词汇洞察页解决了学情分析问题。最关键的是，从洞察到行动只需要点一下——系统自动生成多天连续复习方案，包含动态回滚机制，确保学生真正掌握薄弱词汇。一期已经在 demo 上跑通了完整闭环。"

### 8.3 5 分钟详细汇报

**（问题切入）**
各位领导，我们在和一线英语老师沟通中发现一个共性问题：老师每天花大量时间找资源和分析数据，但这些时间本应该花在教学上。

**（方案展示）**
我们做了三件事：

第一，统一搜索入口。老师不管找听力、词汇、课文还是试卷，都在一个搜索框完成。系统会自动识别老师当前在教哪个单元、哪个班级，优先返回匹配的资源。

第二，词汇洞察。系统自动分析班级的词汇练习数据，告诉老师：哪些词错得多、为什么错、影响了多少学生。不用老师自己翻报告。

第三，一键生成复习方案。老师确认词表后，系统自动生成多天连续复习计划——Day 1 主复习、Day 3 巩固回滚、Day 5 收口。整个过程老师只需要确认，不需要手动逐条布置任务。

**（价值总结）**
这个闭环把老师的"数据分析 + 方案设计"时间从约 60 分钟压缩到约 5 分钟，效率提升 10 倍以上。

**（后续规划）**
一期先在 demo 上验证交互和规则。二期计划接入真实大模型和后端 API，扩展到听力和写作的洞察分析。
