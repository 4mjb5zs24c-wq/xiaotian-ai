## 1. AI 搜索入口与触发方式

### 1.1 入口位置

| 入口 | 位置 | 触发方式 |
|------|------|------|
| 首页搜索框 | 首页右侧「小天AI智能助手」卡片 | 输入文本 → 回车 或 点击发送 |
| AI 搜索页 | `/ai-search` 路由 | 直接打开页面 → 输入搜索 |
| 首页「小天AI」按钮 | 顶部栏右侧蓝色按钮 | 跳转到 `/ai-search` |
| 快捷入口点击 | AI 搜索页首页态 4 个入口卡片 | 点击快捷入口 → 自动搜索 |
| 近期使用点击 | AI 搜索页首页态 chip 标签 | 点击标签 → 自动搜索 |
| 外部链接跳转 | `?query=xxx&autoRun=1` URL 参数 | 页面加载时自动执行搜索 |

### 1.2 搜索触发时机

1. **用户主动触发**：
   - 在搜索框中按 `Enter`
   - 点击搜索框右侧「搜索」按钮
2. **快捷入口自动触发**：
   - 点击首页态任一快捷入口卡片 → 自动填入搜索词并执行搜索
3. **近期使用自动触发**：
   - 点击近期使用任一 chip 标签 → 自动填入搜索词并执行搜索
4. **URL 参数自动触发**：
   - 如果 URL 包含 `?query=xxx&autoRun=1`，页面加载后自动搜索

### 1.3 双态布局

| 状态 | 判定条件 | 展示内容 |
|------|------|------|
| **首页态** | `query` 为空 且 无搜索结果 | 上下文条 + 完整搜索卡片 + 4 快捷入口 + 近期使用 |
| **搜索结果态** | 执行搜索后，有搜索结果 | 上下文条 + 精简搜索栏 + 意图说明 + 筛选标签 + 结果列表 |

**状态切换规则**：
- 执行搜索 → 从首页态切换到结果态
- 清空搜索词 → 从结果态回到首页态
- 点击快捷入口/近期使用 → 自动填入搜索词 → 切换到结果态

## 2. 用户意图分类体系

### 2.1 搜索类型枚举

| 类型 | 编码 | 说明 | 典型 query |
|------|------|------|------|
| 资源搜索 | `resource` | 查找教材相关的词汇、听力、课文、练习等资源 | "听力练习"、"Unit 3 词汇" |
| 试卷名称搜索 | `paper_name` | 按省份、年份、考试类型查找试卷 | "山东省2024年中考英语真题" |
| 功能入口搜索 | `function_entry` | 查找平台功能入口 | "答题卡"、"听写"、"批改" |
| 无法识别 | `unknown` | 完全无法匹配的查询 | 无意义文本、纯数字、单字符 |

### 2.2 意图识别流程

```
用户输入 query
    ↓
预处理：trim → 空检查 → 无意义检查（纯数字/特殊字符/单字符）
    ↓
按优先级依次匹配（8 层路由）
    ↓
匹配成功 → 分发到对应场景工厂
    ↓
场景工厂生成 NewSearchResult
  - intent（意图说明，含 message/context）
  - filterTabs（筛选标签）
  - resourceGroups（资源分组）
  - functionEntries（功能入口）
  - alternatives（替代推荐，仅无结果时）
  - quickEntries（快捷入口，仅无法识别时）
    ↓
返回给前端渲染
```

### 2.3 意图信息结构

每次搜索返回的结构化意图信息包括：

| 字段 | 说明 | 示例 |
|------|------|------|
| 原始搜索词 | 用户输入的完整 query | "听力练习" |
| 识别意图名称 | 系统归类后的意图标签 | "听力资源搜索" |
| 搜索类型 | resource / paper_name / function_entry / unknown | resource |
| 上下文描述 | 当前教材、年级、单元、班级的可读文案 | "人教版｜七年级上｜Unit 3" |
| 匹配资源类型 | 命中哪些资源类别 | ["sync_listening", "listening_practice"] |
| 默认展开类型 | 哪些类别默认展开给用户看 | ["sync_listening"] |
| 默认折叠类型 | 哪些类别默认折叠 | ["listening_mock"] |
| 意图说明文案 | 展示给用户的一句话说明 | "已为你找到 Unit 3 相关听力资源" |

## 3. 上下文识别规则

### 3.1 上下文来源

搜索上下文来自教师的当前教学环境，包含以下信息：

| 上下文信息 | 说明 | 示例 |
|------|------|------|
| 教材版本 | 教师当前使用的教材 | "人教版" |
| 当前单元 | 教师当前教学进度所在的单元 | "Unit 3 — Food and Drinks" |
| 年级 | 教师当前教授的年级 | "七年级上" |
| 班级 | 当前查看的班级 | "2023级A18班" |
| 地区标识 | 教师所在地区（影响部分资源可用性） | "default" |
| 学生数 | 班级学生总数 | 42 |

### 3.2 上下文使用方式

| 使用场景 | 使用方式 |
|------|------|
| 意图文案生成 | 将上下文格式化为可读文案 `"人教版｜七年级上｜Unit 3 — Food and Drinks｜2023级A18班"` |
| 单元号提取 | 从 `unit` 字段提取 `"Unit 3"` 用于匹配对应的教材资源 |
| 资源筛选 | 按当前单元选择正确的资源集（如 Unit 3 听力资源 vs Unit 1 听力资源） |
| 词汇数据选择 | 按单元选择对应的词汇表数据（如 `MOCK_VOCAB_UNIT_3` vs `MOCK_VOCAB_UNIT_1`） |
| 专项资源匹配 | 按年级匹配专项练习资源 |

### 3.3 上下文优先级

1. **用户显式指定**：如果用户在搜索词中明确指定了单元/教材/年级，以用户输入为准
   - 例如：搜索"Unit 1 听力练习"，即使当前上下文是 Unit 3，也返回 Unit 1 结果
2. **当前上下文优先**：用户未显式指定时，使用当前上下文匹配
   - 例如：搜索"听力练习"，当前上下文是 Unit 3，返回 Unit 3 结果
3. **试卷搜索例外**：试卷名称搜索不受教学上下文限制
   - 例如：搜索"山东省2024年中考英语真题"，不受当前教材版本影响

## 4. 资源匹配规则 — 完整路由优先级

### 4.1 路由总览（8 层优先级）

```
用户输入 query（已做归一化处理）
    ↓
┌─ Priority 1: 功能入口关键词 ──────────────────────────┐
│  匹配平台功能入口（答题卡/词表/听写/批改/导入/讲词） │
│  关键词命中的 query 直接路由到 function_entry           │
│  → 在 scenarioFunctionEntry 内做二次精细匹配           │
└──────────────────────────────────────────────────────┘
    ↓ 未匹配
┌─ Priority 2: 试卷名称精确搜索 ────────────────────────┐
│  解析省份 + 年份 + 考试类型                             │
│  精确匹配 → paper_exact   │  相近匹配 → paper_near     │
└──────────────────────────────────────────────────────┘
    ↓ 未匹配
┌─ Priority 3: 同步词汇搜索 ────────────────────────────┐
│  触发词：同步词汇 / 词汇表 / 单词表 / 课标词汇         │
│  返回：按当前单元的结构化词汇表（含全选/部分选择）      │
└──────────────────────────────────────────────────────┘
    ↓ 未匹配
┌─ Priority 4: 同步课文搜索 ────────────────────────────┐
│  触发词：同步课文 / 课文内容 / 课文原文 / 课文跟读     │
│  含 topic/话题 → 扁平结构 │ 不含 → Section 层级结构    │
└──────────────────────────────────────────────────────┘
    ↓ 未匹配
┌─ Priority 5: 资源类型搜索（12 个子优先级 5a-5l）──────┐
│  5a 写作 │ 5b 词汇 │ 5c 语法 │ 5d 阅读                  │
│  5e 听力模拟(优先于后续)                                │
│  5f 听力(排除听说) │ 5g 听说(含地区检查)                │
│  5h 同步练习 │ 5i 真题 │ 5j 专项                        │
│  5k 模拟(排除听力模拟) │ 5l 配音                        │
└──────────────────────────────────────────────────────┘
    ↓ 未匹配
┌─ Priority 6: Unit N + 资源类型组合 ───────────────────┐
│  识别 Unit 编号 + 资源类型关键词                        │
│  无类型关键词 → unit1_comprehensive（综合）             │
│  纯"资源/综合/练习" → unit1_comprehensive               │
└──────────────────────────────────────────────────────┘
    ↓ 未匹配
┌─ Priority 7: 模糊/默认/对话式查询 ────────────────────┐
│  "有没有" / "帮我找" / 中文短词 2-4 字                  │
│  → unit1_comprehensive                                 │
└──────────────────────────────────────────────────────┘
    ↓ 未匹配
┌─ Priority 8: 完全无法识别 ────────────────────────────┐
│  返回 3 个快捷入口建议                                  │
│  isUnrecognizable = true, isNoResults = true            │
└──────────────────────────────────────────────────────┘
```

### 4.2 详细匹配规则表

#### Priority 1：功能入口关键词

| 正则模式 | 匹配示例 | 分发场景 |
|------|------|------|
| `/三方卡\|答题卡\|纸质答题卡\|纸质练习\|新建答题卡\|自制答题卡\|制卡/` | "答题卡"、"纸质答题卡"、"快速制卡" | `function_entry` |
| `/词表\|词单/` | "词表"、"我的词表"（不含"导入"） | `wordlist` |
| `/导入词表/` | "导入词表" | `wordlist -> [func-import-wordlist, func-my-wordlist]` |
| `/听写\|默写批改\|词句\|句子听写/` | "听写"、"词汇听写"、"词句听写" | `function_entry` |
| `/批改\|篇章默写/` | "批改"、"篇章默写" | `function_entry` |
| `/导入试卷\|导入考卷\|导入试题/` | "导入试卷" | `function_entry` |
| `/讲词\|单词讲解\|词义讲解\|讲单词/` | "讲词"、"restaurant"（单个英文词） | `function_entry` |
| `/自定义/` | "自定义批改" | `function_entry` |

> **注意**：如果 query 匹配多个功能关键词，按上面的表格顺序取第一个匹配。详见 [5. 功能入口匹配 — 二次精细匹配](#5-功能入口匹配--二次精细匹配)。

#### Priority 2：试卷名称精确搜索

| 匹配条件 | 分发场景 |
|------|------|
| 省份 + 年份 + 考试类型 全部匹配（如 山东 + 2024 + 中考） | `paper_exact` |
| 有 2+ 信号但非全部匹配 | `paper_near` |
| 有 1 个信号 + 试卷关键词（真题/试卷/考题/试题/真题卷） | `paper_near` |

解析能力：
- 识别 10 个省份：山东、北京、上海、广东、江苏、浙江、福建、四川、湖北、湖南（含完整名和简称变体）
- 识别年份：`2024年`、`24年`、独立 4 位数年份或 2 位数年份
- 识别考试类型：中考、高考、期中、期末、模拟

#### Priority 3：同步词汇搜索

触发词：`同步词汇`、`词汇表`、`单词表`、`课标词汇`、`单词列表`

返回：按当前单元的结构化词汇表
- 课标词汇区（可勾选全选/部分选择）
- 非课标词汇区
- 语块区
- 每个区支持"全选X词"/"取消全选"
- 选中后展示 UsageSelector（布置听写/默写/跟读/选词练习）
- 点击"生成练习"基于选中词和练习形式生成作业

#### Priority 4：同步课文搜索

触发词：`同步课文`、`课文内容`、`课文原文`、`课文跟读`

返回结构取决于查询是否包含 `topic` 或 `话题`：
- **含 topic/话题**：扁平结构，按 Topic 组织
- **不含 topic/话题**：层级结构，Section → Passage → 逐句/整篇

#### Priority 5a-5l：资源类型搜索（12 个子优先级）

| 子优先级 | 触发模式 | 场景 | 排除条件 |
|:--:|------|------|------|
| **5a** | `写作练习\|写作训练\|作文练习\|书面表达\|^作文$\|应用文\|读后续写` | `writing` | 必须在功能入口之前，避免"应用文"被功能入口捕获 |
| **5b** | `词汇练习\|单词练习\|单词拼写\|词形变化\|单词默写\|单词听写\|^单词$` | `vocab_practice` | — |
| **5c** | `语法练习\|语法填空\|单句语法\|语法训练\|完形填空\|选词填空\|短文填空\|^语法$` | `grammar` | — |
| **5d** | `阅读理解\|阅读练习\|阅读训练\|阅读七选五\|英语阅读\|任务型阅读` | `reading` | — |
| **5e** | `听力模拟\|听力模考` | `listening_mock` | 必须在 5f 和 5k 之前 |
| **5f** | `^听力$\|听力资源\|听力练习\|听力训练\|听力素材` | `listening` | **排除**含"听说"的 query |
| **5g** | `听说练习\|听说训练\|听说资源\|听说` | `no_speaking_region` 或 `listening` | 若 `region='default'` 且 query 含 `Unit 1` → `no_speaking_region`；否则 → `listening` |
| **5h** | `同步练习\|同步训练\|单元练习` | `sync_practice` | — |
| **5i** | `^真题$\|真题资源\|真题库\|历年真题\|中高考真题\|区域精选` | `real_exam` | 必须在 5j 之前，避免"真题"被"专项"捕获 |
| **5j** | `专项\|专项训练\|专项练习\|词汇专项\|语法专项\|听力专项\|听说专项\|写作专项\|阅读专项` | `special_topic` | — |
| **5k** | `模拟\|模拟卷\|模拟题\|模拟试题\|单元检测\|阶段测试\|考前冲刺\|期末考试\|期中考试\|摸底考试` | `mock_exam` | **排除**"听力模拟"（已在 5e 处理） |
| **5l** | `配音\|配音练习\|视频配音\|趣味配音\|同步视频\|视频资源` | `unit1_comprehensive` | — |

> **"听说"特殊处理（5g）**：当 query 匹配"听说"关键词时，需要额外检查地域和单元。如果当前地域为 `'default'` 且 query 中明确包含 `Unit 1`，表示该地区没有 Unit 1 的听说练习，系统返回替代推荐（`isNoResults: true`）。其他情况按正常听力流程处理。

#### Priority 6：Unit N + 资源类型组合

识别 query 中的 Unit 编号 + 资源类型关键词：

| 资源类型关键词 | 分发场景 |
|------|------|
| 听力 / 听说 | `listening` |
| 词汇 / 单词 / 词表 | `vocab_practice` |
| 语法 | `grammar` |
| 写作 / 作文 | `writing` |
| 阅读 | `reading` |
| 课文 | `sync_text_structured` |
| 模拟 / 检测 / 测试 / 考试 | `mock_exam` |
| 真题 | `real_exam` |
| 专项 | `special_topic` |
| 无类型关键词 | `unit1_comprehensive`（综合资源） |

也匹配不包含 Unit 编号但包含 `资源`、`综合`、`练习` 的 query。

#### Priority 7：模糊/默认

| 模式 | 场景 |
|------|------|
| `^阅读$\|^阅读资源$` | `reading` |
| `有没有\|帮我找\|有什么\|找.*资源\|找.*练习\|看看` | `unit1_comprehensive` |
| 中文短语 2-4 个字（含 CJK 字符） | `unit1_comprehensive` |

#### Priority 8：完全无法识别

返回 3 个快捷入口：
- 当前单元资源
- 同步词汇
- 听力练习

### 4.3 资源分组结构

每个场景返回的资源按分组组织，每个分组包含以下属性：

| 属性 | 说明 | 示例 |
|------|------|------|
| 分组名称 | 展示给用户的组标题 | "精准匹配 — Unit 3 听力资源" |
| 分组类型 | resource / sync_vocab / sync_text / paper / alternative | resource |
| 是否精准匹配 | 决定展开/折叠默认态 | 精准匹配→默认展开 |
| 默认展开 | 分组初始状态 | true |
| 展示上限 | 默认展示的最高条目数，超出折叠 | 5 |
| 推荐理由 | 该组的推荐说明文案，展示为弱化提示条 | "以下听力资源与 Unit 3 精确匹配" |
| 替代标签 | 替代推荐组的标签文字，仅 alternative 类型使用 | "当前单元" |
| 筛选类别 | 关联的筛选标签类别，用于标签过滤 | "sync_listening" |

**分组规则**：
- **精准匹配组**：默认展开，展示与搜索词精确匹配的资源
- **推荐资源组**：默认折叠，展示拓展资源，用户可手动展开
- **替代推荐组**：仅无结果场景出现，提供替代方案

### 4.4 筛选标签规则

- 首个标签始终为"全部"
- 标签从所有资源分组汇总生成
- 当标签数 ≤ 1（仅"全部"）时，筛选标签栏不展示
- 筛选逻辑：点击标签 → 只展示该类别匹配的资源分组

## 6. 试卷名称匹配 — 精确到年代与地区

### 6.1 解析能力

`parseSpecificPaperQuery(query)` 从 query 中提取：

| 维度 | 识别范围 | 示例 |
|------|------|------|
| 省份 | 10 个省份（含全名、简称变体） | "山东"、"山东省"、"广东"、"广东省" |
| 年份 | 4 位数（2024, 2023...）或 2 位数（24, 23...） | "2024年"、"24年"、"2024" |
| 考试类型 | 中考 / 高考 / 期中 / 期末 / 模拟 | "中考"、"高考"、"期末" |

### 6.2 匹配度判定

| 匹配级别 | 条件 | 匹配说明 | 分组结构 |
|------|------|------|------|
| **精确匹配** | 省份 + 年份 + 考试类型全部匹配（如 山东 + 2024 + 中考） | 标题/地区/年份/考试类型完全匹配 | 精确 → 相近 → 相关 三层 |
| **相近匹配** | 有 2+ 信号但非全匹配，或有 1 信号 + 试卷关键词 | 同考试类型×相近地区 或 同地区×相近年代 | 相近1 → 相近2 → 相关 三层 |

### 6.3 上下文豁免

试卷搜索**不受当前教学上下文限制**：
- 意图信息中的 context 仍然展示当前教学上下文
- 但实际的资源匹配只基于 query 中提取的试卷信息
- 意图 message 中会注明"用户指定搜索优先于当前教学上下文"

## 7. 同步词汇 + 同步课文特殊规则

### 7.1 同步词汇（sync_vocab）

**触发条件**：query 匹配 `同步词汇|词汇表|单词表|课标词汇|单词列表`

**返回结构**：一个 `groupType: 'sync_vocab'` 的 ResourceGroup，包含：
- **课标词汇区**：当前单元的课标要求词汇
- **非课标词汇区**：课本中的非课标补充词汇
- **语块区**：当前单元的常用语块/固定搭配

**交互能力**：
- 每个区可独立全选/取消全选
- 支持逐词勾选/取消
- 选中后展示 UsageSelector（6 种词汇练习形式的选择器）
- 点击"生成练习" → 基于选中词 + 练习形式生成作业草稿

**全选文案规则**：
- 区名"课标词汇" → 按钮文案"全选课标词"
- 区名"非课标词汇" → 按钮文案"全选非课标词"
- 区名"语块" → 按钮文案"全选语块"
- **不使用**"全选本区"这种模糊文案

**试卷篮规则**：
- 同步词汇资源：`canAddToPaperBasket: false`（不显示"加入试卷篮"按钮）
- 原因：同步词汇是内容选择型资源，不适合放入试卷篮

### 7.2 同步课文（sync_text）

**触发条件**：query 匹配 `同步课文|课文内容|课文原文|课文跟读`

**返回结构**：取决于 query 是否含 `topic/话题`：
- **含 topic/话题**：`sync_text_flat` — 扁平 Topic 结构
- **不含 topic/话题**：`sync_text_structured` — Section → Passage 层级结构

**交互能力**：
- 层级树展开/收起
- 每个节点可全选/部分选择
- 3 种课文练习形式：逐句跟读、整篇跟读、整篇背诵
- 点击"生成练习" → 基于选中课文 × 练习形式生成作业

**试卷篮规则**：
- 同步课文资源：`canAddToPaperBasket: false`（同同步词汇）

## 8. 资源排序与分组规则

### 8.1 分组内排序

资源组内的 items 按以下优先级排序（在场景工厂中由 `findResources(ids)` 的 id 列表顺序决定）：
1. **当前单元优先**：`isCurrentUnit: true` 的资源排在前
2. **类型匹配度**：精确匹配的资源类型排在推荐类型之前
3. **数据顺序**：同一匹配度的资源按数据定义顺序排列

### 8.2 分组展示规则

- **精准匹配组**：默认展开，展示前 5 条，超出折叠
- **推荐资源组**：默认折叠，展开后展示前 3 条
- **替代推荐组**（仅无结果场景）：默认展开顶部组，其他折叠

### 8.3 搜索结果过多处理规则

| 规则 | 说明 |
|------|------|
| 触发条件 | 搜索结果总数 > 50 条 |
| 展示策略 | 默认只展示前 50 条，按资源类型分组 |
| 分组限制 | 每组默认展示前 N 条，超出部分折叠，用户可手动展开 |
| 分页 | 不做传统分页（上一页/下一页），优先通过筛选标签、分组折叠和搜索词优化来收敛结果 |
| 提示文案 | 结果 > 50 条时展示提示："结果较多，已优先展示最匹配的内容，可通过类型筛选继续缩小范围" |
| 筛选建议 | 如果某个筛选标签对应的结果超过该组展示上限，在标签上显示结果数，引导用户点击筛选 |

### 8.4 资源卡片展示规则

双列布局（`grid grid-cols-1 lg:grid-cols-2`）。

每张 ResourceCard 展示：
1. **标题**（最突出）
2. **标签**（最多 3 个，蓝色 pill）
3. **元数据行**：题量 `｜` 预计用时 `｜` 难度 `｜` 年级 `｜` 教材来源
4. **推荐理由条**（条件展示）：`推荐理由：xxx`（蓝底灰字，轻量）
5. **操作按钮行**：预览 `｜` 布置 `｜` 加入试卷篮 `｜` 加入备课

## 10. 支持动作规则

### 10.1 动作按钮一览

搜索结果中存在两种卡片类型，它们的操作按钮不同：

**资源卡片**（搜索匹配到的教学资源）：

| 动作 | 按钮文案 | 触发条件 | 实现方式 |
|------|------|------|------|
| 预览 | "预览" | 资源支持预览 | 打开资源预览浮层 |

| 加入试卷篮 | "加入试卷篮" / "已加入" | 资源可加入试卷篮 | 加入试卷篮并持久化 |
| 加入备课 | "加入备课" | 资源可加入备课 | 加入备课草稿 |
| 生成练习 | "生成练习" | 仅同步词汇/同步课文类资源 | 基于选中词/课文 + 练习形式生成作业草稿 |

**功能入口卡片**（平台功能快捷入口，如"答题卡制作""词汇听写"等）：

| 动作 | 按钮文案 | 触发条件 | 实现方式 |
|------|------|------|------|
| 立即进入 | "立即进入" | 仅功能入口卡片 | 跳转到功能页面或打开 AI 抽屉 |

> 资源卡片的操作（预览/布置/加入试卷篮/加入备课）和功能入口卡片的操作（立即进入）是不同卡片类型的差异化操作，不冲突。

### 10.2 试卷篮规则

- 存储于 localStorage（键名：`xiaotian_paper_basket`）
- 去重：同一 resourceId 不重复添加
- 页面顶部/右上角展示篮内数量角标
- 点击角标打开试卷篮面板
- 从试卷篮可进行后续的布置操作

### 10.3 生成练习规则（同步词汇/课文）

触发条件：
- 当前为 sync_vocab 或 sync_text 类型资源
- 用户在 ContentSelectResource 中选中了至少 1 个内容和 1 种练习形式

生成逻辑：
1. 对每个选中的练习形式 × 所有选中的内容 ID 生成 1 条作业草稿
2. 词汇场景下每条草稿包含所有选中词 ID 的引用
3. 课文场景下每条草稿按叶子节点分组（同一 passage 的 item 合并）

展示：
- 底部状态栏："已选择 X 个内容，Y 种练习形式，将生成 Z 条独立作业"
- 点击"生成练习" → 将作业草稿传递给 AssignmentConfirmPanel

## 11. 兜底推荐与替代推荐规则

### 11.1 无结果 + 替代推荐

**触发条件**：
- query 无法匹配到任何精确资源
- `isNoResults: true`

**返回结构**：3 层替代推荐
1. **当前单元可替代资源**：`defaultExpanded: true`，展示当前单元的关联资源（综合练习、词汇练习、阅读练习等）
2. **同年级推荐资源**：`defaultExpanded: false`，展示同年级的通用资源（阶段测试、专项练习）
3. **非当前单元推荐资源**：`defaultExpanded: false`，展示其他单元的练习和模拟题

意图 message：
```
未找到与「xxx」精确匹配的资源，已为你推荐可替代资源。
```

### 11.2 听说练习无结果（地区限制）

**触发条件**：
- query 匹配"听说"关键词
- 当前地区为 `'default'`
- query 中包含 `Unit 1`

**表现**：与无结果替代推荐类似，但意图 message 为：
```
当前地区暂无 Unit 1 听说练习，已为你推荐可替代资源。
```

### 11.3 完全无法识别

**触发条件**：
- query 为空、纯数字、纯特殊字符、单字符
- 或在所有 7 层优先级中都未匹配到

**返回**：
- `isUnrecognizable: true, isNoResults: true`
- 3 个快捷入口：当前单元资源、同步词汇、听力练习
- 意图 message："小天暂时无法理解你的搜索内容，请尝试以下快捷入口或换一种方式描述。"

## 14. AI搜索与普通搜索的边界

| 维度 | AI 搜索 | 普通搜索 |
|------|------|------|

| 过滤维度 | 说明 |
|------|------|
| 教师账号 | 每个教师只能访问自己有权限的资源 |
| 学校 | 学校购买了版权的资源才可见 |
| 地区 | 地区限定资源需根据教师所在地区过滤 |
| 教材版本 | 按教师当前使用的教材版本匹配 |
| 年级 | 按教师当前教授的年级匹配 |
| 班级 | 班级维度的数据隔离 |
| 资源授权状态 | 已下架或不可布置资源不展示（或仅可预览） |

**一期 Demo 不涉及**：
- 用户角色权限控制
- 资源发布状态管理
- 多班级资源隔离
- 地区教材版本限制

### 16.2 正式开发规划

| 维度 | Demo 阶段 | 正式开发 |

### 17.2 展开常用功能

在结果态下的精简搜索栏右侧，有「展开常用功能」按钮：
- 默认收起
- 点击展开为 4 个轻量快捷入口（4 列横排）
- 入口与首页态的 4 个快捷入口对应
- 不展示"查看学情"和"错词复习"

### 17.3 搜索历史

| 数据 | 说明 |
|------|------|
| 近期使用 | 固定展示 5 条最近搜索的 chip 标签（当前 demo 为固定数据） |
| 将来规划 | 从 localStorage 或后端记录搜索历史 |

### 17.4 清空搜索

- 搜索框右侧有 X 图标（query 非空时显示）
- 点击 X → 清空 query、清空 result → 回到首页态
- 首页态的搜索框 X 点击同样回到空状态
