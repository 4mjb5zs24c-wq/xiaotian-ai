## 1. 背景与问题

### 1.1 当前问题

英语教师在日常教学中有两类高频痛点：

**资源查找低效：**
- 教师需要根据当前教材、单元、班级查找适合的词汇、听力、课文、专项练习等资源
- 平台资源分布在多个模块，教师需要记住每个资源的入口路径
- 搜索结果与当前教学上下文脱节（如教师正在教 Unit 3，搜索结果展示的是 Unit 1 内容）

**学情分析与干预滞后：**
- 教师需要手动翻阅练习报告才能了解班级词汇掌握情况
- 缺乏系统化的"词汇洞察"：不知道哪些词错得多、为什么错、怎么干预
- 当前的洞察信息分散，缺乏从"发现问题"到"执行教学动作"的闭环

### 1.2 解决机会

- 通过 **AI 智能助手** 提供统一的资源搜索入口，支持上下文感知的搜索结果
- 通过 **AI 词汇洞察** 系统化展示班级词汇练习数据，并提供一键式复习方案生成能力
- 建立从"数据洞察 → 诊断归因 → 复习干预 → 效果跟踪"的完整教学闭环

## 2. 项目目标

### 2.1 产品目标

1. **资源搜索提效**：教师通过一个搜索框即可找到所需的教学资源，不需要记忆模块路径
2. **学情可见**：系统化展示班级词汇练习的关键指标和问题归因
3. **从洞察到行动**：教师可从洞察结果一键生成词汇复习方案，布置系列化练习任务
4. **闭环反馈**：复习方案发布后可查看任务完成情况和数据概览

### 2.2 成功指标

| 指标 | 目标 | 说明 |
|------|------|------|
| 搜索匹配准确率 | ≥ 90% | 搜索结果与当前教学上下文一致 |
| 洞察卡片操作转化率 | ≥ 60% | 点击"生成复习方案"的比例 |
| 复习方案发布成功率 | ≥ 95% | 发布不出现阻断性错误 |
| 发布到查看报告的路径闭环 | 100% | 发布后可在报告列表查看并展开 |

## 4. 使用场景

### 场景 A：教师课前准备 — 搜索资源

1. 教师打开小天 AI 搜索页（首页）
2. 教师输入"听力练习"
3. 系统根据当前教学上下文（人教版 · Unit 3）返回 Unit 3 相关听力资源
4. 教师预览资源，选择合适的听力练习布置给学生

### 场景 B：教师查看学情 — 词汇洞察

1. 教师在首页看到词汇洞察卡片："2023级A18班不会写类错误较集中"
2. 点击"查看洞察"进入词汇洞察页面
3. 查看高频错词列表、归因分析、典型错误证据
4. 将需要复习的词加入草稿篮

### 场景 C：教师生成复习方案

1. 教师点击"生成复习方案"
2. 选择复习目标（快速巩固近期错词）
3. 确认词表（默认 Top 30 高频错词）
4. 设置复习周期、每日题量
5. 预览方案详情，修改计划名称和开始时间
6. 确认发布
7. 在练习报告列表中查看发布结果

### 场景 D：教师跟踪复习效果

1. 在练习报告列表中找到已发布的复习计划
2. 展开查看 Day 1 / Day 3 / Day 5 子任务
3. 查看数据概览：覆盖词汇、完成率、掌握率提升、回滚题正确率
4. 等学生完成后点击"报告"查看单日练习报告

## 5. 一期范围

### 5.1 小天智能助手 / AI 搜索

- 统一的 AI 搜索入口页（首页态 + 搜索结果态两套布局）
- 上下文感知的搜索结果（根据当前教材、单元、班级匹配资源）
- 支持搜索类型：听力练习、同步词汇、课文、专项练习、试卷、写作、语法、真题等
- 资源卡片支持：预览、布置、加入试卷篮、加入备课
- 搜索支持快捷入口：当前单元资源、同步词汇、听力练习、快速制卡
- 近期搜索历史展示
- 搜索实现方式：规则引擎 + 模拟数据（一期不接入真实大模型）

> **详细规则**：AI 搜索的完整路由优先级、意图识别、上下文匹配、资源分组、兜底推荐等规则，详见 [`06_AI搜索与智能助手资源匹配规则说明.md`](./06_AI搜索与智能助手资源匹配规则说明.md)。

### 5.2 词汇洞察

- 词汇洞察页面（独立路由 `/vocabulary-insight`）
- 诊断总览区：AI 自然语言总结 + 核心指标 + 推荐动作
- 高频错词工作台：左列表 + 右详情（归因、典型错误证据、操作栏）
- 错误类型洞察区：按"不会写 / 读不准 / 生词 / 不会用"分类
- 学生洞察区：薄弱学生 + 掌握较好学生
- 词汇加入复习草稿篮
- 支持从洞察页直接生成复习方案

### 5.3 复习草稿篮

- 浮动按钮入口 + 全屏面板
- 支持查看词表、勾选、全选、删除、清空
- 按班级 + 教师账号持久化（浏览器本地存储，有效期 7 天）
- 从草稿篮生成专属复习方案（3 步流程）
- 发布成功后清空已使用词

### 5.4 词汇复习方案

- **两个入口**：
  1. 草稿篮入口：3 步流程（设置周期 → 设置题量 → 预览发布）
  2. 通用入口：4 步流程（选择目标 → 确认词表 → 复习设置 → 预览发布）
- **5 种复习目标**：快速巩固近期错词、当前单元词汇复习、阶段/考前复习、薄弱学生补练、自定义
- 支持设置计划名称（可修改）
- 支持设置计划开始时间，各 Day 子任务时间自动推算
- 子任务名称可独立编辑
- 预览页压缩为轻量摘要卡 + 任务列表
- 底部按钮固定可见
- 发布后存储到教师草稿篮（演示阶段使用浏览器本地存储）
- 练习报告列表中展示为聚合卡片

### 5.5 动态回滚规则

- 默认开启，非老师可选开关
- Day 1 无回滚题
- Day N（N≥2）：回滚题 ≈ 当天题量 × 1/5
- 回滚词不足时主复习题补齐
- 有效作答率 < 50% 时使用上次有效回滚池 + 高频错词

### 5.6 练习报告列表

- 词汇复习方案作为聚合卡片展示在原有时间轴列表中
- 可展开查看 Day 子任务
- 子任务复用原有报告按钮样式
- 数据概览弹层（点击触发、滚动关闭、不依赖展开状态）

### 5.7 学生端

- 一期不做新页面，承接现有作业日历/作业列表
- 复习日任务作为普通作业展示

## 7. 业务流程

### 7.1 核心业务流程

```
教师发现学情问题
    │
    ├─→ 首页词汇洞察卡片 → 查看洞察 → 词汇洞察页 → 加入草稿篮
    │                                                          │
    └─→ 词汇洞察页 → 生成复习方案 ─────────────────────────────┘
                    │
                    ▼
            选择复习目标（通用入口）/ 跳过目标（草稿篮入口）
                    │
                    ▼
            确认词表 → 复习设置（周期/复习日/题量）
                    │
                    ▼
            预览发布 → 确认发布
                    │
                    ▼
            练习报告列表（聚合卡片 + Day 子任务）
                    │
                    ▼
            学生端承接（按作业日历展示每日任务）
```

### 7.2 资源搜索流程

```
教师打开 AI 搜索页
    │
    ├─→ 输入关键词搜索
    │   └─→ 系统匹配资源（规则引擎 + 上下文）
    │       └─→ 展示结果（资源卡 + 功能入口 + 推荐）
    │
    ├─→ 点击快捷入口（当前单元资源 / 同步词汇 / 听力练习 / 快速制卡）
    │   └─→ 自动搜索并展示结果
    │
    └─→ 点击资源卡操作按钮
        └─→ 预览 / 布置 / 加入试卷篮 / 加入备课
```

## 8. 页面说明

### 8.1 小天 AI 搜索页

| 状态 | 展示内容 |
|------|------|
| 首页态（未搜索） | 当前教学上下文、AI 搜索卡片（标题 + 描述 + 搜索框 + 按钮）、4 个快捷入口、近期使用 |

**搜索匹配规则**：
- 优先匹配当前教学上下文（教材版本、单元、班级）
- 当前上下文为 Unit 3 时，资源结果优先展示 Unit 3 相关内容
- 推荐理由条文案弱化，使用 `推荐理由：` 前缀，不含重复文案

### 8.2 词汇洞察页

路径：`/vocabulary-insight`

| 区域 | 内容 |
|------|------|
| 顶部 Header | 时间范围选择、班级选择、更新时间 |
| 诊断总览 | AI 总结文本、核心指标、推荐动作按钮 |
| 复习草稿提示条 | 草稿词数量、过期提醒、查看词表/生成方案 |
| 高频错词工作台 | 左列表（错误类型筛选）+ 右详情（归因、证据、操作栏） |
| 错误类型洞察 | 按 4 种错误类型分组的统计卡片 |
| 学生洞察 | 薄弱学生 + 掌握较好学生列表 |
| 干预记录 | 历史干预记录及效果对比 |

### 8.3 复习草稿篮面板

- 浮动按钮入口（带数量角标）
- 全屏面板：词表列表 + 全选/删除/清空 + 生成方案按钮
- 按钮文案动态更新："用已选 X 个词生成方案"
- 主归因标签带颜色区分
- 来源标签、影响学生数展示

### 8.4 词汇复习方案弹窗

**通用入口（4 步）**：

| 步骤 | 内容 |
|------|------|
| 步骤 1：选择目标 | 5 种复习目标卡片 2×3 网格 |
| 步骤 2：确认词表 | 按目标展示不同词表配置（范围/排序/预览） |
| 步骤 3：复习设置 | 周期 + 复习日选择 + 每日题量 + 动态回滚说明 + 掌握判定 + 极简摘要 + 生成方案 |
| 步骤 4：预览发布 | 轻量摘要卡（名称/开始时间/安排/题量）+ 子任务列表（可编辑名称/显示时间/题量结构）+ 固定底部按钮 |

**草稿篮入口（3 步）**：

| 步骤 | 内容 |
|------|------|
| 步骤 2：设置周期 | 复习目标卡 + 周期 + 复习日选择 |
| 步骤 3：设置题量 | 每日题量 + 动态回滚 + 掌握判定 + 极简摘要 + 生成方案 |
| 步骤 3.5：预览发布 | 生成后：摘要卡 + 子任务列表 + 固定底部按钮 |

| 掌握判定 | "连续答对 2 次即掌握"（通用方案固定规则） |
| 计划名称 | 默认生成，支持编辑 |
| 开始时间 | 默认明天 09:00，支持修改，子任务时间自动推算 |
| 子任务名称 | 默认生成，支持逐条编辑 |
| 发布 | 校验 → localStorage 持久化 → 草稿清理 → 成功弹窗 |

## 10. 规则说明

### 10.1 错误归因规则

| 归因类型 | 描述 | 颜色标识 |
|------|------|------|
| 不会写 | 拼写错误，单词书写不正确 | 橙色 |
| 读不准 | 发音类错误 | 红色 |
| 生词 | 学生未掌握的词汇 | 蓝色 |
| 不会用 | 语境使用错误 | 天蓝色 |

严重程度计算：
- 极高：得分率 ≤ 30% 且影响学生 ≥ 10 人
- 高：得分率 ≤ 50% 或影响学生 ≥ 8 人
- 中高：得分率 ≤ 65%
- 中：得分率 ≤ 80%
- 低：其余

### 10.2 复习方案生成规则

| 目标 | 默认周期 | 默认复习日 | 默认题量 |
|------|:--:|------|:--:|
| 快速巩固近期错词 | 5 天 | Day 1, 3, 5 | 30 题 |
| 当前单元词汇复习 | 7 天 | Day 1, 3, 5, 7 | 50 题 |
| 阶段/考前复习 | 14 天 | Day 1, 3, 5, 7, 9, 11, 13 | 50 题 |
| 薄弱学生补练 | 7 天 | Day 1, 3, 5, 7 | 30 题 |
| 自定义 | 7 天 | Day 1, 3, 5, 7 | 50 题 |

草稿词不足 20 个时，默认题量降为 30 题。

### 10.3 动态回滚规则

- **规则性质**：系统规则，不是教师手动开关
- **触发条件**：复习日 ≥ 第 2 个
- **回滚题比例**：约当天题量 × 1/5
- **Day 1**：无回滚题（首轮主复习建立初始记忆）
- **回滚词不足**：用主复习题补齐当天总题量
- **有效作答率 < 50%**：结合上次有效回滚池 + 高频错词生成

### 10.4 掌握判定规则

- **默认**：连续答对 2 次即掌握
- **自定义目标可选**：连续答对 / 累计 3 次 / 末次答对
- **已掌握词**：不再进入后续回滚池

## 12. 数据口径

| 指标 | 定义 | 计算方式 |
|------|------|------|
| 已练词汇数 | 统计周期内班级练习过的词汇总数 | 去重后的词汇 ID 计数 |
| 高频错词数 | 得分率低于阈值的词 | 得分率 ≤ 65% 或按严重程度筛选 |
| 薄弱学生数 | 得分率明显低于班级平均水平的学生 | 综合词汇得分率 < 60% |
| 得分率 | 单个词/学生的正确比例 | 正确次数 / 总练习次数 × 100% |
| 影响学生数 | 某个词出错涉及的学生数 | 去重后的学生 ID 计数 |
| 覆盖词汇数 | 复习方案中覆盖的词数 | 词表中参与复习计划的词数 |
| 累计完成率 | 复习计划中已完成子任务的比例 | 已完成 Day 数 / 总 Day 数 × 100% |
| 词汇掌握率提升 | 发布前 vs 当前正确率的变化 | 当前正确率 - 发布前基准正确率（百分点） |
| 回滚题正确率 | 动态回滚中答对的题占总回滚题比例 | 正确回滚题数 / 总回滚题数 × 100% |
