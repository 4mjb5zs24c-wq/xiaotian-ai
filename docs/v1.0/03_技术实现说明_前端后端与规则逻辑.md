## 2. 一期技术范围

### 2.1 一期需要支持的能力

| 能力 | 说明 |
|------|------|
| AI 搜索资源匹配 | 支持自然语言搜索教学资源，根据当前教学上下文返回匹配结果 |
| 词汇洞察数据聚合 | 按班级、时间范围聚合词汇练习数据，生成高频错词、归因分析、薄弱学生等洞察 |
| 复习草稿篮 | 教师可跨页面收集需要复习的词汇，保留 7 天 |
| 词汇复习方案生成与发布 | 从洞察或草稿篮入口一键生成多天连续复习计划并发布为作业任务 |
| 动态回滚任务生成 | 后续复习日根据前一日的错词数据自动生成回滚题 |
| 练习报告列表展示 | 词汇复习计划作为聚合卡片出现在现有练习报告列表中 |
| 数据概览指标计算 | 提供覆盖词汇、累计完成率、词汇掌握率提升、回滚题正确率等计划级指标 |

### 2.2 演示与正式开发的边界

- 当前 demo 使用本地模拟数据验证业务流程和交互方案。
- 正式开发需由后端提供数据存储、任务发布、规则计算、权限过滤和统计能力。
- 具体接口、字段、存储方案由技术方案确认。

## 5. 数据来源与计算职责

> 以下指标的具体计算口径见 [`04_词汇洞察与复习方案规则口径说明.md`](./04_词汇洞察与复习方案规则口径说明.md)，此处仅标注计算职责归属。

### 5.1 词汇洞察指标

| 指标 | 计算职责 | 说明 |
|------|:--:|------|
| 已练词汇数 | 后端/数据 | 按班级、时间范围、筛选条件去重统计 |
| 词汇错误记录数 | 后端/数据 | 按错误作答人次统计 |
| 单词得分率 | 后端/数据 | 标准化得分率平均计算 |
| 高频错词 | 后端/数据 | 得分率 ≤65% 口径，按多维度排序 |
| 主归因 | 后端/数据 | 按影响学生数→错误次数→得分率→兜底严重程度判定 |
| 影响学生数 | 后端/数据 | 去重计数 |
| 错误次数 | 后端/数据 | 作答人次累计 |
| 薄弱学生 | 后端/数据 | 综合词汇得分率 <60% |
| 掌握率 | 后端/数据 | 已掌握学生数 ÷ 练过学生数 |
| 覆盖率 | 后端/数据 | 练过学生数 ÷ 全班总学生数 |

### 5.2 复习方案数据概览指标

| 指标 | 计算职责 | 说明 |
|------|:--:|------|
| 覆盖词汇 | 后端 | 计划内所有 Day 任务的词汇并集去重 |
| 累计完成率 | 后端 | 已完成人次 ÷ 已到截止时间的应完成人次 |
| 词汇掌握率提升 | 后端 | 当前词汇掌握率 − 发布前词汇掌握率 |
| 回滚题正确率 | 后端 | 正确作答数 ÷ 有效作答数 |

### 5.3 前端展示职责

- 前端负责将后端返回的指标数据按设计规范渲染为图表、卡片和列表。
- 零值、空值和"暂不可用"状态由前端根据返回数据判断并展示对应文案。
- 文案模板（如"完成首轮后生成""Day 3 后生成"）由前端在产品层控制。

## 6. AI 搜索技术协作说明

### 6.1 一期技术方案

- AI 搜索一期采用规则引擎匹配 + 平台资源数据，不直接接入真实大模型。
- 支持根据教师搜索词和当前教学上下文返回结构化搜索结果。

### 6.2 规则依据

- 资源类型分类、路由优先级、意图识别规则、上下文匹配规则、排序与分组规则、兜底推荐规则详见 [`06_AI搜索与智能助手资源匹配规则说明.md`](./06_AI搜索与智能助手资源匹配规则说明.md)。

### 6.3 边界说明

- AI 搜索一期用于资源搜索、资源推荐、预览、布置、加入试卷篮、加入备课、生成单次练习。
- AI 搜索本身不直接生成多天词汇复习方案。
- 如果 AI 搜索中搜索到词汇相关内容，可以引导老师进入词汇洞察页或布置单次词汇练习。
- 多天词汇复习方案只从词汇洞察/草稿篮入口发起。

### 6.4 搜索结果处理

- 搜索结果 > 50 条时，默认展示前 50 条最匹配结果，按资源类型分组，每组可展开更多。
- 不做传统分页，优先通过筛选标签、分组折叠和搜索词优化来收敛结果。
- 搜索无结果时展示 3 层替代推荐，而非空页面。

## 7. 词汇复习方案生成与发布流程

### 7.1 流程概述

```
入口判断（首页洞察 / 词汇洞察页 / 草稿篮）
    │
    ▼
确定复习目标（通用入口）或 跳过目标选择（草稿篮入口）
    │
    ▼
获取词表（按目标/草稿篮勾选确定词汇范围）
    │
    ▼
设置参数（周期、复习日、每日题量、计划名称、开始时间）
    │
    ▼
生成任务计划（计算 Day 数量、主复习题/回滚题分配、子任务时间）
    │
    ▼
预览发布（展示方案摘要、子任务列表，教师可编辑名称）
    │
    ▼
确认发布（校验 → 后端创建计划和子任务 → 返回结果）
    │
    ▼
任务进入练习报告列表（计划作为聚合卡片，子任务关联到各 Day 作业）
    │
    ▼
学生端承接（按现有作业日历/作业列表展示每日复习任务）
```

### 7.2 流程关键点

| 节点 | 说明 |
|------|------|
| 入口判断 | 不同入口决定流程路径和默认参数（详见第 3 章） |
| 词表获取 | 通用入口按复习目标推荐词表，草稿篮入口使用已选草稿词 |
| 参数设置 | 周期、复习日、题量的默认值按目标预设，详见 04 第 5 章 |
| 任务生成 | 每个复习日生成 1 份任务；Day 1 全部为主复习题，后续 Day 含回滚题 |
| 校验 | 发布前校验草稿不为空、已选复习日 ≥1、题量 >0、计划名称/任务名称/开始时间均非空 |
| 草稿清理 | 发布成功后仅清空已使用的草稿词；非草稿入口发布不清空草稿篮 |

## 8. 动态回滚技术协作说明

### 8.1 核心规则

以下规则与 [`04_词汇洞察与复习方案规则口径说明.md`](./04_词汇洞察与复习方案规则口径说明.md) 第 6 章保持一致：

| 规则 | 说明 |
|------|------|
| Day 1 | 无回滚题，全部为主复习题 |
| 触发条件 | 从第 2 个复习日开始 |
| 回滚题比例 | 约当天题量 × 1/5 |
| 生成时机 | 前一复习日截止时间后，系统自动生成 |
| 发布方式 | 回滚题自动进入下一复习日任务，不需要教师每天确认 |
| 回滚词来源 | 上一复习日有效作答中的错词数据 |
| 回滚词排序 | 按错误率、影响学生数、错误次数逐级排序 |
| 回滚词不足 | 可用回滚词少于预期回滚题数时，用主复习题补齐当天总题量，不从范围外乱补词 |
| 有效作答率不足 | 上一复习日有效作答率 < 50% 时，优先使用上一次有效回滚池；无有效回滚池时，用当前词表内高频错词补齐 |
| 主词与回滚词重叠 | 不重复占名额，优先保留为主复习题并增强对应归因题型；同词当天最多不超过 2 题 |

### 8.2 与教师操作的关系

- 动态回滚是非自定义目标的系统内建规则，不是教师可手动勾选的开关。
- 教师不需要每天确认回滚题内容，回滚题在前一日截止后自动生成并进入任务。
- 教师可在复习日开始前手动调整回滚题（二期规划）。

## 9. 与练习报告列表的关系

| 维度 | 说明 |

| 展示方式 | 词汇复习计划作为计划型作业进入现有练习报告列表，按布置时间插入时间轴 |
| 父级卡片 | 展示计划级信息（名称、时间范围、复习日、题量、词表、状态） |

## 10. 状态与异常协作

### 10.1 业务状态

| 阶段 | 状态 | 说明 |
|------|------|------|
| 方案创建 | 未发布 | 教师正在配置方案 |
| 方案创建 | 发布中 | 方案通过校验，正在写入后端 |
| 方案创建 | 发布成功 | 后端创建计划和子任务完成 |
| 方案创建 | 发布失败 | 后端写入异常，保留当前方案配置 |
| 任务执行 | 未开始 | 计划已发布，当前时间早于该 Day 开始时间 |
| 任务执行 | 进行中 | 该 Day 开始时间已到，截止时间未到 |
| 任务执行 | 已截止 | 该 Day 截止时间已过 |
| 任务执行 | 可补做 | 截止时间后允许学生补提交 |
| 数据概览 | 数据未生成 | 首轮复习未完成 / Day 1 无回滚题 |
| 数据概览 | 数据生成中 | 数据正在计算 |
| 数据概览 | 数据可查看 | 数据已生成，前端展示 |

### 10.2 异常规则

异常降级场景、提示文案、提示级别、是否阻断详见 [`04_词汇洞察与复习方案规则口径说明.md`](./04_词汇洞察与复习方案规则口径说明.md) 第 9 章。

关键协作点：
- 红色错误（阻断发布）由前端校验 + 后端校验共同保障。
- 蓝色信息（自动降级）由后端计算后返回降级数据 + 前端展示对应提示。
- 橙色警告（数据不足）由后端判断后返回标识 + 前端展示对应提示。
- 发布失败时，前端应保留当前方案配置和表单状态；如后端已部分接收请求，需保证任务不重复创建，并返回明确失败原因。
