## 2. 前端页面与组件

### 2.1 页面路由

| 路径 | 页面组件 | 说明 |
|------|------|------|
| `/` | `HomePage` | 首页（含词汇洞察单卡片） |
| `/ai-search` | `SearchPage` | AI 搜索页 |
| `/vocabulary-insight` | `VocabularyInsightPage` | 词汇洞察详情页 |
| `/practice-reports` | `PracticeReportPage` | 练习报告列表 |

### 2.2 核心组件

**ReviewPlanWizard**（复习方案生成弹窗）：
- Props：
  ```typescript
  interface Props {
    onClose: () => void
    entrySource?: 'insight' | 'draftBasket'
    draftWordCount?: number
    draftWordIds?: string[]
    onPublish?: () => void
  }
  ```
- entrySource 决定流程路径：
  - `'insight'`：通用 4 步流程
  - `'draftBasket'`：草稿篮 3 步流程
- State：约 30 个状态变量，包括 `goal`（复习目标）、`planName`（计划名称）、`planStartDate/Time`（开始时间）、`dayLabels`（子任务自定义名称）等
- 发布逻辑：构建 `ReviewPlanAssignmentCollection` 对象 → 写入 localStorage → 成功弹窗

**ReviewPlanAssignmentCard**（练习报告聚合卡）：
- 父级卡片复用原有 `ReportCard` 样式（标题栏 + 时间范围 + 预计用时 + 班级/分组/完成/状态）
- 展开后展示 Day 子任务卡片（同样样式）
- 子任务按钮：统一"报告"，禁用态置灰

**DataOverviewPopover**（数据概览浮层）：
- 使用 `createPortal` 渲染到 `document.body`
- `z-index: 9999` 避免被任何容器遮挡
- 点击按钮定位，点击外部/ESC/滚动关闭
- 4 项指标：覆盖词汇、累计完成率、掌握率提升、回滚正确率

## 3. 关键状态管理

### 3.1 Zustand Store

```typescript
interface AIStore {
  teacherContext: TeacherContext      // 当前教学上下文（教材/年级/单元/班级）
  vocabDraftBasket: VocabDraftItem[]  // 复习草稿篮
  paperBasket: PaperBasketItem[]      // 试卷篮
  // ... 其他状态
}
```

**VocabDraftItem**：
```typescript
interface VocabDraftItem {
  wordId: string
  wordText: string
  mainType: string          // '生词' | '读不准' | '不会写' | '不会用'
  sourceTags: string[]      // ['高频错词', '学生错词']
  affectedStudentCount: number
  addedAt: number           // timestamp
  classId: string
  expireAt: number          // 7 天有效期
  scoreRate?: number
}
```

### 3.2 搜索状态（SearchPage）

- `isHome = !result && !searching`：区分首页态/搜索结果态
- `query`：搜索词（从搜索框或快捷入口填入）
- `result`：`NewSearchResult` 类型，包含资源分组、功能入口

### 3.3 复习方案状态（ReviewPlanWizard）

- `step`：当前步骤（1-4）
- `goal`：复习目标
- `dayCount`、`wordsPerDay`、`selectedDays`：周期配置
- `planName`、`planStartDate/Time`：计划元信息
- `dayLabels`：Record<number, string> 子任务自定义名称
- `generated`、`published`：流程状态

## 7. 规则计算流程

### 7.1 搜索路由（matchNewSearch）

```
用户输入 query
    ↓
规则引擎解析 query 文本
    ↓
按 8 层优先级匹配：
  1. 功能入口关键词（制卡/答题卡/听写/批改...）
  2. 试卷名称（省份+年份+考试类型）
  3. 同步词汇
  4. 同步课文
  5a-5l. 资源类型（写作/词汇/语法/阅读/听力/听说/同步/真题/专项/模拟/配音）
  6. Unit+N + 资源类型组合
  7. 模糊匹配/默认
  8. 完全无法识别 → 展示快捷入口
    ↓
返回 NewSearchResult（含资源分组 + 功能入口 + 推荐）
```

### 7.2 词汇严重程度计算

```
calcSeverity(scoreRate, affectedStudentCount):
  if scoreRate <= 30 AND affectedStudentCount >= 10 → "极高"
  else if scoreRate <= 50 OR affectedStudentCount >= 8 → "高"
  else if scoreRate <= 65 → "中高"
  else if scoreRate <= 80 → "中"
  else → "低"
```

### 7.3 动态回滚题量计算

```
getEffectiveRollbackCount(scenario, wordsPerDay, dayIndex):
  if dayIndex == 0:
    return { mainQ: wordsPerDay, rollbackQ: 0 }  // 首日无回滚

  expected = ceil(wordsPerDay / 5)
  mainQ = floor(wordsPerDay * 4 / 5)

  if scenario == 'rollback_shortage':
    actual = scenario.availableRollbackCount
    return { mainQ: wordsPerDay - actual, rollbackQ: actual }  // 回滚不足时补齐

  if scenario == 'low_answer_rate':
    if hasPreviousRollbackPool:
      return { mainQ, rollbackQ: expected }  // 使用上次有效池
    else:
      return { mainQ: wordsPerDay, rollbackQ: 0 }  // 无法生成回滚

  return { mainQ, rollbackQ: expected }  // 正常
```

### 7.4 子任务时间推算

```
computeDayTime(dayIndex):
  startDate = new Date(planStartDate + "T" + planStartTime)
  startDate.setDate(startDate.getDate() + dayIndex - 1)

  return {
    startStr: "MM-DD planStartTime",   // 如 "06-15 09:00"
    endStr: "MM-DD 20:00"              // 默认截止当天 20:00
  }
```

### 7.5 计划名称与子任务标签生成

```
默认计划名称：
  draftBasket → "草稿词复习计划"
  quick_fix → "近期待巩固词复习计划"
  current_unit → "当前单元词汇复习计划"
  stage_exam → "阶段词汇复习计划"
  weak_student → "薄弱学生词汇补练"
  custom → "词汇复习计划"

默认子任务标签：
  idx == 0 → "Day {N} 复习任务"
  idx == last → "Day {N} 复习收口任务"
  其他 → "Day {N} 巩固回滚任务"
```

## 8. 发布任务流程

```
handlePublish():
  1. setPublishError(null)                              // 清空错误
  2. 校验：taskCount == 0 → error                      // 无复习日
  3. 校验：wordsPerDay <= 0 → error                     // 题量为空
  4. 校验：isDraft && effectiveDraftWordCount == 0 → error  // 草稿为空
  5. setPublishing(true)                                // 进入发布中
  6. 构建 planData（调用 computeDayTime 计算各子任务时间）
  7. 写入 localStorage 'xiaotian_review_plans'
  8. onPublish?.()                                      // 草稿篮清理
  9. setPublished(true)                                 // 成功状态
  10. 展示成功弹窗（独立居中弹窗）
```

## 9. 与现有练习报告列表的关系

- 词汇复习计划**不是**新建独立页面，而是作为新类型的条目插入到**原有** `PracticeReportPage` 的时间轴列表中
- 通过 `'days' in item` 判别类型：计划使用 `ReviewPlanAssignmentCard`，普通练习使用 `ReportCard`
- 计划按 `publishedAt` 日期合并到对应日期分组
- 底部原有筛选栏（班级/状态/检查状态/日期/搜索/视图切换）完整保留
- **不新增**顶部洞察条或类型筛选按钮
