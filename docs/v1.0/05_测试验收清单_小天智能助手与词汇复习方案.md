### 3.2 词汇洞察计算口径

| # | 场景 | 操作步骤 | 预期结果 |
|:--:|------|------|------|
| 3.2.1 | 已练词汇数 | 选择时间范围 → 查看核心指标 | 展示去重词汇数，与当前班级/时间范围/筛选条件一致 |
| 3.2.2 | 词得分率 | 查看某个词的详情 | 先按每次有效作答计算标准化得分率，再按有效作答人次平均；空答案计 0 分；未提交不计入 |
| 3.2.3 | 错误率 | 查看某个词的详情 | 错误率 = 1 − 词得分率 |
| 3.2.4 | 高频错词排序 | 查看高频错词列表 | 按错误率（高→低）、影响学生数（多→少）、错误次数（多→少）综合排序 |
| 3.2.5 | 影响学生数 | 查看某个词的详情 | 展示当前范围内该词出现错误作答的去重学生数 |
| 3.2.6 | 错误次数 | 查看某个词的详情 | 展示当前范围内该词的错误作答人次，同一学生多次出错可累计 |
| 3.2.7 | 主要问题 | 查看诊断总览 | 按高频错词的主归因分布统计，取影响学生数和错误次数综合最高的归因 |
| 3.2.8 | 薄弱学生 | 查看学生洞察区 | 展示综合词汇得分率 < 60% 的学生 |
| 3.2.9 | 归因占比 | 查看错误类型洞察区 | 按四类归因统计错误次数占比，按占比排序展示 |
| 3.2.10 | 掌握率 | 查看某个词的详情 | 掌握率 = 已掌握该词学生数 ÷ 练过该词学生数 × 100% |
| 3.2.11 | 覆盖率 | 查看某个词的详情 | 覆盖率 = 练过该词学生数 ÷ 全班学生总数 × 100%；< 50% 时标注"数据量有限" |
