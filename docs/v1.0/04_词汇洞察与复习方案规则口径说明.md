## 1. 高频错词规则

### 1.1 错词筛选标准

| 指标 | 阈值 | 说明 |
|------|:--:|------|
| 得分率 | ≤ 65% | 低于此阈值的词进入高频错词列表 |
| 严重程度筛选 | ≥ "中"（得分率 ≤ 80%） | 默认展示标准 |

### 1.2 排序规则

高频错词按以下权重综合排序（按优先级递减）：
1. **错误率**（从高到低）：得分率越低越靠前
2. **影响学生数**（从多到少）：影响越多学生越靠前
3. **错误次数**（从多到少）：总错误次数越多越靠前

### 1.3 数据清洗

需要剔除的低价值词类（保留语块）：
- 代词类（he, she, it, they...）
- 介词类（in, on, at, to, for...）
- 冠词类（a, an, the）
- 功能词（and, but, or...）

> 实现位置：`vocabularyDataFilter.ts` → `filterVocabularyItems()`

### 1.4 严重程度计算

```
calcSeverity(scoreRate, affectedStudentCount):
  条件 1：scoreRate ≤ 30 且 affectedStudentCount ≥ 10 → "极高"
  条件 2：scoreRate ≤ 50 或 affectedStudentCount ≥ 8 → "高"
  条件 3：scoreRate ≤ 65 → "中高"
  条件 4：scoreRate ≤ 80 → "中"
  其余 → "低"
```

| 严重程度 | 得分率 | 颜色标识 |
|------|:--:|------|
| 极高 | ≤ 30% | 红色 |
| 高 | ≤ 50% | 橙色 |
| 中高 | ≤ 65% | 黄色 |
| 中 | ≤ 80% | 蓝色 |
| 低 | > 80% | 灰色 |

## 2. 归因规则

### 2.1 四级归因体系

| 一级归因 | 代码 | 定义 | 典型表现 |
|------|------|------|------|
| 生词 | `new_word` | 学生未掌握的词汇 | 回答为空/完全错误/与目标词无关 |
| 读不准 | `pronunciation` | 发音类错误 | 音标误读/重音错位/音节遗漏 |
| 不会写 | `spelling` | 拼写错误 | 字母遗漏/错位/冗余/替换 |
| 不会用 | `contextual_usage` | 语境使用错误 | 词性用错/搭配不当/语境不对 |

### 2.2 主归因判定

每个词可以有多个关联归因，但只能有一个**主归因**。

主归因按以下优先级判定：
1. 如果该词的主要错误类型是拼写类 → 主归因"不会写"
2. 如果该词的主要错误类型是发音类 → 主归因"读不准"
3. 如果该词是首次出现且错误率极高 → 主归因"生词"
4. 如果该词在特定语境下反复出错 → 主归因"不会用"

### 2.3 归因文字模板

| 归因 | 模板示例 |
|------|------|
| 不会写 | "该词为多字母组合词，学生常遗漏中间字母或颠倒字母顺序。" |
| 读不准 | "该词音标与学生母语发音习惯差异较大，多个学生出现发音混淆。" |
| 生词 | "该词为当前单元首次出现的课标词，大部分学生尚未建立有效记忆。" |
| 不会用 | "学生在选词填空和语用练习中频繁混淆该词的用法场景。" |

### 2.4 典型错误证据

每个高频错词包含 0-N 条典型错误证据：
```typescript
{
  studentName: string      // 学生姓名
  source: string            // 来源练习名称
  date: string              // 日期
  wrongAnswer: string       // 学生答案
  correctAnswer: string     // 正确答案
  questionType: string      // 题型
  questionId: string        // 原题 ID
}
```

## 3. 草稿篮规则

### 3.1 存储规则

| 维度 | 规则 |
|------|------|
| 存储级别 | 按 `教师账号 + 班级` 存储 |
| 保留期限 | 添加后 7 天自动过期 |
| 去重 | 同一词只保留一条，来源标签合并 |
| 容量 | 无上限 |

### 3.2 词保留字段

加入草稿篮时，每个词必须保留：
- `wordId`：词 ID
- `wordText`：词文本
- `mainType`：主归因（生词/读不准/不会写/不会用）
- `sourceTags`：来源标签（如"高频错词"、"学生错词"）
- `affectedStudentCount`：影响学生数
- `addedAt`：加入时间戳
- `expireAt`：过期时间戳（addedAt + 7 天）
- `scoreRate`：得分率（可选）

### 3.3 发布后清理

| 场景 | 行为 |
|------|------|
| 使用全部草稿词发布成功 | 清空整个草稿篮 |
| 使用部分草稿词发布成功 | 仅清空已使用的词，未选词保留 |
| 发布失败 | 不清空任何草稿词 |
| 中途取消 | 不清空任何草稿词 |

### 3.4 过期提示

- 保留期 > 1 天：显示"还将保留 N 天"，蓝色提示条
- 保留期 ≤ 1 天：显示"明天将自动清空，建议及时生成复习方案"，橙色提示条

## 4. 复习计划生成规则

### 4.1 默认周期与复习日

| 复习目标 | 默认周期 | 默认复习日 | 默认题量/日 |
|------|:--:|------|:--:|
| 快速巩固近期错词 | 5 天 | Day 1, 3, 5 | 30 题 |
| 当前单元词汇复习 | 7 天 | Day 1, 3, 5, 7 | 50 题 |
| 阶段/考前复习 | 14 天 | Day 1, 3, 5, 7, 9, 11, 13 | 50 题 |
| 薄弱学生补练 | 7 天 | Day 1, 3, 5, 7 | 30 题 |
| 自定义复习规划 | 7 天 | Day 1, 3, 5, 7 | 50 题 |

### 4.2 复习日计算逻辑

```
getDefaultReviewDays(dayCount):
  result = []
  for d = 1, 3, 5, 7, ... ≤ dayCount:
    result.push(d)
  return result
```

即默认隔天复习（奇数日），教师可手动勾选/取消任意日期。

### 4.3 每日题量计算

```
defaultWordsPerDay:
  if isDraft:
    if effectiveDraftWordCount < 20 → 30 题
    else → 50 题
  else:
    按 REVIEW_GOAL_META[goal].defaultWordCount
```

### 4.4 子任务标签命名

```
getDefaultDayLabel(day, idx, total):
  if idx == 0 → "Day {N} 复习任务"         // 首个复习日
  if idx == total - 1 → "Day {N} 复习收口任务"  // 最末复习日
  其他 → "Day {N} 巩固回滚任务"
```

教师可在预览发布页逐条编辑子任务名称。

### 4.5 子任务时间推算

```
computeDayTime(dayIndex):
  startDate = new Date(planStartDate + "T" + planStartTime)
  startDate.setDate(startDate.getDate() + dayIndex - 1)

  开始时间 = "MM-DD planStartTime"   // 如 "06-15 09:00"
  截止时间 = "MM-DD 20:00"          // 默认当天 20:00
```

## 5. 动态回滚规则

### 5.1 核心规则

| 维度 | 规则 |
|------|------|
| 规则性质 | 系统内建规则，不是教师可选开关（非 custom 目标） |
| 触发条件 | 从第 2 个复习日开始（Day 1 不含回滚） |
| 回滚比例 | 约当天题量 × 1/5 |
| 来源 | 上一复习日的错词数据 |
| 排列 | 错误率、影响学生数、错误次数综合排序 |

### 5.2 题目分配

```
Day 1: 30 道主复习题 + 0 道回滚题
Day N (N≥2): floor(wordsPerDay × 4/5) 道主复习题 + ceil(wordsPerDay / 5) 道回滚题

示例（每日 30 题）：
  Day 1: 30 + 0
  Day 3: 24 + 6
  Day 5: 24 + 6

示例（每日 50 题）：
  Day 1: 50 + 0
  Day 3: 40 + 10
  Day 5: 40 + 10
```

### 5.3 回滚词不足

当可用回滚词数 < 预期回滚题数时：
- 优先使用已有的可回滚词
- 不足部分用主复习题补齐当天总题量
- **不**从非目标范围乱补词

提示："可回滚词不足，已用主复习题补齐当天题量。"

### 5.4 有效作答率不足

当前一复习日有效作答率 < 50% 时：
- 不完全依赖该日作答数据
- 优先使用上一次有效回滚池
- 无上次有效回滚池时，使用当前词表内高频错词补齐

提示："上一复习日有效作答率不足 50%（XX%），本次回滚题已结合上一次有效回滚池和高频错词生成。"

### 5.5 回滚题去重

若回滚题与上一复习日的题目重复超过 50%：
- 替换部分候选词为同范围的备选词
- 优先保留高错误率的词

## 6. 掌握判定规则

### 6.1 通用方案（非自定义目标）

| 规则 | 值 |
|------|------|
| 判定方式 | 连续答对 |
| 次数 | 2 次 |
| 已掌握处理 | 不再进入后续回滚池 |

### 6.2 自定义目标可选方案

| 方案 | 编码 | 规则 |
|------|------|------|
| 连续答对 | `consecutive_correct` | 连续 2 次正确即掌握 |
| 累计答对 | `accumulated_correct` | 累计 3 次正确即掌握 |
| 末次答对 | `last_test_correct` | 最后一次正确即掌握 |

## 7. 数据概览指标口径

### 7.1 定义

| 指标 | 定义 | 计算公式 |
|------|------|------|
| 覆盖词汇 | 复习方案中涉及的词汇总数 | 去重词 ID 计数 |
| 累计完成率 | 已完成子任务占比 | 已完成 Day 数 / 总 Day 数 × 100% |
| 词汇掌握率提升 | 发布后学生正确率变化 | 当前正确率 - 发布前基准正确率（百分点） |
| 回滚题正确率 | 动态回滚题的正确比例 | 正确回滚题数 / 总回滚题数 × 100% |

### 7.2 可用性判定

| 指标 | 何时可用 | 何时显示"暂不可用" |
|------|------|------|
| 累计完成率 | 计划发布后 | 始终有值（0%） |
| 词汇掌握率提升 | 首轮复习完成后 | 显示"完成首轮后生成" |
| 回滚题正确率 | Day 3 后有回滚数据 | 显示"Day 3 后生成" |

### 7.3 数据概览浮层触发

- **触发方式**：点击按钮（不依赖"展开任务"）
- **关闭方式**：再次点击 / 点击外部 / ESC 键 / 页面滚动
- **层级**：portal 到 body，不依赖父容器

## 8. 异常降级规则

| 异常场景 | 触发条件 | 降级行为 | 提示级别 | 是否阻断发布 |
|------|------|------|:--:|:--:|
| 词表不足 20 个 | effectiveDraftWordCount < 20 | 默认题量降为 30 题 | 蓝色信息 | ❌ |
| 候选词不足 Top N | 可用候选词 < Top N | 用当前可用词生成 | 蓝色信息 | ❌ |
| 回滚词不足 | 可回滚词 < ceil(wordsPerDay/5) | 主复习题补齐 | 橙色警告 | ❌ |
| 有效作答率不足 | 上一日作答率 < 50% | 使用上次回滚池 + 高频错词 | 橙色警告 | ❌ |
| 部分词无可用题 | 题库中无匹配题目 | 跳过 + 补充同范围词 | 蓝色信息 | ❌ |
| 草稿为空 | effectiveDraftWordCount == 0 | — | 红色错误 | ✅ 阻断 |
| 无复习日 | taskCount == 0 | — | 红色错误 | ✅ 阻断 |
| 题量为空 | wordsPerDay ≤ 0 | — | 红色错误 | ✅ 阻断 |
| 发布失败 | localStorage 写入异常 | 保留方案设置 | 红色错误 | ✅ 阻断 |

> **注意**：以上规则和口径为一期设计版本。规则中的阈值（如得分率 ≤ 65%、回滚比例 1/5、连续答对 2 次等）需要在实际使用数据后校准调整。
