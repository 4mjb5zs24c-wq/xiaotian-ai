## 1. 高频错词规则

### 1.1 错词筛选标准

| 指标 | 阈值 | 说明 |
|------|:--:|------|
| 得分率 | ≤ 65% | 低于此阈值的词进入高频错词列表 |
| 严重程度筛选 | ≥ "中"（得分率 ≤ 80%） | 默认展示标准 |

### 1.2 排序规则

高频错词按以下权重综合排序（按优先级递减）：
1. **错误率**（从高到低）：得分率越低越靠前
2. **影响学生数**（从多到少）：影响越多学生越靠前
3. **错误次数**（从多到少）：总错误次数越多越靠前

### 1.3 数据清洗

需要剔除的低价值词类（保留语块）：
- 代词类（he, she, it, they...）
- 介词类（in, on, at, to, for...）
- 冠词类（a, an, the）
- 功能词（and, but, or...）

### 1.4 严重程度计算

严重程度由得分率和影响学生数综合判定，按以下条件逐级匹配（从高到低）：

| 条件 | 严重程度 |
|------|:--:|
| 得分率 ≤ 30% 且 影响学生数 ≥ 10 人 | 极高 |
| 得分率 ≤ 50% 或 影响学生数 ≥ 8 人 | 高 |
| 得分率 ≤ 65% | 中高 |
| 得分率 ≤ 80% | 中 |
| 以上条件均不满足 | 低 |

| 严重程度 | 得分率 | 颜色标识 |
|------|:--:|------|
| 极高 | ≤ 30% | 红色 |
| 高 | ≤ 50% | 橙色 |
| 中高 | ≤ 65% | 黄色 |
| 中 | ≤ 80% | 蓝色 |
| 低 | > 80% | 灰色 |

## 2. 词汇洞察计算口径

> 以下口径为词汇洞察页各指标的统一计算标准，供产品、数据开发和测试验收使用。

### 2.1 已练词汇数

| 维度 | 规则 |
|------|------|
| 定义 | 当前班级、当前时间范围、当前筛选条件下，有有效作答记录的去重词汇数 |
| 统计范围 | 班级内已下发的词汇类练习任务中的词汇 |
| 去重 | 同一词被多个学生或多次练习，只计 1 个词 |
| 时间范围 | 按洞察页选择的时间范围筛选（近 7 天/14 天/30 天/本学期/自定义） |

### 2.2 词汇错误记录数

| 维度 | 规则 |
|------|------|
| 定义 | 当前筛选范围内，所有词汇相关题目中产生的错误作答记录总数 |
| 统计方式 | 按错误作答人次统计，同一学生多次出错可累计 |
| 范围 | 受洞察页时间范围、归因类型筛选条件约束 |

### 2.3 词得分率

| 维度 | 规则 |
|------|------|
| 定义 | 该词相关有效作答的平均标准化得分率 |
| 单题得分率 | 实际得分 ÷ 题目满分 |
| 多空题 | 先按空标准化（每空独立计分），再计算单次作答得分率 |
| 平均方式 | 按有效作答人次平均 |
| 空答案 | 学生已提交但该题为空，按 0 分计入 |
| 未提交 | 学生未提交整份任务，该次不计入该词作答人次 |
| 无法关联 | 无法识别或无法关联词汇的作答不计入 |
| 标准化 | 不同题型得分统一换算为 0-100% 的标准化得分率 |

### 2.4 错误率

| 维度 | 规则 |
|------|------|
| 公式 | 错误率 = 1 - 词得分率 |
| 说明 | 错误率越高，表示该词被学生答错的比例越大 |

### 2.5 高频错词

| 维度 | 规则 |
|------|------|
| 定义 | 当前筛选范围内，得分率较低、影响学生较多、错误次数较多的词 |
| 筛选条件 | 得分率 ≤ 65%（默认），或按严重程度选择"中"及以上 |
| 排序 | 按错误率（高→低）、影响学生数（多→少）、错误次数（多→少）、最近出错时间（近→远）综合排序 |

### 2.6 影响学生数

| 维度 | 规则 |
|------|------|
| 定义 | 当前筛选范围内，该词出现错误作答的去重学生数 |
| 去重 | 同一学生多次出错只计 1 人 |
| 范围 | 受洞察页时间范围和筛选条件约束 |

### 2.7 错误次数

| 维度 | 规则 |
|------|------|
| 定义 | 当前筛选范围内，该词出现错误作答的作答人次 |
| 累计 | 同一学生多次出错可累计 |
| 范围 | 受洞察页时间范围和筛选条件约束 |

### 2.8 主要问题

| 维度 | 规则 |
|------|------|
| 定义 | 按高频错词的主归因分布统计，取影响学生数和错误次数综合最高的归因 |
| 计算 | 对高频错词列表中的每个词，取主归因 → 按归因聚合影响学生数和错误次数 → 取综合得分最高的归因 |
| 展示 | 如"2023级A18班不会写类错误较集中" |

### 2.9 薄弱学生

| 维度 | 规则 |
|------|------|
| 定义 | 当前筛选范围内，词汇整体掌握率低于阈值的学生 |
| 默认阈值 | 综合词汇得分率 < 60% |
| 辅助判断 | 可结合高频错词数量 Top 范围辅助判断 |
| 范围 | 班级内所有有有效作答记录的学生 |

### 2.10 归因占比

| 维度 | 规则 |
|------|------|
| 定义 | 按生词、读不准、不会写、不会用四类归因统计错误次数占比 |
| 计算 | 某归因错误次数 ÷ 四类归因总错误次数 × 100% |
| 展示 | 洞察页错误类型洞察区按占比排序展示 |

### 2.11 掌握率

| 维度 | 规则 |
|------|------|
| 定义 | 练过该词的学生中，已达到掌握判定的学生占比 |
| 公式 | 已掌握该词的学生数 ÷ 练过该词的学生数 × 100% |
| 掌握判定 | 默认连续答对 2 次（详见第 7 章「掌握判定规则」） |
| 与覆盖率的区别 | 掌握率衡量的是"练过的学生中有多少人掌握了"，覆盖率衡量的是"全班有多少人练过这个词" |

### 2.12 覆盖率

| 维度 | 规则 |
|------|------|
| 定义 | 全班学生中，练过该词的学生占比 |
| 公式 | 练过该词的学生数 ÷ 全班学生总数 × 100% |
| 说明 | 覆盖率 < 50% 时，洞察结论需标注"数据量有限" |
| 与掌握率的区别 | 覆盖率只关心是否练过，不关心是否掌握；掌握率只关心练过的学生中有多少人已掌握 |

## 3. 归因规则

### 3.1 四级归因体系

| 一级归因 | 定义 | 典型表现 |
|------|------|------|
| 生词 | 学生未掌握的词汇 | 回答为空/完全错误/与目标词无关 |
| 读不准 | 发音类错误 | 音标误读/重音错位/音节遗漏 |
| 不会写 | 拼写错误 | 字母遗漏/错位/冗余/替换 |
| 不会用 | 语境使用错误 | 词性用错/搭配不当/语境不对 |

> 注：归因编码（如 `new_word`、`spelling` 等）仅用于系统内部标识，不暴露给教师。

### 3.2 主归因判定

每个词可以有多个关联归因，但只能有一个**主归因**。

主归因判定优先级（按以下顺序逐级判定）：
1. 影响学生人数最多的归因
2. 影响学生人数相同时，取错误次数最多的归因
3. 前两项仍相同时，取得分率最低的归因
4. 以上仍无法区分时，按归因严重程度兜底：不会写 > 不会用 > 读不准 > 生词

### 3.3 归因文字模板

| 归因 | 模板示例 |
|------|------|
| 不会写 | "该词为多字母组合词，学生常遗漏中间字母或颠倒字母顺序。" |
| 读不准 | "该词音标与学生母语发音习惯差异较大，多个学生出现发音混淆。" |
| 生词 | "该词为当前单元首次出现的课标词，大部分学生尚未建立有效记忆。" |
| 不会用 | "学生在选词填空和语用练习中频繁混淆该词的用法场景。" |

### 3.4 典型错误证据

每个高频错词包含 0-N 条典型错误证据，每条证据需包含：

| 属性 | 说明 |
|------|------|
| 学生姓名 | 作答学生的姓名 |
| 来源练习 | 该错误出现的练习名称 |
| 日期 | 错误发生日期 |
| 学生答案 | 学生实际提交的错误答案 |
| 正确答案 | 该题的正确答案 |
| 题型 | 题目类型（如听写/默写/选词填空） |
| 原题标识 | 可追溯到原始题目的标识 |

## 4. 草稿篮规则

### 4.1 存储规则

| 维度 | 规则 |
|------|------|
| 存储级别 | 按教师账号 + 班级存储 |
| 保留期限 | 添加后 7 天自动过期 |
| 去重 | 同一词只保留一条，来源标签合并 |
| 容量 | 无上限 |
| 跨页面保留 | 教师在词汇洞察页加入草稿篮的词，在首页、搜索页等其他页面的草稿篮浮动按钮和面板中同样可见 |

### 4.2 词保留属性

加入草稿篮时，每个词必须保留以下信息：

| 属性 | 说明 |
|------|------|
| 词标识 | 系统中该词的唯一标识 |
| 词文本 | 词汇的中文或英文文本 |
| 主归因 | 生词 / 读不准 / 不会写 / 不会用 |
| 来源标签 | 如"高频错词""学生错词"等 |
| 影响学生数 | 该词在班级中出错涉及的学生数 |
| 得分率 | 该词的当前得分率（可选） |
| 加入时间 | 教师点击"加入草稿篮"的时间 |
| 过期时间 | 加入时间 + 7 天 |

### 4.3 发布后清理

| 场景 | 行为 |
|------|------|
| 使用全部草稿词发布成功 | 清空整个草稿篮 |
| 使用部分草稿词发布成功 | 仅清空已使用的词，未选词保留 |
| 发布失败 | 不清空任何草稿词 |
| 中途取消 | 不清空任何草稿词 |

### 4.4 过期提示

- 保留期 > 1 天：显示"还将保留 N 天"，蓝色提示条
- 保留期 ≤ 1 天：显示"明天将自动清空，建议及时生成复习方案"，橙色提示条

## 5. 复习计划生成规则

### 5.1 默认周期与复习日

| 复习目标 | 默认周期 | 默认复习日 | 默认题量/日 |
|------|:--:|------|:--:|
| 快速巩固近期错词 | 5 天 | Day 1, 3, 5 | 30 题 |
| 当前单元词汇复习 | 7 天 | Day 1, 3, 5, 7 | 50 题 |
| 阶段/考前复习 | 14 天 | Day 1, 3, 5, 7, 9, 11, 13 | 50 题 |
| 薄弱学生补练 | 7 天 | Day 1, 3, 5, 7 | 30 题 |
| 自定义复习规划 | 7 天 | Day 1, 3, 5, 7 | 50 题 |

各目标的默认时间范围：
- 快速巩固近期错词：近 7 天
- 当前单元词汇复习：当前教学单元
- 阶段/考前复习：近 30 天
- 薄弱学生补练：近 14 天
- 自定义：近 7 天

### 5.2 复习日计算与同步规则

默认取周期内的奇数日（隔天复习），即 1, 3, 5, 7, ..., 直到不超过总周期天数。教师可在复习日选择区手动勾选或取消任意日期。

**复习日变化后的同步规则**：老师切换周期或勾选/取消复习日后，以下内容实时同步更新：
- 子任务数量（几个复习日就生成几份任务）
- 各 Day 名称
- 各 Day 日期
- 主复习题 / 回滚题分配
- 底部方案摘要
- 预览发布页子任务列表

若未选择任何复习日，阻断进入下一步或发布，提示"请至少选择 1 个复习日"。

非复习日不生成任务，学生如有未完成任务可在非复习日补做。

### 5.3 每日题量规则

#### 5.3.1 题量可选值

| 复习目标 | 可选每日题量 |
|------|------|
| 快速巩固近期错词 | 20、30、50 题 |
| 当前单元词汇复习 | 30、50、100 题 |
| 阶段/考前复习 | 50、80、100、200 题 |
| 薄弱学生补练 | 20、30、50 题 |
| 自定义复习规划 | 30、50、100 题 |
| 草稿篮入口（词数 < 20） | 默认 30 题，可选 20、30、50 题 |
| 草稿篮入口（词数 ≥ 20） | 默认 50 题，可选 30、50、100 题 |

#### 5.3.2 题量计算说明

| 规则 | 说明 |
|------|------|
| 每日题量按"题"计算，不按"词"计算 | 一个词可能对应多道题（如拼写题 + 选词填空题），每日题量上限按题数控制 |
| 普通词当天通常只出 1 题 | 一个词当天生成 1 道题 |
| 回滚词或严重错词可最多出 2 题 | 同一词在当天主复习题和回滚题中各出现一次时，合并为 2 题 |
| 教师可手动调整题量 | 从可选值中选择，不可输入任意值 |

### 5.4 子任务标签命名

系统按子任务在复习序列中的位置自动生成名称：
- 首个复习日 → "Day {N} 复习任务"
- 最末复习日 → "Day {N} 复习收口任务"
- 中间复习日 → "Day {N} 巩固回滚任务"

教师可在预览发布页逐条编辑子任务名称，编辑后不受后续时间修改影响。

### 5.5 子任务时间推算

- 开始时间 = 计划总开始时间 + (Day序号 - 1) 天
- 截止时间 = 同一天的默认截止时间（20:00）
- 示例：计划开始时间为 2026-06-15 09:00，复习日 Day 1 → 06-15 09:00 至 06-15 20:00；Day 3 → 06-17 09:00 至 06-17 20:00

### 5.6 题型按归因推荐规则

#### 5.6.1 推荐逻辑

系统根据班级高频错词的主要归因分布，自动推荐对应题型比例。教师可切换固定模板或手动调整题型。

#### 5.6.2 归因 → 题型映射

| 归因 | 推荐题型（按优先级） | 说明 |
|------|------|------|
| 不会写 | 拼写题、默写题、听写题、汉译英、语境填词 | 侧重书写输出，强化拼写记忆 |
| 读不准 | 跟读题、听音辨词、听写题、发音类练习 | 侧重语音输入和发音模仿 |
| 生词 | 英汉匹配、释义选择、汉译英、基础识记题 | 侧重词义建立和初步记忆 |
| 不会用 | 语境填空、选词填空、词形变化、单句语法填空 | 侧重语境理解和用法辨析 |

#### 5.6.3 题型模板

| 模板 | 适用场景 | 题型比例建议 |
|------|------|------|
| 综合推荐（默认） | 班级归因分布均衡 | 按班级主要归因自动分配 |
| 书写强化 | 不会写类占比较高 | 拼写/默写/听写 ≥ 60% |
| 听说强化 | 读不准类占比较高 | 跟读/听音辨词/听写 ≥ 60% |
| 语境应用 | 不会用类占比较高 | 语境填空/选词填空/词形变化 ≥ 60% |
| 基础巩固 | 生词类占比较高 | 英汉匹配/释义选择/汉译英 ≥ 60% |

#### 5.6.4 题型降级

当某词按归因推荐的题型在题库中无匹配题目时，按以下优先级降级：
1. 优先使用同归因的备选题型
2. 同归因备选题型也无匹配时，降级为其他可用题型
3. 提示"部分词暂无对应题型，系统已自动调整为可用题型"（蓝色信息，不阻断）

## 6. 动态回滚规则

### 6.1 核心规则

| 维度 | 规则 |
|------|------|
| 规则性质 | 系统内建规则，不是教师可选开关（非 custom 目标） |
| 触发条件 | 从第 2 个复习日开始（Day 1 不含回滚） |
| 回滚比例 | 约当天题量 × 1/5 |
| 来源 | 上一复习日的错词数据 |
| 排列 | 错误率、影响学生数、错误次数综合排序 |

### 6.2 题目分配

```
Day 1: 全部为主复习题 + 0 道回滚题
Day N (N≥2): 约 4/5 主复习题 + 约 1/5 动态回滚题

示例（每日 30 题）：
  Day 1: 30 + 0
  Day 3: 24 + 6
  Day 5: 24 + 6

示例（每日 50 题）：
  Day 1: 50 + 0
  Day 3: 40 + 10
  Day 5: 40 + 10
```

### 6.3 回滚题生成时间

| 维度 | 规则 |
|------|------|
| 生成时机 | 前一复习日截止时间后，系统自动根据该日错词数据生成回滚题 |
| 触发方式 | 系统自动触发，不需要老师每天确认 |
| 进入任务 | 回滚题生成后自动进入下一复习日任务，老师无需手动操作 |

### 6.4 回滚题自动发布

- 回滚题在前一复习日截止后自动生成并进入下一复习日任务
- 下一复习日开始时，学生端自动看到包含回滚题的完整任务
- 老师不需要每天确认回滚题内容
- 老师可在复习日开始前手动调整回滚题（二期规划）

### 6.5 回滚词不足

当可用回滚词数 < 预期回滚题数时：
- 优先使用已有的可回滚词
- 不足部分用主复习题补齐当天总题量
- **不**从非目标范围乱补词

提示："可回滚错词不足，系统将使用主复习题补齐本次任务题量。"（橙色警告，不阻断）

### 6.6 主复习词与回滚词重叠处理

| 场景 | 处理规则 |
|------|------|
| 某词既是当日主复习词，又被选入回滚词 | 不重复占名额，优先保留为主复习题，同时增强对应归因题型（如从拼写变为拼写+选词填空） |
| 同词当天最多出题数 | 同一词当天最多不超过 2 题（1 道主复习 + 1 道增强题） |

### 6.7 回滚题去重

| 场景 | 处理规则 |
|------|------|
| 回滚题与上一轮回滚题重复超过 50% | 优先用同范围备选高频错词替换 |
| 替换原则 | 优先保留错误率更高的词，替换重复率低的词 |

### 6.8 有效作答率不足

当前一复习日有效作答率 < 50% 时：
- 不完全依赖该日作答数据
- 优先使用上一次有效回滚池
- 无上次有效回滚池时，使用当前词表内高频错词补齐

提示："上一复习日有效作答率不足 50%，本次回滚题将结合上一次有效回滚池和高频错词生成。"（橙色警告，不阻断）

## 7. 掌握判定规则

### 7.1 通用方案（非自定义目标）

| 规则 | 值 | 说明 |
|------|------|------|
| 判定方式 | 连续答对 | 学生需连续答对该词 |
| 次数 | 2 次 | 连续 2 次答对即判定为掌握 |
| 已掌握处理 | 不再进入后续回滚池 | 但若该词原本在后续固定主复习内容中，仍可按原计划出现（不作为回滚词出现） |

### 7.2 同词当天多题判定

| 场景 | 规则 |
|------|------|
| 同一词当天出现 2 道题 | 两题都答对才算该词当天答对 |
| 2 题中仅答对 1 题 | 该词当天视为未答对，不累计连续答对次数 |

### 7.3 自定义目标可选方案

| 方案 | 规则 |
|------|------|
| 连续答对 | 连续 2 次正确即掌握；中间有错则计数归零 |
| 累计答对 | 累计 3 次正确即掌握；中间可以有错误，不影响累计次数；一旦再次出错，该词仍可继续被系统关注 |
| 末次答对 | 最后一次作答正确即掌握 |

### 7.4 已掌握词在后续任务中的处理

| 场景 | 规则 |
|------|------|
| 已掌握词在回滚池中 | 不再进入后续回滚池 |
| 已掌握词在固定主复习内容中 | 仍可按原计划出现，但不标记为"回滚词" |
| 已掌握词在自定义方案中 | 按所选方案的判定规则决定是否继续出现在后续任务中 |

## 8. 数据概览指标口径

### 8.1 定义

| 指标 | 定义 | 计算公式 |
|------|------|------|
| 覆盖词汇 | 本复习计划覆盖的去重词汇数 | 计划内所有 Day 任务的词汇并集去重计数 |
| 累计完成率 | 已完成复习任务人次占比 | 已完成复习任务人次 ÷ 已到截止时间的应完成复习任务人次 × 100% |
| 词汇掌握率提升 | 发布后学生正确率变化 | 当前正确率 - 发布前基准正确率（百分点） |
| 回滚题正确率 | 动态回滚题的正确比例 | 正确回滚题数 ÷ 已到截止时间的总回滚题数 × 100% |

### 8.2 累计完成率口径说明

| 规则 | 说明 |
|------|------|
| 分子 | 已完成复习任务人次（学生提交即计入） |
| 分母 | 已到截止时间的应完成复习任务人次 |
| 未到截止时间 | 不计入分母 |
| 补做 | 补做完成后实时更新完成率 |
| 暂无已到截止时间的任务 | 完成率展示为 0%，但此时不是完整完成率 |
| 示例 | Day 1 截止时间为 6/15 20:00，当前时间为 6/16 09:00 → Day 1 计入分母；Day 3 截止时间为 6/17 20:00 → Day 3 不计入分母 |

### 8.3 词汇掌握率提升口径说明

| 规则 | 说明 |
|------|------|
| 基线 | 计划发布前一刻，本计划覆盖词汇的基准正确率 |
| 当前值 | 只统计已到截止时间的复习日的作答数据 |
| 展示格式 | "发布前 X%，当前 Y%，提升 Z 个百分点" |
| 首轮未完成 | 显示"完成首轮后生成" |

### 8.4 回滚题正确率口径说明

| 规则 | 说明 |
|------|------|
| 统计范围 | 只统计已到截止时间的回滚题 |
| Day 1 展示 | Day 1 无回滚题时显示"Day 3 后生成" |
| 对比口径 | 建议使用"该词在本计划中第一次出现时的正确率"作为对比基线 |

### 8.5 可用性判定

| 指标 | 何时可用 | 何时显示"暂不可用" |
|------|------|------|
| 累计完成率 | 计划发布后 | 始终有值（0%）；暂无截止任务时展示 0% |
| 词汇掌握率提升 | 首轮复习完成后 | 显示"完成首轮后生成" |
| 回滚题正确率 | Day 3 后有回滚数据 | 显示"Day 3 后生成" |

### 8.6 数据概览浮层触发

- **触发方式**：点击按钮（不依赖"展开任务"）
- **关闭方式**：再次点击 / 点击外部 / ESC 键 / 页面滚动
- **层级**：渲染到页面顶层，不依赖父容器

### 9.2 页面提示展示规则

#### 9.2.1 蓝色信息提示

- **用途**：说明系统已自动降级或自动补齐。
- **行为**：不阻断老师继续操作。
- **展示位置**：建议展示在当前步骤底部或方案说明区域中。
- **示例**：
  > 当前仅有 8 个可用词，未达到 Top 30，将按现有词生成复习计划。

#### 9.2.2 橙色警告提示

- **用途**：说明数据不足、回滚不足、有效作答率不足等情况。
- **行为**：不阻断发布，但需要老师感知方案已降级。
- **展示位置**：建议展示在预览发布页的方案说明中。
- **示例**：
  > 可回滚错词不足，系统将使用主复习题补齐本次任务题量。

#### 9.2.3 红色错误提示

- **用途**：用于无法继续生成或发布的场景。
- **行为**：必须阻断下一步或发布。
- **展示位置**：错误提示展示在当前操作按钮上方或当前步骤顶部。
- **示例**：
  > 当前草稿为空，无法生成词汇复习方案。请先添加复习词。

### 9.3 提示级别速查

| 级别 | 颜色 | 典型场景 | 阻断发布 |
|:--:|:--:|------|:--:|
| 蓝色信息 | 蓝 | 词表不足、候选词不足、部分词无题、题型降级 | 否 |
| 橙色警告 | 橙 | 回滚词不足、有效作答率不足 | 否 |
| 红色错误 | 红 | 草稿为空、无复习日、题量为空、名称/时间为空、发布失败 | 是 |
