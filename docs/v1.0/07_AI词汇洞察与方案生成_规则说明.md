# AI 词汇洞察与方案生成规则说明

> 版本：v2.2  
> 更新日期：2026-06-24  
> 用途：产品规则、计算口径、展示逻辑、流程联动和异常处理说明。  
> 具体接口如何拆、字段如何命名、接口入参出参如何设计，由前后端开发根据现有系统能力自行设计。

## 1. 首页词汇入口规则

### 功能目的

首页词汇区域让老师快速了解班级近期词汇薄弱情况，并提供两个独立入口：一个是基于错词数据的"词汇洞察"，一个是基于教材/课标词的"阶段词汇复习方案"。

### 老师看到什么

首页右侧「AI 教学助手」区域下方有两张并列卡片：

- **左侧：词汇洞察**  
  展示近 7 天高频错词数和薄弱学生数的摘要。老师从这里进入后可以看到详细的词汇能力分析和错词列表。  
  按钮：「查看词汇洞察」

- **右侧：阶段词汇复习方案**  
  展示一句简短说明，告诉老师这个功能适用于期中、期末、高三一轮等复习场景。  
  按钮：「生成复习方案」

### 数据来源

词汇洞察卡片的数据来自词汇洞察的默认摘要数据（近 7 天范围）。阶段词汇复习方案卡片不需要数据，点击后进入独立的方案生成流程。

### 点击后发生什么

- 点击左卡「查看词汇洞察」→ 跳转到词汇能力洞察页
- 点击右卡「生成复习方案」→ 在当前页面打开阶段词汇复习方案弹窗，不跳转新页面

### 空态 / 异常规则

词汇洞察卡片在无数据时不展示数字摘要，展示「暂无数据」。阶段方案卡片始终正常展示。

### 待确认点

无。

## 2. 词汇能力洞察页规则

### 功能目的

词汇能力洞察页是老师查看班级词汇薄弱情况的完整工作台，包含总览、能力维度、高频错词列表、学生洞察和干预记录。

### 老师看到什么

页面从上到下分为五个区域：

1. **顶部概览**：标题"词汇能力洞察"+ 班级名 + 数据更新时间 + 右上角时间范围切换 + 总结文案 + 关键指标（已练词汇数 / 高频错词数 / 薄弱学生数 / 主要薄弱能力）+「生成词汇提升方案」按钮
2. **词汇能力雷达图**（概览区右侧卡片）
3. **高频错词工作台**：左侧错词列表 + 右侧错词详情
4. **学生洞察**（左侧卡片）
5. **干预记录**（右侧卡片）

### 数据来源

所有数据跟随右上角时间范围筛选联动。老师切换时间范围（近 7 天 / 近 14 天 / 近 30 天 / 本学期 / 当前单元）后，页面上的总结文案、雷达图、错词列表、学生洞察和生成方案的数据来源同步更新。详见第 14 节「时间筛选联动规则」。

### 空态 / 异常规则

当前时间范围内没有足够的词汇练习数据时，展示空态提示「当前范围内暂无足够的词汇练习数据，请切换时间范围后查看。」，此时「生成词汇提升方案」按钮仍然可见但生成功能不可用。

### 待确认点

无。

## 3. 词汇能力雷达图规则

### 功能目的

通过雷达图可视化班级在四个词汇能力维度上的表现，帮助老师快速识别班级在哪些能力上偏弱。

### 四个固定维度

1. 词汇识记：对词汇音、形、义的基本识别与记忆
2. 语境理解：在语篇、对话等语境中理解词汇含义
3. 词汇运用表达：在写作、翻译等输出场景中正确运用词汇
4. 词汇学习策略：学生自主规划、监控和调整词汇学习的能力（当前标记为"待完善"）

四个维度固定不变，不可增减。

### 计算规则

词汇能力得分只按题型映射到能力维度，不按错因映射。具体映射关系由后端根据题型体系确定。

如果一道题同时对应多个能力维度（例如"默写"同时涉及词汇识记和词汇运用表达），则该题的得分和满分同时计入多个能力维度的分子和分母。

每个能力维度的得分计算公式为：该维度下有效作答小题实际得分之和 ÷ 该维度下有效作答小题满分之和，最终转换为 0～100 的分数。

### 题型范围

词汇能力计算基于平台题型映射。当前题型范围以现有题型清单为基础，并需和平台题型库、DP/教研最终确认。

一个题型可以对应一个或多个词汇能力。一个题型对应多个能力时，该题型作答数据同时计入多个能力维度的分子和分母。

词汇能力只按题型映射，不按错因映射。例如"默写"题型同时对应词汇识记和词汇运用表达，而不是按"不会写"错因去判断属于哪个能力。

题型与能力的映射关系需要由后端统一维护，并随平台题型库更新而同步。

### 展示规则

- 每个维度显示得分（0～100）
- 数据点用蓝色圆点标注
- 多边形填充区域展示能力分布形态
- "词汇学习策略"维度展示时附带"待完善"标签，表示该维度计算规则尚未最终确定

### 空态 / 异常规则

无能力得分数据时，雷达图区域展示「暂无数据」。缺少某个维度数据时，该维度按 0 分展示。

### 待确认点

词汇学习策略维度的具体计算方式待确认。

## 4. 高频错词计算与展示规则

### 功能目的

高频错词用于帮助老师快速识别当前班级近期最需要关注的词汇问题，并作为生成词汇提升方案的数据来源。

### 数据范围

高频错词统计范围跟随右上角时间筛选变化。老师选择近 7 天、近 14 天、近 30 天、本学期或当前单元时，高频错词列表同步变化。

### 列表不是原始记录

高频错词列表展示的是按词汇聚合后的结果，不是原始错误记录。老师看到的是"每个词的综合表现"，而不是"每一条错误"。

### 去重规则

高频错词去重沿用平台现有词汇去重规则，具体规则由平台词汇中心和错词库确定。前端不自行创造大小写归一、模糊合并、别名合并等新规则。

正式开发时，建议由后端返回已经聚合好的高频错词结果，前端只负责展示和排序。Demo 阶段使用的临时去重逻辑仅供参考，不作为正式产品规则。

### 聚合规则

同一个词的多条错误记录需要聚合为一个条目。聚合后：

- 错误次数：累加
- 涉及学生数：按学生去重统计
- 得分率与错误率：按聚合后的有效作答重新计算（不是取第一条记录的值）
- 主要错因：取错误次数最多的错因类型
- 多个错音：全部展示，不只展示一个

### 得分率与错误率

- 得分率 = 该词所有有效作答小题实际得分之和 ÷ 该词所有有效作答小题满分之和
- 错误率 = 100% − 得分率
- 有效作答指有提交、有评分结果、可归属到该词的作答记录
- 多空题按空计为小题

### 排序规则

高频错词先按词聚合，再按以下优先级排序，最后取 Top N：

1. 错误率从高到低
2. 涉及学生数从多到少
3. 错误次数从多到少
4. 有效作答次数从多到少

### 展示数量

- 词汇洞察数据池：取 Top 50 高频错词
- 列表默认展示：Top 12（可滚动查看更多）
- 生成词汇提升方案：基于当前范围 Top 50 高频错词
- 方案报告高频薄弱内容：展示 Top 10
- 不足对应数量时按实际数量展示，不硬凑重复词

### 错因筛选

列表顶部提供四个错因筛选标签：不会写、读不准、生词、不会用。老师点击某个标签后只展示该错因类型的高频错词，再次点击取消筛选。

### 空态 / 异常规则

当前范围内无高频错词数据时，列表展示「暂无高频错词数据」。「生成词汇提升方案」不可用。

### 待确认点

高频错词去重口径待确认（平台现有规则是什么？是否按平台词汇唯一标识去重？标准词和展示词的去重逻辑是否有差异？大小写、词形变化、短语别名等如何处理？）。

## 5. 高频错词详情规则

### 功能目的

老师点击左侧列表中的某个高频错词后，右侧展示该词的详细信息，包括归因、错误写法、学生作答示例和原题查看入口。

### 老师看到什么

右侧详情从上到下展示：

1. **词汇信息**：词文本 + 主归因标签 + 关联归因标签（如有）+ 得分率 + 受影响人数 + 错误次数 + 练习来源
2. **常见错误写法**：表格展示每个错误写法、涉及学生数和出现次数。如果该词有多个错音，全部展示，不只展示一个
3. **学生作答示例**：每条示例包含学生姓名、来源任务和日期、错误答案→正确答案、错因标签和「查看原题」按钮

### 不展示的内容

高频错词详情**不展示**"主因分析"长文案。详情区只有错因标签，不出现大段 AI 生成的归因分析文字。

### 默认状态

页面首次加载或时间范围切换后，自动选中列表中第一个词展示详情。如果列表为空，右侧展示「选择一个高频错词查看详情」。

### 待确认点

无。

## 6. 查看原题规则

### 功能目的

老师可以在高频错词详情中，点击某个学生作答示例的「查看原题」按钮，在弹出的窗口中看到该学生在原题中的完整作答情况。

### 老师看到什么

点击「查看原题」后在当前页面弹出一个窗口，包含：

- 原题内容
- 学生作答（红色背景标注）
- 正确答案（绿色背景标注）
- 题目解析

### 点击行为

点击「查看原题」打开弹窗，不跳转新页面。弹窗可以关闭回到高频错词页面。

### 数据来源

原题数据优先通过作答记录定位，避免同一学生同一题多次作答时取错记录。如果作答记录不可用，则通过题目和学生信息定位。

查看原题功能优先复用平台已有的题目查看能力。

### 空态 / 异常规则

如果某条学生作答示例没有关联的原题数据，则不展示「查看原题」按钮。如果查询不到原题，展示「暂无原题数据」。

### 待确认点

查看原题弹窗复用平台能力，具体取数方式需和现有题目/作答记录能力对齐。

## 7. 学生洞察规则

### 功能目的

让老师在同一个页面中快速了解班级中哪些学生词汇掌握薄弱、哪些学生掌握较好，为后续教学决策提供参考。

### 场景一：词汇洞察页薄弱学生

词汇洞察页薄弱学生用于帮助老师识别当前筛选范围内需要关注的学生。

**判定规则**：当前筛选范围内词汇得分率低于班级平均，或高频错词涉及数量较多的学生进入薄弱学生列表。

**排序优先级**：
1. 得分率低的优先
2. 涉及高频错词数量多的优先
3. 错误次数多的优先

**老师看到什么**：
- 概览状态：每个学生显示姓名、得分率、主要问题和涉及高频错词数量
- 展开后：展示该学生的主要错词、错因、错音和错误明细

**较好学生**：得分率较高且词汇掌握稳定的学生展示在右侧，显示姓名、得分率、已掌握词汇数、近期趋势（持续进步或保持稳定）。

### 场景二：方案报告页待关注学生

方案报告页待关注学生规则与词汇洞察页不同，判定条件更严格。

**判定规则**（满足任一条件即进入待关注）：
1. 未完成任一已发布词汇闯关
2. 整体正确率低于所在班级平均正确率

多班级场景按学生所在班级平均判断，不按全部班级总平均。

**排序优先级**：
1. 未完成且正确率低的学生优先
2. 正确率越低越靠前
3. 未完成次数越多越靠前

**展示内容**：每个学生展示姓名、整体正确率、完成进度、状态标签和关注原因。原因示例：
- "正确率低于班级平均"
- "未完成任务，且正确率低于班级平均"
- "正确率提升不明显"

### 交互规则

- 默认只展示学生概览信息，不展开错词明细
- 点击某个薄弱学生后展开错词明细，再次点击收起
- 学生列表默认展示前 5 名，其余学生折叠可展开

### 当前版本范围

当前版本的学生洞察只做问题查看，主干预入口是「生成词汇提升方案」（针对班级整体）。单学生的个性化练习布置属于后续能力，不在本期开发范围内。

### 空态 / 异常规则

无薄弱学生数据时展示「暂无薄弱学生数据」；无较好学生数据时展示「暂无较好学生数据」。

### 待确认点

1. 薄弱学生是否需要绝对阈值（不仅低于班级平均，还需低于某一绝对分数线）待确认。
2. 较好学生的判定标准待确认。

## 8. 词汇洞察生成词汇提升方案规则

### 功能目的

基于当前时间范围内的班级高频错词和薄弱学生数据，自动生成词汇提升方案（包含 2 份词汇闯关练习），帮助老师快速布置针对性巩固练习。

### 入口

词汇能力洞察页顶部概览区的「生成词汇提升方案」按钮。

### 老师看到什么

点击按钮后打开一个弹窗，包含：

1. **AI Loading 动画**（详见第 10 节）
2. **方案信息**：覆盖高频错词数、班级、有效期、共 2 份练习且每份 50 题
3. **方案提示**：说明该方案基于当前时间范围的高频错词和薄弱学生自动生成
4. **两份练习预览**：词汇闯关 1（立即发布，50 题）、词汇闯关 2（次日发布，50 题，含巩固练习）
5. **底部操作**：重新生成、确认布置

### 老师不需要选择的内容

- **不出现**一周/两日方案类型选择
- **不出现**年级、教材、单元选择
- **不出现**题量、题型、难度、版本调整控件
- **不展示**回滚规则、补题规则等后台生成逻辑

### 生成规则

方案直接基于当前时间范围的高频错词（Top 50）和薄弱学生数据生成。

**词汇闯关 1**：立即发布，基于当前范围 Top 50 高频错词生成，每份 50 题，尽量覆盖 50 个词。

**词汇闯关 2**：固定次日 08:00 发布。包含固定生成题目和回滚题目两部分：

- 固定生成题目按方案规则提前生成
- 回滚题目根据词汇闯关 1 的作答情况，从仍需巩固的词汇中回滚生成

老师端不展示固定题、回滚题、补题、一个词多题等后台细节。老师端只看到「词汇闯关 2｜次日 08:00 发布｜50 题」等前台信息。

### 回滚和补题规则

回滚和补题规则属于后台生成逻辑，不在前台展示。规则如下：

1. 每份练习固定 50 题
2. 每份尽量覆盖 50 个词
3. 当可用词不足 50 个时，允许一个词对应多道题
4. 当某题型题量不足时，优先用本难度其他题型补充
5. 同难度题量仍不足时，从低难度题目补充
6. 这些规则用于保证每份练习尽量达到 50 题，不需要展示给老师

### 弹窗布局

弹窗在屏幕中视觉居中。弹窗内容可滚动，标题栏固定。

### 无数据 / 数据少规则

- **无数据**（高频错词数为 0 或有效作答记录为 0）：不允许生成方案，展示「当前范围内暂无可用于生成方案的数据，请切换时间范围或复习范围后重试。」
- **数据少**（高频错词数过少，具体阈值待确认）：允许生成方案，但展示提示「当前范围内可参考数据较少，生成结果可能不够充分，建议结合实际教学情况使用。」

### 确认布置

点击「确认布置」后方案发布，老师可在练习报告中查看方案报告。

### 待确认点

1. 回滚规则和补题规则需要确认现有后端能力是否完全支持。
2. 数据少的判断阈值待确认（详见第 15 节）。

## 9. 阶段词汇复习方案规则

### 功能目的

面向期中、期末、高三一轮等阶段性复习场景，由系统识别老师当前教学阶段，老师确认或调整后，按复习范围生成阶段词汇巩固方案。

阶段词汇复习方案**不是**基于班级错词数据生成，而是基于教材词/课标词和复习范围生成。这一点与词汇洞察生成方案（第 8 节）有本质区别。

### 入口

首页右侧「阶段词汇复习方案」卡片，点击「生成复习方案」按钮后弹窗，不跳转新页面。

### 整体流程

老师打开弹窗后的操作流程为：

1. 系统识别当前教学阶段，展示识别结果和推荐设置
2. 老师确认或手动修改年级
3. 老师选择复习方式（课标词 / 教材）
4. 如果选择教材复习，展示并默认选中册次和单元，老师可修改
5. 老师选择复习周期
6. 老师选择建议练习时间
7. 老师选择方案开始练习时间
8. 老师点击「开始生成」
9. 进入小天 AI Loading
10. Loading 后展示生成好的复习方案（上方为方案说明，下方为练习列表）

**注意：不要一打开弹窗就直接展示生成好的方案。老师需要先确认设置再生成。**

### 步骤一：系统识别与顶部文案

打开弹窗后，顶部展示一条友好的识别文案，告知老师系统识别到的教学阶段。

高中场景示例：「小天已根据您近期使用的教材内容，识别到当前可能处于高二上学期期末复习阶段，并为您推荐了适合的阶段词汇复习设置。若年级或复习范围不准确，您可以手动修改后再生成方案。」

初中场景示例：「小天已根据您近期使用的教材内容，识别到当前可能处于初二上学期期末复习阶段，并为您推荐了适合的阶段词汇复习设置。若年级或复习范围不准确，您可以手动修改后再生成方案。」

### 步骤二：年级识别与修改

年级不是让老师从空白状态手动选择，而是由系统先识别。

**识别依据**：老师近期使用过的同步内容、已选择/使用过的册次和单元，以及教研提供的阶段判断表。具体识别规则表待 DP 提供。

如果识别结果不准确，老师可以手动修改年级。修改年级后，复习方式、教材册次、单元、复习周期、练习时间等默认推荐值需要随新年级重新刷新。

**年级展示规则**：
- 初中账号只展示初一、初二、初三
- 高中账号只展示高一、高二、高三
- Demo 阶段可以保留模拟学段切换（仅在开发模式下可见），正式产品不允许老师自由切换学段

### 步骤三：复习方式

老师需要选择复习方式：按课标词复习，或按教材复习。

- 选择「按课标词复习」：不展示教材、册次、单元选择
- 选择「按教材复习」：展示教材、册次、单元选择

系统会根据识别到的年级和当前教学阶段，默认选中对应的册次和单元。默认册次和单元由 DP 整理的规则表决定，当前标记为"待 DP 提供默认规则"。老师可以修改默认选中的册次和单元。

**联动规则**：
- 切换年级后，需要重新刷新默认册次和单元
- 切换册次后，需要清空不属于当前册次的单元
- 单元是否必选按照 DP 规则处理，暂未确认则先标记待确认

**高中教材册次展示**：必修一、必修二、必修三、选必一、选必二、选必三。不使用"高一上册""高一下册"等表述。

**初三/高三复习**：默认选中课标词复习，老师可以切换到教材复习。是否允许切换待产品确认。

### 步骤四：复习周期

弹窗中需要展示复习周期选项。复习周期决定生成多少份练习。

- 可选周期：一周、两周、三周、四周
- 默认值与年级、教学阶段有关，由 DP 整理的规则表决定。当前标记为"待 DP 提供默认周期规则"
- 练习数量与复习周期的对应关系由 DP 整理规则。当前标记为"待 DP 提供练习数量规则"

前台不再简单固定为两个方案类型卡片，改为"复习周期 + 练习时间 + 复习方式"共同决定方案生成结果。

### 步骤五：建议练习时间

老师选择练习时间偏好，影响每日练习的排期。

可选时间组合示例：周一至周五、周六日、自定义多选。

- 默认练习时间由 DP 根据年级和复习阶段整理规则，当前标记为"待 DP 提供默认练习时间规则"
- 只选择周六日时，后台在重新生成时可以轮换到趣味版方案
- 趣味版、基础版、进阶版、培优版等属于后台版本策略，不直接暴露给老师选择
- 老师端只看到练习安排和生成结果，不看到具体版本名称

### 步骤六：方案开始练习时间

生成方案结果区上方需要展示方案开始练习时间。

- 默认值为当天
- 老师可以修改开始练习时间
- 修改开始时间后，下方每份练习的发布时间按新的开始时间重新计算

### 步骤七：点击「开始生成」

老师完成设置后点击「开始生成」按钮，进入 AI Loading（Loading 文案见第 10 节）。Loading 结束后展示生成结果。

### 步骤八：生成结果页

生成结果页结构：

**上方 — 方案说明**：展示本次方案的关键信息，包括：
- 当前年级
- 复习方式
- 复习范围（课标词 N 个 / 教材 · 册次 · 单元）
- 复习周期
- 练习时间
- 方案开始练习时间
- 预计生成练习数量

**下方 — 练习列表**：展示生成好的每份练习。每份练习展示：
- 练习名称（如"词汇闯关 1""词汇闯关 2"）
- 发布时间
- 截止时间
- 题量
- 覆盖词汇数量
- 题型和题量概览

题型和题量不需要全部平铺占用大量空间，可在卡片上展示简要概览，完整内容通过悬浮、展开或轻量提示查看。开发时需保证每份练习的题型组成和各题型题量可被老师查看。

### 排期与练习发布规则

- 每天最多布置一份练习
- 一周最多四份练习
- 老师只选择周六日：按所选周六日时间每天推送一份
- 老师选择周一至周五：按所选练习时间每天推送一份，一周最多四份
- 具体生成几份练习，结合复习周期和 DP 的练习数量规则确定

### 每份练习基本规则

- 每份练习 50 题（除非 DP 另行调整）
- 第一份练习支持预览试题
- **不允许**老师调整题量、题型、难度、版本
- 版本策略不展示给老师

### 重新生成规则

1. 重新生成不改变老师已选择的年级、复习方式、复习范围、复习周期、练习时间和方案开始时间
2. 重新生成只在当前规则范围内生成另一套方案
3. 后台可在规则允许范围内轮换其他版本方案
4. 老师只选择周六日时，重新生成可轮换到趣味版方案
5. 版本策略属于后台逻辑，不展示给老师
6. 重新生成后需要重新进入 AI Loading

### 确认布置

点击「确认布置」后方案发布，老师可在练习报告中查看方案报告。

### 弹窗布局

弹窗在屏幕中视觉居中。弹窗内容可滚动。

### 无数据 / 数据少规则

- **无数据**：当前复习范围下无可用数据时，展示「当前范围内暂无可用于生成方案的数据，请调整年级或复习范围后重试。」
- **数据少**：允许生成方案但展示提示「当前范围内可参考数据较少，生成结果可能不够充分，建议结合实际教学情况使用。」

### 待确认点

1. 年级识别规则表待 DP 提供
2. 教材复习默认册次和单元规则待 DP 提供
3. 复习周期默认值待 DP 提供
4. 复习周期与练习数量的对应关系待 DP 提供
5. 建议练习时间默认值待 DP 提供
6. 周六日场景下趣味版轮换规则需 DP/后端确认
7. 每周最多四份、每天一份的排期规则需和后端确认
8. 每份练习题型和题量展示方式需前端确认交互样式
9. 初三/高三是否允许从课标词切换教材复习待产品确认
10. 单元是否必选待 DP 确认
11. 预览试题的取数方式待确认

## 10. 生成方案 AI Loading 规则

### 功能目的

在方案生成过程中，通过 AI Loading 动画让老师感知系统正在处理数据，避免老师以为系统无响应。

### 老师看到什么

弹窗首次打开或点击「重新生成」后，方案预览区域替换为 Loading 动画：

- 一个蓝色 AI 图标（脉冲动画）
- 下方三行进度文字，每行前面有状态标记：
  - ✓（绿色）：已完成的步骤
  - 蓝色脉冲圆点：正在进行的步骤
  - 灰色圆点：尚未开始的步骤

### 三步进度文案

两种方案使用不同的 Loading 文案：

**词汇洞察生成方案**：
1. 正在分析错词和学生表现…
2. 正在匹配练习内容…
3. 正在生成方案…

**阶段词汇复习方案**：
1. 小天正在分析年级与复习范围…
2. 正在匹配适合当前阶段的词汇练习内容…
3. 正在生成阶段词汇复习方案…

### 动画时长

当前 Demo 使用前端模拟动画（约 2 秒）。正式接入后端生成接口后，动画时长应跟随实际接口响应时间。

### 重新生成

点击「重新生成」后，Loading 动画重新执行，方案预览数据刷新。

### 空态 / 异常规则

生成超时或失败时，展示错误提示并允许老师重新生成。

### 待确认点

方案生成是同步返回结果还是异步生成并通过轮询获取结果？是否需要流式（streaming）返回进度？

## 13. 方案报告规则

### 功能目的

方案报告是词汇方案的完整数据分析页面，帮助老师了解方案执行效果、学生表现变化和后续教学建议。

### 入口

从以下位置进入：

- 首页练习报告列表的「方案报告」按钮
- 干预记录的「报告」按钮
- 直接通过地址访问方案报告页

### 不展示的内容

方案报告页**不展示**方案版本信息，**不展示**生成来源（如"基于词汇洞察生成"）。

### 报告结构（8 个区域）

#### 1. 报告头部

展示方案名称、班级、复习范围、方案状态（已完成/进行中）、完成进度、数据更新时间和下载 PDF 按钮。

#### 2. 核心指标（5 个）

- **整体完成率**：已发布词汇闯关的学生完成情况
- **整体正确率**：已发布且有有效作答的词汇闯关的正确率加权平均
- **正确率变化**：与方案前基线对比的变化幅度。有历史基线时对比方案前，无基线时对比首次闯关。变化幅度 > 2 个百分点为"提升"，< −2 个百分点为"降低"，−2 到 +2 之间为"基本持平"
- **主要薄弱能力**：四个能力维度中得分最低的一个
- **待关注学生**：未完成任一已发布闯关或正确率低于班级平均的学生数

#### 3. 核心发现

基于数据的文字总结，一般 2～3 条。

#### 4. 词汇能力表现对比

使用横向对比条展示四个能力维度在方案前后（或首次闯关 vs 当前）的得分变化。每个维度展示"前值"条和"后值"条，并标注变化幅度（提升 X 个百分点 / 持平 / 降低 X 个百分点）。变化最大的维度标注"提升最明显"。

#### 5. 练习表现趋势

使用折线图展示方案内每一份已发布且有有效作答数据的词汇闯关的完成率和正确率变化趋势。

- 完成率用虚线表示
- 正确率用蓝色实线表示
- Y 轴为百分比（0%～100%），X 轴为各词汇闯关
- 每个数据点标注具体数值
- 无历史基线不影响趋势展示，只要方案内有已发布且有有效作答数据的闯关就可以展示趋势
- 只有在完全无有效作答数据时，趋势图才展示空态

#### 6. 待关注学生

列出所有满足"待关注"条件的学生，包括姓名、正确率、完成进度、状态标签和关注原因。按优先级排序：未完成且正确率低的优先，正确率越低越靠前，未完成次数越多越靠前。

#### 7. 高频薄弱内容

- **高频错词 Top 10**：表格展示词汇、错误率、涉及学生数、主要问题和对应能力维度
- **薄弱题型 Top 3**：卡片展示题型名称、正确率、作答人次和涉及学生数

#### 8. 后续建议

基于数据的教学建议列表（一般 2～3 条），附带下载 PDF 按钮。

### 计算规则说明

详细计算规则参见 `vocabPlanReportCalculator.ts` 中的注释，包括：

- 整体完成率 = 已完成学生人次 ÷ 应完成学生人次（仅已发布的闯关纳入计算）
- 整体正确率 = 各闯关正确率按有效作答学生数加权平均
- 正确率变化 = 当前整体正确率 − 基线正确率
- 待关注学生需同时满足条件判断和排序

### 空态 / 异常规则

- 无可用有效作答数据时，各指标展示占位符
- 方案数据不存在时展示提示信息
- 无基线数据时，正确率变化的对比对象自动切换为首次闯关

### 待确认点

方案版本字段是否需要后端存储？（当前前端不展示，但后端可能需要保存用于审计）

## 15. 空态、异常和边界规则

### 无数据规则

无数据不允许生成方案。以下情况视为无数据：

- 当前范围内没有词汇练习数据
- 当前范围内没有有效作答记录
- 当前范围内没有可用于生成方案的高频错词

无数据提示文案：「当前范围内暂无可用于生成方案的数据，请切换时间范围或复习范围后重试。」

| 场景 | 处理方式 |
|------|---------|
| 词汇洞察页某时间范围无数据 | 展示空态提示，引导老师切换时间范围 |
| 高频错词数为 0 或有效作答记录为 0 | 不允许生成词汇提升方案 |
| 阶段方案复习范围无数据 | 不允许生成方案，引导老师调整范围 |
| 学生洞察无数据 | 展示「暂无薄弱学生数据」/「暂无较好学生数据」 |
| 干预记录无数据 | 不展示干预记录卡片 |
| 方案报告无有效作答数据 | 各指标展示占位符 |
| 方案数据不存在 | 展示「报告不存在或暂无数据」 |

### 数据少规则

数据少时**允许**生成方案，但需要在弹窗中展示提示。

提示文案：「当前范围内可参考数据较少，生成结果可能不够充分，建议结合实际教学情况使用。」

数据少判定规则（建议）：
- 高频错词数少于 20 个，视为数据较少
- 或有效作答学生数过少时，视为数据较少，具体人数阈值可后续结合平台数据确认

### 边界规则

- Top N 取数不足时，按实际数量展示，不硬凑重复词
- 一个词对应多个错音时全部展示，不只取一个
- 方案报告无历史基线时，正确率变化对比对象自动切换为首次闯关
- 方案报告趋势图只在完全无有效作答数据时才空态，无基线不影响展示

### 异常规则

- 接口请求失败时，保持上一次成功数据不变并展示错误提示
- 方案生成超时或失败时，展示错误提示并允许重新生成
- 方案 ID 无效时，不跳转到其他页面，展示明确的错误提示

## 16. 后端能力支持说明

多数数据模块需要后端数据支持，但不代表每个模块都需要一个独立接口。具体接口如何拆分、数据如何聚合、字段如何设计，由前后端开发根据现有系统能力自行决定。本文档只定义产品规则、计算口径、展示逻辑和异常处理。

### P0（核心数据与生成能力）

1. **词汇洞察汇总数据**：按时间范围和班级返回总结文案、关键指标（已练词汇数、高频错词数、薄弱学生数、主要薄弱能力）和数据更新时间
2. **高频错词聚合数据**：按时间范围和班级返回已聚合的高频错词列表，包含得分率、错误率、错误次数、涉及学生数、主要错因、错音分布和学生作答示例。去重规则沿用平台现有规则
3. **词汇能力得分计算**：按题型到能力维度的映射规则，返回四个维度的得分
4. **学生洞察数据**：按时间范围和班级返回薄弱学生和较好学生列表
5. **词汇提升方案生成**：基于高频错词（Top 50）和薄弱学生数据生成方案，内部处理回滚、补题、题目组合等逻辑，前端不感知
6. **阶段词汇复习方案生成**：基于年级和复习范围（教材/课标词）生成方案
7. **方案报告数据**：按方案标识返回完整报告数据，包括核心指标、能力对比、阶段趋势、待关注学生、高频薄弱内容和后续建议

### P1（辅助数据与入口能力）

1. **首页词汇洞察摘要**：返回默认时间范围（近 7 天）的高频错词数和薄弱学生数摘要，供首页卡片展示
2. **干预记录 / 方案记录**：返回班级近期词汇干预历史列表，包括方案效果摘要
3. **练习报告列表中的方案报告识别**：在练习报告列表中区分普通练习报告和方案报告，以便前端展示不同的入口按钮和跳转目标
4. **查看原题**：优先复用平台已有的题目查看能力

### 前端表现类能力不需要单独后端接口

以下能力纯前端实现，不依赖独立后端接口：

- AI Loading 动画（对接方案生成接口的状态变化即可）
- 弹窗视觉居中
- 按钮文案和展示逻辑
- 页面跳转和弹窗打开/关闭
- 时间筛选控件的切换和联动状态管理
- 雷达图、折线图、对比条的 SVG 渲染
- 错因筛选标签的本地过滤
