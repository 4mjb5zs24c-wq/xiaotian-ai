# AI 智能搜索 — 功能介绍

> 老师只需输入一句话，小天就能智能识别意图，精准匹配教学资源、试卷或功能入口。

---

## 一、这是什么？

AI 智能搜索是嵌入在教学助手顶部的智能化搜索入口。不同于传统的"关键词+筛选"搜索，你只需要**用自然语言描述你的教学需求**，小天的 AI 引擎会自动识别你的意图：

- **搜资源**：找到对应教材单元的同步练习、听力素材、专项练习……
- **搜试卷**：直接找到某省某年的真题或模拟卷
- **找功能**：快速打开制卡、听写、讲词等教学工具

**一句话总结**：输入教学问题，小天帮你找到最好的教学资源。

---

## 二、可以搜什么？

### 2.1 教学资源（18 种）

| 资源类别 | 示例搜索词 | 返回内容 |
|----------|-----------|---------|
| 同步词汇 | "同步词汇"、"单词表" | 当前单元课标词+非课标词+语块，可直接选中生成听写/默写 |
| 同步课文 | "同步课文"、"课文内容" | 当前单元课文段落，可选中生成跟读/背诵练习 |
| 同步听力 | "Unit 1 资源" | 同步教材的听力练习、听力素材 |
| 听说练习 | "听说练习" | 口语跟读、朗读、听说训练资源 |
| 听力练习 | "听力练习"、"听力素材" | 听力专项练习、听力短对话/短文/长对话 |
| 词汇练习 | 搜"Unit 1"综合结果中含 | 单词拼写、中英检测、词形变化练习 |
| 语法专项 | "语法专项"、"语法练习" | 语法填空、单句语法填空 |
| 写作练习 | 综合结果中含 | 应用文、读后续写、同步作文练习 |
| 阅读练习 | "阅读理解"、"阅读练习" | 阅读理解、阅读七选五专项 |
| 综合练习 | "综合练习" | 多题型混合的综合训练 |
| 单元检测 | "单元检测" | 单元同步测试卷 |
| 阶段测试 | "阶段测试"、"期中" | 阶段性综合检测 |
| 模拟题 | "模拟"、"模拟卷"、"模拟题" | 各年级模拟试题 |
| 真题 | "山东2024中考"、"真题" | 各省市历年真题，支持**精确匹配**+**近似推荐** |
| 专项 | "专项训练"、"词汇专项" | 按题型/技能分类的专项练习 |
| 考前冲刺 | "考前冲刺" | 考前综合复习冲刺套题 |
| 配音 | 综合结果中含 | 视频配音练习素材 |
| 同步视频 | 综合结果中含 | 课文配套视频资源 |

### 2.2 试卷名称精准搜索

支持按**省份 + 年份 + 考试类型**组合搜索试卷，目前覆盖：

- **省份**：山东、北京、上海、广东、江苏、浙江、福建、四川、湖北、湖南
- **年份**：2020~2026
- **类型**：中考、高考、期中、期末、模拟

**精确匹配示例**：
| 搜索词 | 匹配结果 |
|--------|----------|
| `山东 2024 中考真题` | 山东省2024年中考英语真题 |
| `北京 2025 高考` | 北京市2025年高考真题 |
| `广东 2023 中考模拟` | 广东省2023年中考模拟题 |

**近似匹配**：当省份、年份不完全匹配时，自动推荐相近的试卷（如搜"河南2024中考"，推荐"全国通用2024中考"）。

### 2.3 功能入口速达

输入以下关键词，直接打开对应的教学功能：

| 搜索词 | 打开功能 |
|--------|---------|
| `讲词` 或直接输入单个英文单词（如 `welcome`） | 打开全屏讲词页 |
| `制卡`、`答题卡`、`自制答题卡` | 打开答题卡制作功能 |
| `听写`、`默写批改` | 打开听写/默写批改功能 |
| `批改`、`应用文`、`读后续写` | 打开作文批改功能 |
| `导入试卷`、`导入试题` | 打开试卷导入功能 |
| `自定义` | 打开自定义练习入口 |
| `词表`、`词单` | 打开词表管理 |

## 三、怎么搜？

### 3.1 搜索方式

| 方式 | 操作 |
|------|------|
| **输入搜索** | 在顶部搜索框输入需求，按 Enter |
| **快速标签** | 点击搜索框下方的预置标签（如"Unit 1 资源"、"同步词汇"） |
| **近期搜索** | 点击近期搜索过的词，一键重复搜索 |
| **首页触发** | 首页 AI 搜索框输入后自动跳转到搜索页 |

### 3.2 搜索过程的反馈

```
输入 → 按 Enter → 「小天正在理解你的意图...」（400ms）
     → 展示结果：意图摘要 + 筛选标签 + 资源列表
```

### 3.3 结果中你可以做什么

| 操作 | 说明 |
|------|------|
| **筛选** | 顶部筛选标签可以按资源类别缩小范围（如只看"同步听力"） |
| **预览** | 点击资源卡片的「预览」按钮查看资源详情 |
| **布置** | 点击「布置」将该资源布置给学生 |
| **加入试卷篮** | 把多个资源加入试卷篮，统一管理后一起布置 |
| **展开折叠** | 资源分组支持展开/折叠，默认展开精准匹配，折叠推荐资源 |
| **查看全部** | 每个分组超过显示上限时，可点击"查看全部"展开 |

## 四、特殊情况的处理

### 4.1 搜不到精确结果时

如果你搜的内容没有精确匹配，小天不会直接说"没找到"，而是：

- **替代推荐**：按「当前单元」「同年级推荐」「非当前单元」三个维度推荐相近资源
- **例如**：搜"听说练习"但当前教材版本不支持听说，会收到"当前单元"和"同年级推荐"两组替代资源

### 4.2 完全无法识别时

如果输入内容无法被理解，会展示**快捷入口**卡片，引导你快速到达常用功能：

- "搜 Unit 1 资源"
- "搜同步词汇"
- "搜听力练习"

### 4.3 搜索结果为空但有功能入口

当你**只搜了一个英文单词**时——比如搜 `welcome`——小天会识别到这是单词查询，自动弹出「讲词」入口，点击后打开该词的**全屏讲词页**，包含词义、例句、搭配和教学资源。

## 五、搜索范围与限制

| 维度 | 当前支持 |
|------|---------|
| **教材版本** | 基于当前教学上下文（教师设定的教材） |
| **年级学段** | 小学/初中/高中，按教师身份自动关联 |
| **教学单元** | 识别当前教学进度，优先推荐匹配单元的同步资源 |
| **内容来源** | 平台资源库 + 真题试卷库 + 自建题库 |
| **搜索方式** | 关键词匹配 + 自然语言意图识别 |
