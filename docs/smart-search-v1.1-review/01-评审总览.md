# 小天智能助手：首页智能搜索 v1.1 评审总览

> **版本**：v1.1
> **日期**：2026-06-22
> **状态**：已完成，可评审
> **分支**：`feature/smart-search-v1.1`

---

## 一、项目背景

v1.0 使用关键词正则匹配做搜索，覆盖了基础资源搜索场景。v1.1 在零改动 v1.0 搜索引擎的前提下，将搜索升级为"意图理解 + 智能推荐 + 精准跳转"的智能搜索体验。

## 二、核心变化一览

| 维度 | v1.0 | v1.1 |
|------|------|------|
| 匹配方式 | 关键词正则精确匹配 | 35条意图注册表：关键词 + 别名 + 错别字 |
| 结果分组 | 精准匹配组/推荐组/替代组 | 智能匹配推荐 + 智能关联推荐 |
| 我的内容 | 不支持 | 我的答题卡、词表、试卷 |
| 精准跳转 | 不支持 | 报告/错题/备课/错词 → 引导页 |
| 名称匹配 | 仅试卷名称 | 5级匹配：完全/前缀/包含/拆分/模糊 |
| 区域精选 | 仅听说场景 | 14个省份的区域资源 |
| Loading | 简单状态 | AI思考感三步Loading |
| 兜底 | 3个快捷入口 | 9个搜索建议 + 6个常用功能 |

## 三、实现规模

| 维度 | 数量 |
|------|:--:|
| 覆盖意图 | 35条（4精准跳转 + 24资源/功能 + 7legacy） |
| 新增文件 | 12个（intentRegistry、intentHandlers、dataSources、enhancer、nameMatcher、regionMatcher + 5个UI组件） |
| 核心代码 | ~4,800行（含类型定义） |
| UI组件 | 19个（5个v1.1新增） |
| 测试覆盖 | 185条回归全部通过 |

## 四、技术架构

```
SearchPage.tsx (搜索流程编排)
    ├── 精准跳转层: detectPrecisionJump → PrecisionJumpCard
    ├── 意图匹配层: matchV1_1Intent → intentHandlers.buildXxxResult
    ├── 名称匹配层: matchResourceNames → buildNameMatchResult
    ├── 区域匹配层: matchRegionResources → buildRegionMatchResult
    └── v1.0兼容层: matchNewSearch → enhanceSearchResult
```

## 五、关键决策

| 决策 | 理由 |
|------|------|
| 不改动v1.0 searchEngine.ts | 保持向后兼容，v1.1作为增强层叠加 |
| 关键词在intentRegistry集中管理 | 单源真，修改只需一处 |
| 数据源独立封装dataSources.ts | 后续接真实接口只替换数据源 |
| 双分组结构 | "智能匹配推荐+智能关联推荐"比v1.0术语更直观 |
| 精准跳转在搜索引擎之前拦截 | 避免跳转意图触发不必要的搜索 |
