# 场景化演示脚本

> 用于评审演示，按用户故事组织，每个场景包含搜索词 → 页面预期 → 讲解话术 → 对应规则ID。

---

## 场景 1：老师想快速找答题卡

**用户故事**：英语老师需要布置纸笔练习，想快速打开答题卡。

**Demo 搜索词**：`答题卡`、`试卷答题卡`

**演示步骤**：
1. 在搜索框输入"答题卡"，按Enter
2. 观察Loading动画三步式AI思考感
3. 查看小天理解文案："小天理解：你可能想找「答题卡」相关内容，已为你整理可直接使用的答题卡和创建入口。"
4. 查看智能匹配推荐分组的Tab：【全部 5】【我的答题卡 3】【功能入口 2】
5. 点击"我的答题卡"Tab → 仅展示3条我的答题卡
6. 点击"功能入口"Tab → 仅展示新建答题卡 + 三方答题卡
7. 我的答题卡按钮：布置(主)/下载/更多
8. 新建答题卡按钮：立即新建；三方答题卡按钮：去制作
9. 查看右上角"查看我的答题卡 >"入口
10. 查看智能关联推荐：词汇听写/词句听写/篇章默写/应用文/读后续写

**讲解话术**：
"搜'答题卡'后，系统理解为你想找答题卡相关内容。智能匹配推荐包含你的3条答题卡和2个创建入口，通过Tab可以分别查看。关联推荐补充了答题卡搭配使用的听写和写作入口。"

**边界说明**：试卷答题卡 → 答题卡意图，不进入试卷；答提卡/打题卡 → 错别字兼容。

**对应规则ID**：SS-AC-001

**验收点**：Tab正确、按钮正确、精准跳转不混入

## 场景 2：老师想布置听写

**用户故事**：英语老师想快速布置听写练习。

**Demo 搜索词**：`听写`、`词典听写`

**演示步骤**：
1. 搜索"听写"
2. 智能匹配推荐排序：听写功能入口 → 当前单元词汇 → 我的词表
3. 听写功能入口为轻量入口卡（词汇听写/词句听写/自定义篇章默写，按钮"去布置"）
4. 当前单元词汇优先展示：单词听写/听音识词按钮
5. 我的词表主按钮为"听默写"
6. Tab：【全部/听写入口/当前单元词汇/我的词表】

**讲解话术**：
"搜'听写'时，系统理解为你想布置听写练习。智能匹配推荐把听写功能入口放在最前面，方便快速创建。当前单元词汇和我的词表紧随其后。如果搜'词表'，排序会先展示我的词表。"

**边界说明**：听些 → 错别字兼容；默写→主按钮变为布置默写。

**对应规则ID**：SS-DIC-001, SS-WL-001

**验收点**：排序正确、主按钮动态变化、Tab正确

## 场景 3：老师想找自己的词表

**用户故事**：老师之前创建了词表，想快速找到并使用。

**Demo 搜索词**：`词表`、`我的词表`、`Unit 3 课标词汇表`

**演示步骤**：
1. 搜索"词表" → 智能匹配推荐展示我的词表前3条（两列卡片）
2. 每张词表卡片：名称 + 词条数 + 来源 + 快捷动作（听默写/布置默写/跟读背诵/更多）
3. 右上角"查看我的词表 >"
4. 然后展示听写与默写入口
5. 搜索"Unit 3 课标词汇表" → 名称匹配 → 精确命中

**讲解话术**：
"搜'词表'时优先展示我的词表中的3条，可以直接听默写或布置默写练习。如果搜具体词表名称，系统会名称匹配，精确命中我的资源。"

**边界说明**：不展示大面积练习配置表单。

**对应规则ID**：SS-WL-001, SS-NAME-001

**验收点**：我的词表两列、名称匹配精确、无配置表单

## 场景 4：老师想找试卷/真题/区域资源

**用户故事**：老师需要找试卷，包括自己创建的、平台的、以及特定区域的真题资源。

**Demo 搜索词**：`试卷`、`北京真题`、`海淀期末`

**演示步骤**：
1. 搜索"试卷" → 智能匹配推荐：我的试卷5条 + 同步试卷/专项试卷/模拟试卷
2. 我的试卷按钮：预览/去布置/查看
3. 搜索"北京真题" → 区域精选：北京地区真题 → 智能匹配推荐显示区域精选资源
4. 搜索"海淀期末" → 区域精选：海淀区期末试卷

**讲解话术**：
"搜'试卷'时，优先展示我的试卷5条，然后是平台试卷资源。如果带上地区词，比如'北京真题'、'海淀期末'，系统自动识别为区域精选搜索，召回匹配的地区资源。"

**边界说明**：地区词覆盖14个省份；单元卷归入单元练习。

**对应规则ID**：SS-PAPER-001、SS-EXAM-001、SS-REGION-001

**验收点**：我的试卷优先、区域精选生效

## 场景 5：老师想查看报告/错题/错词

**用户故事**：老师想查看学情报告或错题/错词分析。

**Demo 搜索词**：`报告`、`错题`、`错词`

**演示步骤**：
1. 搜索"报告" → 精准跳转卡："小天理解你想查看「报告/学情」相关内容。"→ 按钮"去报告列表"
2. 搜索"错题" → 精准跳转卡："错题统计和错题明细目前仍在错题本中查看。"→ 按钮"去错题本"
3. 搜索"错词" → "已为你推荐词汇洞察，可查看班级错词情况。"→ 按钮"查看词汇洞察"
4. 注意：精准跳转页不展示普通资源、不展示空分组、搜索框保留

**讲解话术**：
"搜'报告''错题''错词'时，系统不会乱推资源，而是精准跳转到对应功能页面。搜索框始终保留，老师可以随时修改搜索词。"

**边界说明**：词汇薄弱 → 精准跳转而非词汇意图。

**对应规则ID**：SS-JUMP-001

**验收点**：精准跳转、不混入资源、搜索框保留

## 场景 6：老师输入不标准

**用户故事**：老师口语化表达、简称、错别字，系统能正确理解。

**Demo 搜索词**：`专门`、`专业`、`答提卡`、`卷纸`、`默一下`、`哈哈哈哈`

**演示步骤**：
1. "专门" → 意图：专项；AI文案："你可能想找「专项」练习"
2. "答提卡" → 意图：答题卡（错别字兼容）
3. "卷纸" → 意图：试卷（口语化表达）
4. "默一下" → 意图：听写与默写（口语化表达）
5. "哈哈哈哈" → 无法识别兜底：搜索建议词 + 常用功能推荐

**讲解话术**：
"系统对老师的表达方式做了兼容：'专门'归到专项、'卷纸'归到试卷、'答提卡'的错别字也能正确识别。完全无法识别时，兜底页面给出搜索建议和常用功能，不展示无关资源。"

**边界说明**：兜底不展示普通资源，常用功能不含"试卷""视频"。

**对应规则ID**：SS-SPECIAL-001、SS-AC-001、SS-FALLBACK-001

**验收点**：关键词归一化、兜底正确

## 场景 7：老师找同步教学资源

**用户故事**：老师备课需要当前单元的听力、课文、视频等资源。

**Demo 搜索词**：`听力`、`课文`、`视频`、`配音`

**演示步骤**：
1. "听力" → 智能匹配推荐：同步听力资源 → 关联：听力专项/听力模拟
2. "课文" → 关联当前单元词汇和听力
3. "视频" → 主题视频作为关联推荐
4. "配音" → 关联主题视频

**讲解话术**：
"搜索同步教学资源时，系统优先匹配当前单元的内容，并在关联推荐中补充专项、模拟等拓展资源。"

**对应规则ID**：SS-LISTEN-001、SS-TEXT-001、SS-VIDEO-001

**验收点**：当前单元优先、关联推荐正确

---

## 场景 8：老师搜索无法识别内容

**用户故事**：老师输错了、或者输入了系统尚不支持的内容。

**Demo 搜索词**：`哈哈哈哈`

**演示步骤**：
1. 不展示智能匹配推荐
2. 不展示智能关联推荐
3. 展示顶部提示："小天暂未准确理解「哈哈哈哈」"
4. 展示"你可以试试这样搜索"：答题卡/词表/词汇听写/单元练习/作文/配音/专项/听力/课文
5. 展示"常用功能推荐"：答题卡/词表/词汇听写/单元练习/作文/配音
6. 搜索建议词可点击，点击后重新搜索

**讲解话术**：
"完全无法识别时，系统不会空展示或乱推资源，而是引导老师尝试常见搜索词和常用功能，帮助老师快速找到想要的内容。"

**对应规则ID**：SS-FALLBACK-001

**验收点**：不展示资源、搜索建议可点击、常用功能不含试卷/视频
