# 小天AI · 英语教师工作台 — 产品规格文档

> 版本：v0.1 · 状态：MVP 设计稿 · 2026-05-26

---

## 1. 产品定位

小天AI 是面向中国初高中英语老师的 **AI 教学助手系统**，而非通用聊天机器人。

核心区别：

| | 通用 AI Chat | 小天AI |
|---|---|---|
| 交互模式 | 对话驱动 | 工作流驱动 |
| 上下文 | 无记忆 | 绑定班级、教材、学情 |
| 输出 | 自由文本 | 结构化教学动作 |
| 入口 | 单一对话框 | 嵌入各教学场景 |

**一句话定位：** 让AI融入教师的日常工作流，而非让教师适应AI的对话模式。

## 2. 用户画像

### 主要用户：中学英语教师

| 维度 | 描述 |
|---|---|
| 年龄段 | 25–45岁，主力30–38岁 |
| 技术水平 | 会用智能手机、办公软件，非技术背景 |
| 工作痛点 | 备课耗时、作业批改量大、学情跟踪靠记忆 |
| 核心诉求 | 减负、提效、精准教学 |

### 典型的一天

> 王老师，32岁，带2个班共84名学生。
> 上午批改作文6篇花了1小时，下午要准备Unit 4的听力材料，
> 晚上还要整理本周练习报告。她想：如果AI能在每个环节帮我省15分钟就好了。

### 用户分级

| 层级 | 占比 | 特征 |
|---|---|---|
| 核心用户 | 60% | 日常高频使用错词本、练习报告、作文批改 |
| 中度用户 | 30% | 每周2-3次，使用资源库、AI搜索 |
| 轻度用户 | 10% | 偶尔使用，主要是首页AI问答 |

## 3. 核心场景

### 场景总览

```
课前备课 ──────→ 课堂教学 ──────→ 课后作业 ──────→ 阶段评测
   │                                    │                │
   ▼                                    ▼                ▼

| 阶段评测 | 分析成绩、制定计划 | AI洞察：趋势分析、弱项识别、教学建议 |
| 日常答疑 | 查单词用法、问语法 | AI问答，自动带入当前教材上下文 |

| 折叠态 | 默认 | 显示为右下角圆形按钮（✨） |
| 展开态（默认尺寸） | 点击按钮或首页右侧区域 | 380px宽浮层，显示对话界面 |

| 最小化 | 点击最小化 | 收缩为顶部条，保留当前对话 |

### 浮层内部结构

```
┌──────────────────────┐
│ ✨ 小天AI助手    [_][□][×] │  ← 标题栏
├──────────────────────┤
│                      │
│  欢迎语 + 快捷入口    │  ← 初始态
│  · 帮我出10道单选题   │
│  · 分析本周错词      │

│  · 推荐听力材料      │
│                      │
│  ──── 对话区域 ────  │  ← 消息列表
│                      │
│  [教师提问]          │
│  [AI回复，含结构化卡片]│

### 浮层交互规则

- 在任意页面均可唤起浮层

- 浮层输出支持结构化组件：卡片、表格、列表、图表
- 支持附件上传（图片、文档）

## 6. AI搜索

### 定位

AI搜索是教师快速查找教学资源的入口，区别于通用搜索的关键在于**自动带入教材上下文**。

### 搜索流程

```
输入关键词 → AI识别意图 → 匹配教材内容 → 返回结构化结果
                │
                ├── 词汇查询：返回释义、例句、用法对比
                ├── 语法查询：返回规则说明、例句、易错点
                ├── 资源查询：返回匹配的练习题、音频、视频
                └── 教学问题：返回结构化建议
```

### 搜索结果模板

| 意图类型 | 结果结构 |
|---|---|
| 词汇查询 | 音标、释义、例句（3句）、常见搭配、与本单元关联 |
| 语法查询 | 规则概述、例句、易错提醒、对应教材页码 |
| 资源查询 | 资源卡片列表（类型标签、难度、时长、来源） |
| 宽泛问题 | 分段回答，附带追问建议 |

### 教材感知

搜索时系统自动附加当前顶部栏选择的 **教材版本 + 年级 + 单元** 作为隐藏上下文，教师无需每次手动输入。

## 7. AI洞察

### 定位

AI洞察不是数据看板，而是**可操作的教学建议**。每条洞察必须指向具体的学生或知识点，并给出建议动作。

### 洞察卡片格式

```
┌─────────────────────────────────────────────┐
│ 💡 AI 洞察                                  │
│                                             │
│ 本周班级整体词汇掌握率提升 3%。              │
│ 建议重点关注 张小明、李华 的作文训练，      │
│ 两人在时态运用上存在相似错误。              │
│ 错词高频集中在 Unit 3 的食物类词汇。        │
│                                             │
│ [查看详情 →]  [生成专项练习]   [忽略]       │
└─────────────────────────────────────────────┘
```

### 洞察分级

| 级别 | 标识 | 含义 | 示例 |
|---|---|---|---|
| 提醒 | 蓝 | 正常信息 | "本单元生词可结合Unit 2食物主题扩展" |
| 注意 | 黄 | 需要关注 | "刘洋成绩连续2次下滑" |
| 预警 | 红 | 需要立即行动 | "阅读理解正确率跌破50%，需专项训练" |

### 洞察生成时机

- 首页：每次加载时刷新，总结最近7天
- 错词本/错题本：进入页面时，针对当前数据给出总结
- 练习报告：查看单份报告时，针对该学生给出个性化建议
- 写作批改：批改完成后自动生成

## 8. Workflow 机制

### 核心理念

Workflow 是把 **多步骤教学任务** 串联为自动化流程。教师一键触发，AI按步骤执行并输出结构化结果。

### Workflow 示例：出卷流程

```
[触发] 教师：帮我出一份Unit 3的单元测验卷

步骤1 ─→ 分析Unit 3知识点和重难点
步骤2 ─→ 根据知识点分布生成题型矩阵
步骤3 ─→ 生成题目（单选10 + 完形1 + 阅读2 + 写作1）
步骤4 ─→ 根据学生错题本，为薄弱项加题
步骤5 ─→ 排版输出为可打印格式

[输出] Word/PDF + 答案 + 评分标准
```

### 已规划的 Workflow

| Workflow | 触发方式 | 步骤数 | 输出 |
|---|---|---|---|
| 出卷 | AI浮层 / 首页快捷入口 | 5 | Word文档 |
| 生成练习纸 | 错词本"生成练习" | 3 | PDF练习纸 |
| 单元报告 | 练习报告页"生成" | 4 | 班级报告PDF |
| 批改作文 | 写作批改页"上传" | 3 | 批改结果+评分 |

### Workflow 进度展示

```
┌─────────────────────────────────────┐
│ 🤖 正在生成练习卷...                │
│                                     │
│ ✓ 分析知识点                        │
│ ✓ 生成题型矩阵                      │
│ ● 生成题目（进行中...）             │
│ ○ 个性化调整                        │
│ ○ 排版输出                         │
│                                     │
│ [预计还需 15 秒]                    │
└─────────────────────────────────────┘
```

## 9. 错词本

### 功能定位

自动归集学生在练习和测试中拼错的单词，提供结构化展示和练习生成。

### 页面结构

- 顶部：AI洞察卡片（高频错词总结 + 教学建议）
- 主体：错词列表（表格形式）
  - 正确拼写、中文释义、常见错误写法、错误次数
- 操作：
  - 按单元/频率筛选
  - 选中错词 → 一键生成专项练习
  - 导出错词表（PDF/打印）
  - 标记“已强化”（教师手动标记教学后清零）

### 数据来源

| 来源 | 采集方式 |
|---|---|
| 在线练习 | 系统自动采集拼写错误 |
| 手写批改 | 教师拍照上传，AI识别标注 |
| 考试试卷 | 扫描后AI提取 |

### 页面临界状态

| 状态 | 展示 |
|---|---|
| 空数据 | 插图 + "暂无错词数据，开始收集后可在此查看" |
| 加载中 | 骨架屏（表格行占位） |
| 数据过多 | 分页 + 搜索 + 按单元筛选 |

## 10. 错题本

### 功能定位

自动归集语法、阅读理解、完形填空等题型的错题，按题型和知识点分类。

### 页面结构

- 顶部：AI洞察卡片（高频失分题型 + 知识盲区总结）
- 筛选栏：按题型筛选（全部/单选/完形填空/阅读理解/句型转换）
- 主体：错题列表（表格形式）
  - 题型、所属单元、题干、正确答案、错误人数、正确率（进度条）
- 操作：
  - 点击展开查看详情（题目完整内容 + 选项 + 解析）
  - 选中错题 → 生成举一反三变式题
  - 导出错题集

### AI增强

- 每道错题附带AI生成的解题思路
- 同类错题自动聚类，识别“知识点盲区”
- 根据错题推荐针对性练习题

## 11. 写作批改

### 功能定位

教师上传学生作文（图片或文本），AI自动批改并生成结构化反馈。

### 页面结构

- 顶部：AI洞察卡片（批次批改进度 + 共性问题总结）
- 上传区：拖拽上传图片/文本，支持批量
- 批改结果卡片：
  - 原文 + 错误标注（语法、拼写、时态、搭配…）
  - 分项评分：内容、结构、语法、词汇
  - AI总评 + 修改建议
  - 教师可二次编辑评语

### 批改流程

```
上传图片/文本 → OCR识别（如为图片） → AI逐句批注 → 分项评分 → 生成总评 → 教师确认/修改 → 归档
```

### 批改标注类型

| 标注类型 | 颜色 | 示例 |
|---|---|---|
| 语法错误 | 红 | 时态、主谓一致 |
| 拼写错误 | 橙 | 单词拼写 |
| 搭配不当 | 黄 | 介词、固定搭配 |
| 表达建议 | 蓝 | 可优化的表达 |

### 页面临界状态

| 状态 | 展示 |
|---|---|
| 未上传 | 拖拽上传引导区 |
| 批改中 | 进度指示 + 预估时间 |
| 批改完成 | 结果卡片列表 |
| 识别失败 | 错误提示 + 重试/手动输入 |

## 12. 听力/听说

### 功能定位

提供听力材料和AI听说练习，支持课堂播放和课后练习。

### 页面结构

- 顶部：AI洞察卡片（班级听力弱项分析）
- 素材筛选：按教材单元、难度、类型（对话/独白/新闻）
- 素材列表卡片：
  - 标题、时长、难度标签、来源
  - 播放按钮 + 查看文稿
- 操作：
  - 下载音频
  - 生成配套练习题
  - AI生成听说对话脚本

### AI功能

- 输入关键词 → AI生成定制听力材料（文本 + TTS语音）
- 口语评分：学生朗读后AI评分（发音、流利度、完整度）
- 听力文本自动标注难度等级（CEFR对标）

## 13. 资源库

### 功能定位

教学资源的统一管理和检索入口，支持AI智能推荐。

### 页面结构

- 搜索栏（AI搜索）
- 分类标签：课件、练习卷、听力音频、视频、教案
- 筛选：教材版本、年级、单元、类型、难度
- 资源卡片网格：
  - 类型图标、标题、来源、大小/时长
  - 预览/下载按钮

### 资源类型

| 类型 | 格式 | 来源 |
|---|---|---|
| 课件 | PPT/PDF | 教师上传 + 系统内置 |
| 练习卷 | PDF/Word | 系统生成 + 教师上传 |
| 听力音频 | MP3 | 系统内置 + AI生成 |
| 视频 | MP4 | 外部链接 + 上传 |
| 教案 | PDF/DOC | 教师上传 + AI生成模板 |

### AI推荐

- 根据当前教学进度自动推荐匹配资源
- 关联错词/错题数据，推荐针对性补充材料

## 18. 产品设计原则

### 18.1 AI隐身

AI不作为独立的“角色”存在，而是嵌入每个功能中。教师感受到的是“系统很智能”，而非“我在和一个AI对话”。

### 18.2 教师主权

AI的建议永远是建议，教师可以采纳、修改或忽略。所有AI生成的内容（批改、评语、报告）都允许教师二次编辑后再发布。

### 18.3 减负优先

功能设计第一准则：这个功能有没有帮老师省时间？如果增加了老师的操作步骤，即使看起来很智能，也不做。

### 18.4 渐进式展示

- 信息层级清晰：每个页面先展示AI洞察总结（一眼看完），再展示详细数据
- 避免一次性展示过多数据
- 关键指标突出，细节可展开

### 18.5 教材为中心

所有功能围绕教材组织，而非围绕AI能力组织。AI的上下文始终包含教材版本、年级、单元。

### 18.6 离线可用

核心数据（错词本、错题本、资源库）应支持离线查看。AI功能需要网络，但查看已有数据不需要。

### 18.7 专业克制

- 配色：浅色为主，蓝色/indigo为辅，教育行业专业感
- 字体：系统默认中文字体，保证可读性
- 图标：简洁线性图标（lucide风格）
- 动画：仅在必要时使用微动效，不炫技
- 语言：专业但亲切，避免技术黑话
