## 1. 版本定位

v1.1 不是重做智能搜索，而是在 v1.0 基础上增强：

1. 搜索从"关键词命中"升级为"意图识别 + 智能匹配推荐 + 智能关联推荐"。
2. 支持老师的口语化表达、简称、近义词、错别字和模糊表达。
3. 支持我的内容推荐，包括我的答题卡、我的词表、我的试卷。
4. 支持资源名称匹配，包括试卷名称、课本名称、章节名称、课本试卷名称、我的试卷名称等。
5. 支持地区词匹配，带地区的试卷、真题、模拟、检测等搜索需要召回区域精选资源。
6. 支持"已识别但当前入口不承接"的精准跳转，例如报告、错题本、备课。
7. 完全无法识别时，采用"搜索建议 + 常用功能推荐"的组合兜底。

### 1.1 与 v1.0 的关系

| 维度 | v1.0 | v1.1 |
|------|------|------|
| 匹配方式 | 关键词正则精确匹配 | 关键词匹配 + 别名/近义词/错别字模糊匹配 |
| 结果分组 | 精准匹配组 + 推荐组 + 替代组 | 智能匹配推荐 + 智能关联推荐（统一双分组） |
| 我的内容 | 不支持 | 我的答题卡/我的词表/我的试卷 |
| 名称匹配 | 仅试卷名称（省份+年份+考试类型） | 全面名称匹配（试卷/课本/章节/个人资源） |
| 地区匹配 | 仅听说场景简单检查 | 区域精选资源召回 |
| 精准跳转 | 不支持 | 报告/错题本/备课/词汇洞察等已识别场景引导跳转 |
| Loading | 简单"搜索中" | AI 思考感文案 |
| 兜底 | 3 个快捷入口 | 搜索建议词 + 常用功能推荐 |
| 新增意图 | — | 套题/微技能/选题组卷/自定义批改 等 |

### 1.2 技术实现建议

v1.1 建议在 v1.0 规则引擎基础上扩展：
- 新增意图匹配规则（不删除 v1.0 已有规则）
- 新增别名/近义词/错别字映射表
- 新增"我的内容"数据源接入
- 新增名称匹配索引
- 双分组结构替代现有分组逻辑
- AI 理解文案生成逻辑

## 2. 搜索结果统一分组

所有搜索结果统一使用两个分组：

### 智能匹配推荐

展示与老师搜索词关联性最强、最直接命中的内容。

例如：

- 搜"答题卡"：展示我的答题卡、新建答题卡、三方答题卡。
- 搜"试卷"：展示我的试卷、同步试卷、专项试卷、模拟试卷。
- 搜"听力"：展示当前同步单元听力。
- 搜"作文"：展示自定义应用文、自定义读后续写。
- 搜"专项"：展示专项分类下的资源。

### 智能关联推荐

展示小天基于搜索意图联想到的补充资源。

例如：

- 搜"听力"：关联听力专项、听力模拟。
- 搜"视频"：关联主题视频。
- 搜"主题视频"：关联当前单元视频。
- 搜"配音"：关联主题视频。
- 搜"专项"：关联同步和模拟中同能力方向的资源。

**如果没有关联结果，则不展示"智能关联推荐"分组。**

### 2.1 分组展示规则

| 分组 | 默认状态 | 展示上限 | 超出处理 |
|------|:--:|:--:|------|
| 智能匹配推荐 | 展开 | 前 5 条 | 折叠，支持"查看更多"展开 |
| 智能关联推荐 | 展开 | 前 3 条 | 折叠，支持"查看更多"展开 |

### 2.2 分组内排序

每个分组内按以下优先级排序：
1. 完全匹配（名称/关键词精确命中）
2. 前缀匹配
3. 连续包含匹配
4. 多关键词命中
5. 当前上下文匹配（教材/年级/单元）
6. 我的资源优先于平台资源
7. 最近更新/最近使用优先

## 3. 顶部 AI 理解文案与 Loading

### 3.1 AI 理解文案

搜索结果顶部需要展示"小天理解"文案。

**通用模板**：

> 小天理解你可能想找「{意图关键词}」
> 已为你整理智能匹配结果，并补充相关资源。

**具体意图示例**：

| 搜索词 | AI 理解文案 |
|------|------|
| 答题卡 | 小天理解你可能想找「答题卡相关功能」。已为你整理智能匹配结果，并补充相关资源。 |
| 听力 | 小天理解你可能想找「听力练习资源」。已为你整理智能匹配结果，并补充相关资源。 |
| 试卷 | 小天理解你可能想找「试卷资源」。已为你整理智能匹配结果，并补充相关资源。 |
| 错题 | 小天理解你想查看「错题 / 错题本」相关内容。已为你引导到对应功能入口。 |

### 3.2 Loading 文案

搜索 Loading 不使用普通"加载中"，需要包装成 AI 思考感。

**通用 Loading 序列**（建议每步展示约 0.5-1 秒）：

1. "小天正在理解你的需求..."
2. "正在匹配相关功能和资源..."
3. "正在为你整理推荐结果..."

**意图明确的 Loading**（搜索词含义清晰时）：

1. "小天正在理解「{搜索词}」的相关场景..."
2. "正在匹配{具体匹配内容描述}..."
3. "已为你整理相关结果。"

**意图明确的 Loading 示例**：

| 搜索词 | Loading 序列 |
|------|------|
| 答题卡 | ① 小天正在理解「答题卡」的相关场景... ② 正在匹配创建、管理、制作和相关练习入口... ③ 已为你整理相关结果。 |
| 听力 | ① 小天正在理解「听力」的相关场景... ② 正在匹配同步听力、听力专项和模拟资源... ③ 已为你整理相关结果。 |
| 词表 | ① 小天正在理解「词表」的相关场景... ② 正在匹配我的词表、听写默写和单元词汇... ③ 已为你整理相关结果。 |

### 3.3 搜索词明确性判定

- 搜索词匹配到明确的意图关键词 → 使用"意图明确的 Loading"
- 搜索词为模糊表达或未命中关键词 → 使用"通用 Loading 序列"
- 搜索词过短（1-2 字）或纯英文单词 → 使用"通用 Loading 序列"

## 31. 名称匹配规则

除意图关键词匹配外，智能搜索需要支持资源名称匹配。

### 31.1 支持匹配范围

1. 试卷资源名称。
2. 课本名称。
3. 课本章节名称。
4. 课本试卷/同步练习名称。
5. 我的试卷中的资源名称。
6. 我的答题卡名称。
7. 我的词表名称。
8. 其他用户个人资源名称。

### 31.2 匹配方式

名称匹配不要求完全匹配，支持：

| 匹配级别 | 说明 | 示例 |
|:--:|------|------|
| 完全匹配 | 搜索词与资源名称完全一致 | 搜"Unit 3 Food and Drinks" → 精确匹配同名课本 |
| 前缀匹配 | 资源名称以搜索词开头 | 搜"Unit 3" → 匹配"Unit 3 Food and Drinks" |
| 连续包含匹配 | 资源名称中连续包含搜索词 | 搜"Food" → 匹配"Unit 3 Food and Drinks" |
| 关键词拆分匹配 | 搜索词拆分后的核心关键词，在资源名称中命中 2 个及以上 | 搜"山东中考英语" → 拆分"山东""中考""英语"，命中 2+ 即匹配 |
| 轻度模糊匹配 | 支持错别字、大小写、空格、中英文符号差异 | 搜"答提卡" → 匹配"答题卡"；搜"unit3" → 匹配"Unit 3" |

### 31.3 名称匹配召回最低门槛

1. 搜索词与资源名称完全一致；
2. 资源名称以搜索词开头；
3. 资源名称中连续包含搜索词；
4. 搜索词拆分后的核心关键词，在资源名称中命中 2 个及以上；
5. 短词或泛词需结合当前教材、单元、地区、资源类型等上下文共同判断；
6. 支持错别字、大小写、空格、中英文符号差异的轻度模糊匹配。

### 31.4 名称匹配排序

完全匹配 > 前缀匹配 > 连续包含匹配 > 多关键词命中 > 轻度模糊匹配 > 当前上下文匹配 > 我的资源 > 最近更新/最近使用 > 平台资源。

**在匹配程度相同的情况下**，我的试卷、我的答题卡、我的词表等老师个人资源优先于平台资源。

### 31.5 名称匹配展示

- 默认展示前 5 条名称匹配结果。
- 提供"查看更多资源"入口（展开或跳转对应列表页）。

## 33. 优先级与排除规则

### 33.1 意图优先级总规则

按以下优先级处理：

**具体名称匹配 > 精确意图词 > 子意图词 > 泛意图词 > 关联推荐 > 兜底推荐。**

### 33.2 特殊优先级

以下特殊优先级需要在意图识别中正确处理：

1. **听力模拟**优先于听力和模拟。
2. **听力专项**优先归入专项，不归入普通听力。
3. **真题**优先于专项。
4. **主题视频**优先于普通视频。
5. **趣味配音**优先于普通视频。
6. **试卷答题卡**优先归入答题卡，不归入普通试卷。
7. **读后续写**优先归入写作类，不归入普通阅读。
8. **微技能**优先于泛专项。
9. **专门、专业**归一为专项。
10. 包含"听说"的搜索词**不归入普通听力**。
11. 模拟意图需**排除"听力模拟"**。

### 33.3 排除规则速查表

| 搜索词 | 应命中意图 | 不应命中的意图 |
|------|------|------|
| 听力模拟/听力模考 | 听力模拟 | 听力、模拟 |
| 听力专项 | 专项 | 普通听力 |
| 听说练习 | 听说 | 普通听力 |
| 主题视频 | 主题视频 | 普通视频 |
| 趣味配音 | 配音 | 普通视频 |
| 试卷答题卡 | 答题卡 | 试卷 |
| 读后续写 | 写作 | 阅读 |
| 微技能 | 微技能 | 泛专项 |
| 专门/专业 | 专项 | — |

### 33.4 意图识别流程（v1.1 增强版）

```
用户输入 query
    ↓
预处理：trim → 空检查 → 无意义检查
    ↓
意图识别（按优先级依次匹配）：
    ↓
┌─ 1. 名称精确匹配（资源名称完全一致）─── 名称匹配结果
│  2. 名称模糊匹配（前缀/包含/拆分/错别字）
│  3. 特殊子意图（听力模拟/微技能/试卷答题卡 等）
│  4. 精确意图词（答题卡/词表/写作/真题 等）
│  5. 子意图词（应用文/读后续写/单元练习 等）
│  6. 泛意图词（练习/试卷/听力/语法/阅读 等）
│  7. 精准跳转意图（报告/错题/备课/错词 等）
│  8. 兜底（搜索建议+常用功能推荐）
└──────────────────────────────────────────
    ↓
意图命中 → 生成双分组结果：
  - 智能匹配推荐
  - 智能关联推荐（可空）
    ↓
生成 AI 理解文案 + Loading 序列
    ↓
返回结果给前端渲染
```

### 33.5 与 v1.0 优先级体系的兼容

v1.1 的优先级体系是 v1.0 8 级优先级的**增强版**，而非替代：

| v1.0 优先级 | v1.1 对应 |
|------|------|
| P1 功能入口关键词 | 融入各意图（答题卡/词表/听写/批改等） |
| P2 试卷名称精确搜索 | 融入名称匹配 + 试卷意图 + 区域精选 |
| P3 同步词汇搜索 | 融入词表/词汇意图 |
| P4 同步课文搜索 | 融入课文意图 |
| P5 资源类型搜索（12 子优先级） | 融入各对应意图，增加子意图/排除规则 |
| P6 Unit N + 资源类型组合 | 融入名称匹配（名称中包含 Unit 识别） |
| P7 模糊/默认 | 融入练习/作业意图 |
| P8 完全无法识别 | 增强为搜索建议+常用功能推荐兜底 |
