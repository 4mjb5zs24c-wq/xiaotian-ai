# 小天AI · 交互规则文档

> 版本：v0.1 · 2026-05-26

---

## 0. 核心铁律

**小天AI是工作流助手，不是聊天机器人。**

一切交互设计的出发点：

| ❌ 聊天机器人做法 | ✅ 小天AI做法 |
|---|---|
| 等用户来聊 | 嵌入教学场景主动提供帮助 |
| 回答通用问题 | 回答带有教材/班级上下文 |
| 纯文本回复 | 输出结构化卡片、表格、可操作组件 |
| 无状态 | 记住教师当前教材、年级、班级 |
| 被动响应 | 主动推送洞察和待办 |
| 自由对话 | 围绕教学workflow执行任务 |

---

## 1. AI助手行为规范

### 1.1 身份定义

- 名称：小天
- 定位：英语教师的教学工作助手
- 语气：专业、简洁、可执行，不使用技术黑话
- 人称：用"你"称呼教师

### 1.2 回复规则

| 规则 | 说明 |
|---|---|
| 教学优先 | 所有回复必须关联教学场景，不说废话 |
| 可执行 | 每条建议必须是教师能立刻做的动作 |
| 上下文感知 | 自动带入当前教材版本、年级、单元、班级 |
| 结构化输出 | 避免大段文字，优先使用卡片、列表、表格 |
| 留有余地 | 以"你可以修改后使用"结尾，维护教师主权 |

### 1.3 禁止行为

- 禁止扮演"老师"角色去教教师
- 禁止给出无法执行的模糊建议
- 禁止在无上下文时进行冗长对话
- 禁止使用"作为AI"开头的句子
- 禁止推荐与当前教材无关的内容

## 2. AI搜索规则

### 2.1 入口

- 页面顶部搜索栏（资源库页面常驻）
- AI浮层内输入框（任意页面）

### 2.2 意图识别

系统根据输入内容自动判断意图：

| 意图类型 | 触发词示例 | 行为 |
|---|---|---|
| 词汇查询 | "xxx是什么意思"、单个英文单词 | 弹出词汇卡片 |
| 语法查询 | "怎么用"、"语法"、"区别" | 返回语法讲解 + 例句 |
| 资源检索 | "有没有"、"帮我找"、"练习" | 返回资源卡片列表 |
| 出题请求 | "出几道"、"生成练习"、"来几题" | 触发Workflow |
| 数据查询 | "最近"、"统计"、"情况" | 跳转对应页面或浮层展示 |
| 批改请求 | "批改"、"看下这篇" | 跳转写作批改页 |

### 2.3 搜索结果模板

#### 词汇卡片
```

│ n. 餐厅，餐馆            │
│                         │
│ 例句：                   │
│ · We had dinner at a    │
│   French restaurant.    │
│ · The restaurant serves │
│   Italian food.         │
│                         │
│ 常见搭配：               │
│ fast food restaurant    │

```

## 3. AI洞察卡片规则

### 3.1 出现位置

每个功能页面顶部均有AI洞察卡片。

| 页面 | 洞察内容 |
|---|---|
| 首页 | 本周学情总结 + 重点关注建议 |
| 错词本 | 高频错词分析 + 教学建议 |
| 错题本 | 高频失分题型 + 知识盲区识别 |
| 练习报告 | 成绩趋势分析 + 个性化建议 |
| 写作批改 | 批改进度 + 共性问题 |
| 听力/听说 | 听力弱项分析 |
| 资源库 | AI推荐匹配资源 |

### 3.2 洞察卡片格式

```
┌────────────────────────────────────────────┐
│ 💡 AI 洞察                                 │
│                                            │
│ [洞察正文：2-3句话，包含关键数据和具体建议] │
│                                            │
│ [操作按钮]                                 │
└────────────────────────────────────────────┘
```

### 3.3 洞察分级与触发条件

| 级别 | 颜色 | 触发条件 | 示例 |
|---|---|---|---|
| 常规 | 蓝/indigo | 正常数据，无异常 | "词汇掌握率保持稳定" |
| 关注 | 黄/amber | 指标连续2次下降，或低于班级均分15% | "刘洋成绩连续2次下滑" |
| 预警 | 红/red | 指标跌破临界值，或连续3次下降 | "阅读理解正确率跌破50%" |

### 3.4 洞察操作

每条洞察至少包含一个可操作按钮：

| 按钮 | 行为 |
|---|---|
| 查看详情 | 跳转到对应页面/展开详细数据 |
| 生成专项练习 | 触发出题Workflow |
| 忽略 | 标记为已读，不再提醒（仅本次） |

## 4. Workflow触发规则

### 4.1 触发方式

| 方式 | 场景 |
|---|---|
| 首页快捷入口 | "出一份练习""批改作文"等按钮 |
| AI浮层输入 | 教师输入自然语言指令 |
| 页面内按钮 | 错词本"生成练习"、错题本"举一反三"等 |
| 工具栏 | 顶部栏"导出PDF""生成报告"等 |

### 4.2 Workflow 执行规则

```
触发 → 参数确认 → 分步执行 → 进度展示 → 结果输出
        │                         │
        └── 自动填充教材/年级/班级   └── 结构化输出+下载
```

### 4.3 进度展示规则

```
┌─────────────────────────────────┐
│ 🤖 [工作流名称]                 │
│                                 │
│ ✓ 步骤1（已完成）               │
│ ✓ 步骤2（已完成）               │
│ ● 步骤3（进行中…）              │
│ ○ 步骤4                         │
│ ○ 步骤5                         │
│                                 │
│ 预计还需 [N] 秒                 │
└─────────────────────────────────┘
```

### 4.4 Workflow 输出规则

| 输出类型 | 格式 | 交互 |
|---|---|---|
| 练习卷 | PDF | 预览 + 下载 + 打印 |
| 报告 | PDF | 预览 + 下载 |
| 批改结果 | 页面内卡片 | 逐篇查看 + 编辑评语 |
| 听力材料 | MP3 + 文本 | 播放 + 下载 + 配套练习 |

## 5. 右侧浮层规则

### 5.1 浮层状态机

```
折叠态 ──点击按钮──→ 展开态 ──拖拽/放大──→ 全屏态
  ↑                    │                      │
  └───点击最小化───────┘                      │
  ↑                                           │
  └──────────────点击收缩─────────────────────┘
```

### 5.2 各状态尺寸

| 状态 | 宽度 | 高度 | 位置 |
|---|---|---|---|
| 折叠态 | 48px（圆形按钮） | 48px | 右下角固定 |
| 展开态 | 380px | 60vh | 首页右侧 / 右下角弹出 |
| 全屏态 | 100%主内容区 | 100%主内容区 | 覆盖主内容区 |

### 5.3 上下文感知规则

浮层打开时，根据当前页面自动加载上下文：

| 当前页面 | 自动加载的上下文 |
|---|---|
| 首页 | 班级概况、本周学情摘要 |
| 错词本 | 当前错词列表摘要、高频错误类型 |
| 错题本 | 当前错题数据摘要、高频失分题型 |
| 练习报告 | 当前查看的学生/班级报告数据 |
| 写作批改 | 当前批改中的作文内容和学生信息 |
| 听力/听说 | 当前筛选的单元和素材信息 |
| 资源库 | 当前筛选条件和教材版本 |

### 5.4 初始态内容

浮层首次打开（无历史对话）时，展示：

## 6. 教师操作路径

### 6.1 高频路径定义

#### 路径A：早上到校 → 查看班级状态
```
打开系统 → 首页
  → 看AI洞察卡片（本周学情总结）
  → 看统计卡片（学生数、练习数、正确率、待批改）
  → 看教学提示（待办事项）
  → 开始备课
```

#### 路径B：课间 → 快速出练习
```
首页 → 点击快捷入口"出一份练习"
  → AI浮层展开，自动填充单元信息
  → 教师确认/修改题型和数量
  → Workflow执行
  → 预览 → 下载 → 打印
```

#### 路径C：下午 → 批改作文
```
首页 → 点击"写作批改"（或顶部入口）
  → 上传作文图片
  → AI批改中（进度展示）
  → 逐篇查看批改结果
  → 教师修改评语 → 确认
```

#### 路径D：周五 → 准备下周听力
```
首页 → 点击"听力/听说"
  → 筛选下周单元
  → 浏览素材列表
  → 选中素材 → 点击"生成配套练习"
  → 下载音频和练习
```

#### 路径E：考前 → 综合复习
```
首页 → 查看AI洞察 → 确定弱项
  → 错词本 → 选中高频错词 → 生成专项练习
  → 错题本 → 筛选薄弱题型 → 生成变式题
  → 练习报告 → 确认重点关注学生
  → 资源库 → 搜索综合练习卷
```

### 6.2 路径切换规则

- 侧边栏导航始终可用，允许任意切换页面
- 切换页面时，AI浮层保持当前对话上下文
- 浏览器前进/后退按钮正常支持路由跳转

## 7. 搜索意图识别

### 7.1 意图分类

```
教师输入
    │
    ├── 包含"出""生成""来几道""练习""试卷"
    │   → 意图：出题 → 触发Workflow
    │
    ├── 包含"批改""修改""看下""这篇""作文"
    │   → 意图：批改 → 跳转写作页
    │
    ├── 单个英文单词或"xxx是什么意思"
    │   → 意图：词汇查询 → 展示词汇卡片
    │
    ├── 包含"怎么用""语法""区别""为什么"
    │   → 意图：语法查询 → 展示语法讲解
    │
    ├── 包含"有没有""帮我找""推荐""资源""素材"
    │   → 意图：资源检索 → 返回资源列表
    │
    ├── 包含"最近""统计""情况""报告""分析"
    │   → 意图：数据查询 → 展示数据卡片或跳转
    │
    └── 其他
        → 意图：通用教学问答 → AI自由回答
```

### 7.2 意图确认规则

- 出题意图：确认单元、题型、数量、难度
- 批改意图：引导上传文件
- 资源意图：直接展示结果
- 查询意图：直接展示数据
- 问答意图：直接回答

### 7.3 模糊意图处理

当意图不明确时：

```
我不太确定你想要什么，可以：
· 出一道题 → 试试说"帮我出10道单选题"
· 批改作文 → 试试说"批改这篇作文"
· 查单词   → 试试直接输入单词
· 找资源   → 试试说"有没有Unit 3的听力材料"
```

## 9. 推荐内容规则

### 9.1 AI推荐（资源库）

资源库底部的AI推荐卡片根据以下信号生成：

| 信号 | 权重 | 说明 |
|---|---|---|
| 当前教学进度 | 高 | 匹配当前教材单元 |
| 错词/错题数据 | 高 | 针对薄弱知识点推荐补充材料 |
| 教学日历 | 中 | 临近考试推荐复习资料 |
| 教师使用历史 | 低 | 基于过往下载记录推荐 |

### 9.2 教学提示（首页）

首页右侧教学提示基于：

| 信号 | 示例 |
|---|---|
| 待批改作文数 | "今天有 6 篇作文待批改" |
| 教学进度提醒 | "Unit 3 词汇测试时间建议本周五" |
| 资源更新 | "听力资源更新：新概念英语第 12 课" |

### 9.3 推荐频率

- 首页：每次刷新/进入时更新
- 资源库：进入页面时更新
- AI洞察：进入对应页面时更新
- 不重复展示已被"忽略"的推荐

## 10. 页面状态切换规则

### 10.1 全局状态

| 状态 | 说明 |
|---|---|
| 当前教材 | 默认"人教版"，可在顶部栏切换 |
| 当前年级 | 根据教材自动推断，默认"七年级上" |
| 当前班级 | 默认"七年级(3)班"，可在顶部栏切换 |
| AI浮层状态 | 折叠/展开/全屏，跨页面保持 |

### 10.2 页面切换行为

| 切换方式 | 行为 |
|---|---|
| 侧边栏导航 | 页面切换 + 路由更新 + 新页面数据加载 |
| AI浮层内跳转 | 浮层保持展开 + 主内容区跳转 |
| 浏览器前进/后退 | 路由更新 + 页面恢复 |

### 10.3 各页面临界状态

| 页面 | 空数据 | 加载中 | 错误 |
|---|---|---|---|
| 首页 | 显示空状态引导 | 骨架屏 | 重试 + 离线数据兜底 |
| 错词本 | 插图 + "暂无错词数据" | 表格骨架屏 | 重试 |
| 错题本 | 插图 + "暂无错题数据" | 表格骨架屏 | 重试 |
| 练习报告 | "暂无练习报告" | 骨架屏 | 重试 |
| 写作批改 | 上传引导区 | 批改进度条 | 重试 + 手动输入 |
| 听力/听说 | 素材网格仍是满的（内置资源） | 骨架屏 | 重试 + 内置资源兜底 |
| 资源库 | 内置资源不为空 | 骨架屏 | 重试 + 内置资源兜底 |

## 11. 首页规则

### 11.1 数据刷新

- 进入首页时刷新AI洞察和统计数据
- 动态时间线实时追加
- 教学提示即时更新

### 11.2 布局规则

- 桌面端：三栏（主内容 2/3 + AI浮层 1/3）
- 平板端：两栏（主内容 + AI浮层收起，折叠态按钮常驻）
- 手机端：单栏（侧边栏收起，AI浮层折叠态按钮）

### 11.3 响应式断点

| 断点 | 宽度 | 布局 |
|---|---|---|
| 桌面 | ≥1024px | 侧边栏常驻 + 三栏内容 |
| 平板 | 768–1023px | 侧边栏折叠 + 两栏内容 |
| 手机 | <768px | 侧边栏折叠 + 单栏 + 浮层折叠态 |

## 12. 错词本规则

### 12.1 数据展示

- 默认按错误次数降序排列
- 支持按单元筛选
- 支持搜索单词
- 每页20条，支持翻页

### 12.2 操作规则

| 操作 | 行为 |
|---|---|
| 点击行 | 展开单词详情（含音标、释义、例句、常见错误） |
| 选中多行 | 底部出现批量操作栏 |
| "生成练习" | 触发出题Workflow，题型为单词拼写 |
| "导出" | 导出为PDF错词表 |
| "标记已强化" | 单词从列表移除（可恢复） |

### 12.3 AI交互

- 在错词本页面打开AI浮层 → 自动分析当前错词
- 教师可输入"分析这些错词" → AI给出归类分析和教学建议

| 点击行 | 展开详情（完整题干、选项、解析、AI解题思路） |
| 选中多行 | 底部出现批量操作栏 |
| "生成变式" | 对选中题目生成举一反三变式题 |
| "导出" | 导出为PDF错题集 |

### 13.3 AI交互

- AI可对每道错题自动生成解题思路
- 同类错题自动聚类，生成"知识点盲区"报告

## 14. 写作批改规则

### 14.1 上传规则

- 支持格式：JPG、PNG、PDF、DOC、DOCX
- 支持批量上传（最多一次20篇）
- 图片自动OCR识别
- 单文件限制：10MB

### 14.2 批改规则

| 步骤 | 行为 |
|---|---|
| 1. 识别 | 图片OCR → 提取文本 |
| 2. 批注 | AI逐句检查：语法、拼写、时态、搭配、表达 |
| 3. 评分 | 按内容、结构、语法、词汇四项评分 |
| 4. 总评 | 生成总体评价和改进建议 |
| 5. 确认 | 教师查看、修改评语、确认 |

### 14.3 批注颜色规则

| 类型 | 颜色 | 示例 |
|---|---|---|
| 语法错误 | 红色 | 时态、主谓一致、单复数 |
| 拼写错误 | 橙色 | 单词拼写 |
| 搭配不当 | 黄色 | 介词、固定搭配 |
| 表达建议 | 蓝色 | 句式优化、用词建议 |

### 14.4 教师权限

- 教师可修改AI的任意批注
- 教师可修改评分
- 教师可追加评语
- 教师可删除错误标注
- 确认后的批改结果自动归档

## 15. 听力/听说规则

### 15.1 素材筛选

- 默认显示当前教学单元
- 支持切换单元
- 支持按类型筛选（单词/对话/场景/文化/视频）
- 支持按难度筛选（基础/进阶/拓展）

### 15.2 播放规则

- 点击播放按钮直接在页面内播放
- 支持查看文稿（同步高亮）
- 支持倍速播放（0.75× / 1× / 1.25× / 1.5×）

### 15.3 AI生成

- 输入主题/关键词 → AI生成定制听力文本
- 文本 → TTS语音合成

### 15.4 口语评分（后续版本）

- 评分维度：发音、流利度、完整度
