## AI演进路线

### Phase 1：AI对话 + 基础Workflow（近期 · 1-2个月）

```
目标：AI从"静态占位"变为"可对话可执行"
─────────────────────────────────────────
✓ LLM API集成（Claude / 国内大模型）
✓ AI浮层真实对话
✓ 意图识别（出题/批改/查词/找资源）
✓ 出卷Workflow（单选/完形/阅读/写作）
✓ 批改作文Workflow（OCR → 批注 → 评分）
✓ 搜索结构化结果（词汇卡片/语法讲解）
✓ AI洞察第一版（基于真实数据的文本总结）
```

### Phase 2：AI数据闭环（中期 · 2-4个月）

```
目标：AI能从数据中学习，形成反馈闭环
─────────────────────────────────────────
✓ 错词自动采集 + 归类 + 趋势
✓ 错题聚类 + 知识点盲区识别
✓ 学情趋势预测 + 分级预警
✓ 自动出题（基于错题的变式题）
✓ 智能推荐（基于学情的资源匹配）
✓ Workflow引擎：多步骤编排 + 进度追踪
✓ 个人学情画像
```

### Phase 3：AI主动服务（远期 · 4-6个月）

```
目标：AI从被动响应变为主动服务
─────────────────────────────────────────
✓ 主动推送：学生成绩下滑预警
✓ 主动建议：下一节课的教学重点
✓ 自动生成：每周学情报告（无需手动触发）
✓ 口语评分 + 发音纠正
✓ 分层教学方案自动生成
✓ 学期纵向对比分析
✓ 教案智能生成
```

### Phase 4：AI教师Copilot（愿景 · 6-12个月）

```
目标：AI成为教师的"第二大脑"
─────────────────────────────────────────
✓ 多模态输入：拍照/语音/手写批改识别
✓ 全流程自动化：从备课→上课→作业→评测
✓ 自定义Workflow：教师可编排自己的AI流程
✓ 跨班级/跨年级洞察
✓ 教师教学风格学习 + 个性化AI
✓ 课堂实时辅助（如举手识别、答题统计）
```
