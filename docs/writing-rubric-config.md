# 各地区中高考英语写作评分维度配置

> 版本: v1.1 | 日期: 2026-05-27
> 用途: AI 写作洞察的评分维度适配
> 状态: V1 使用系统写作模型输出，地区维度为 P1/P2 增强

---

## V1 决策：使用系统写作模型输出

**产品决策（2026-05-27）**：

1. 系统已有写作评分模型，后续可以直接接入模型输出的评分维度和诊断结果。
2. 写作洞察 V1 **不需要**把"地区写作评分维度"作为必须人工补齐项。
3. V1 暂时使用系统写作模型的输出字段作为依据。
4. 各地区中高考写作评分维度配置作为 P1/P2 增强项。
5. **不允许在无官方来源时编造地区评分规则。**

### V1 数据输入（来自系统写作模型）

| 字段 | 说明 |
|------|------|
| 作文类型 | 应用文 / 读后续写 / 命题作文 / 看图写话 |
| 系统写作模型总分 | 模型评分总分 |
| 系统写作模型分项得分 | 各维度得分 |
| 内容维度诊断 | 审题、立意、要点完整、内容深度 |
| 语言维度诊断 | 语法、词汇、句型、表达准确性 |
| 结构/逻辑维度诊断 | 谋篇布局、段落衔接、逻辑推进 |
| 亮点表达 | 高级词汇、复杂句型 |
| 共性错误 | 时态混用、单复数、中式英语等及频次 |
| 个性化范文推荐 | 系统推荐的班级/个人范文 |
| 二次修改建议 | 针对每篇作文的修改方向 |

## 第一版通用维度（适用于所有地区）

在地区特定配置未完成前，统一使用以下 5 个维度：

| 维度 | 说明 | 主要失分点 | 洞察规则 |
|------|------|-----------|---------|
| **内容** | 审题、立意、要点完整、内容深度 | 偏题、漏要点、内容空泛 | 要点完整度 < 60% → 提醒审题训练 |
| **语言** | 语法、词汇、句型、表达准确性 | 时态混用、单复数错误、中式英语 | 语法错误集中 → 推荐专项训练 |
| **结构/逻辑** | 谋篇布局、段落衔接、逻辑推进 | 缺主题句、段落不清、连接词少 | 连接词少 → 推荐连接词专项 |
| **书写/格式** | 书写规范、格式正确、字数达标 | 字数不足、格式错误 | 字数严重不足 → 提醒注意 |
| **高分表达** | 高级词汇、复杂句型、表达地道 | 全篇简单句、词汇重复 | 句式单一 → 推荐句型升级训练 |

## 通用题型

### 应用文（书信/邮件/通知/演讲稿）

**大部分地区中考 + 高考通用**

| 维度 | 权重（暂定） | 特殊关注点 |
|------|:----------:|-----------|
| 内容 | 30% | 格式正确、要点齐全 |
| 语言 | 30% | 语法准确、表达得体 |
| 结构/逻辑 | 20% | 逻辑清晰、过渡自然 |
| 书写/格式 | 10% | 格式规范 |
| 高分表达 | 10% | 词汇和句型丰富度 |

**常见失分点**:
- 格式错误（如书信缺署名、日期格式不对）
- 漏要点或要点不完整
- 语气不当（过于口语化或过于正式）

### 读后续写

**浙江、山东等高考新题型**

| 维度 | 权重（暂定） | 特殊关注点 |
|------|:----------:|-----------|
| 内容 | 35% | 与原文衔接、情节合理、主题一致 |
| 语言 | 30% | 语法准确、词汇丰富 |
| 结构/逻辑 | 20% | 逻辑连贯、段落衔接 |
| 书写/格式 | 5% | 书写规范 |
| 高分表达 | 10% | 动作描写、心理描写、环境描写 |

**常见失分点**:
- 情节发展与原文逻辑矛盾
- 关键词未使用或使用不当
- 时态一致性问题（原文过去时 → 续写也用过去时）
- 两段续写之间缺少衔接
