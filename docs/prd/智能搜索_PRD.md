## 2. 背景与目标

### 2.1 背景

中学英语老师在平台上有大量资源需要查找和使用，包括同步词汇、课文、听力、试卷、专项练习等。传统按菜单层级查找效率低，老师希望用自然语言快速找到资源并完成布置。

### 2.2 目标

智能搜索是教师端的任务型搜索助手，目标是：

1. 老师用自然语言输入后，系统识别意图并匹配资源和功能入口
2. 在搜索结果中直接支持预览、布置、加入备课等操作
3. 结合老师当前教材、单元、班级等上下文，优先返回匹配结果
4. 对无法识别的内容进行兜底推荐

### 2.3 不是通用聊天机器人

智能搜索不是开放域对话 AI。它只做三件事：

- 理解老师的搜索意图
- 匹配平台上的资源、功能和入口
- 支持老师完成布置等后续操作

搜索范围限定在平台已有资源、试卷和功能内。

## 3. 用户与场景

### 3.1 用户

- 中学英语老师
- 有当前教材、单元、班级上下文

### 3.2 核心场景

| 场景 | 示例输入 | 预期结果 |
|------|---------|---------|
| 查当前单元资源 | `Unit 3 练习`、`布置单元练习` | 返回当前单元同步练习、检测等资源 |
| 查当前单元词汇 | `单词`、`词汇`、`词表` | 返回我的词表、听写入口、同步词汇 |
| 搜索听写 | `听写`、`默写`、`词汇听写` | 优先返回听写功能入口、单元词汇、我的词表 |
| 搜索听力资源 | `听力`、`听力练习` | 返回同步听力、听力练习、听力模拟 |
| 搜索作文 | `作文`、`应用文`、`读后续写` | 返回写作入口 |
| 查试卷/真题 | `试卷`、`真题`、`期末卷`、`套题` | 返回匹配的试卷资源 |
| 搜索单词 / 讲词 | `restaurant`、`apple banana`、`look up words` | 优先按词汇查询处理，展示讲词 / 单词教学入口，并保留相关词汇资源或词表结果 |
| 搜索答题卡 / 自定义批改入口 | `答题卡`、`制卡`、`三方卡`、`自定义听写`、`自定义应用文` | 返回我的答题卡、新建答题卡、第三方答题卡，以及自定义词汇听写、词句听写、自定义应用文、读后续写、自定义篇章默写等相关功能入口 |
| 查错题 / 词汇薄弱 | `错题`、`错题本`、`词汇薄弱` | 展示错题本或词汇洞察相关入口 |
| 练习报告 / 学情 | `练习报告`、`报告`、`学情` | 本期不作为智能搜索意图，仍从平台原有报告入口进入 |

| 查课本 | `人教版七年级上`、`课本`、`教材` | 返回匹配的课本资源，支持布置和进入课本教学页面 |
| 查视频/配音 | `视频`、`主题视频`、`配音` | 返回对应资源 |
| 卷库标签搜索 | `中考真题`、`阅读专项`、`期末卷`、`语法填空` | 命中标签时返回标签下资源 |

## 4. 产品入口与结构

### 4.1 首页 AI 助手入口

首页右侧「小天 AI 智能助手」区域，包含：

- **自然语言输入框**：文字提示"试试：生成Unit3词汇听写、查同步资源..."
- **发送按钮**：点击或回车触发搜索

首页不展示 3×3 引导卡。3×3 引导卡只在搜索全屏页面 / 独立搜索页展示。

以下引导卡只在搜索全屏页 / 独立搜索页展示，点击等同于老师输入对应搜索词：

| 引导卡 | 等同搜索词 | 目标意图 |
|--------|-----------|---------|
| 查看当前单元词汇 | 当前单元词汇 | 词汇 / 当前单元 |
| 生成 Unit3 词汇听写 | Unit3 词汇听写 | 听写 |
| 查同步资源 | 当前单元同步资源 | 单元资源 |
| 查错题本 | 错题 / 错题本 | 精准跳转错题本 |
| 查看词汇洞察 | 词汇薄弱 / 词汇掌握 | 词汇洞察 |
| 查听力资源 | 听力 | 听力 |
| 查听说资源 | 听说 / 听说练习 | 听说 |
| 查作文资源 | 作文 / 写作 | 写作 |
| 查试卷资源 | 试卷 | 试卷 |

引导卡规则：
- 引导卡点击结果必须纳入测试用例
- 如引导卡文案调整，需要同步更新意图词典和测试用例
- **默认展示数量**：搜索页默认只展示前 3 个引导卡，其余收起
- **展开查看更多**：点击「查看更多功能」后展开全部 9 个引导卡，保持 3×3 网格
- **收起**：展开后提供「收起」按钮，恢复只展示前 3 个
- **默认状态禁止直接展示 9 个引导卡**
- 首页不展示 3×3 引导卡

**首页搜索行为**：
1. 老师在首页「小天 AI 智能助手」输入框输入搜索词并点击搜索；
2. 系统跳转到搜索全屏页 / 独立搜索结果页；
3. 搜索框中保留老师输入的搜索词；
4. 自动执行搜索并展示该搜索词对应的完整搜索结果；
5. 结果应与老师在搜索全屏页内输入同一搜索词得到的结果一致；
6. 首页搜索不打开抽屉或弹层，不展示简化版结果。

### 4.2 独立搜索页

独立搜索页，提供完整搜索体验：

- 顶部搜索框
- 搜索理解文案展示区
- 分类标签筛选
- 搜索结果列表（智能匹配区 + 推荐关联区）
- 历史搜索记录

## 5. 核心流程

### 5.1 搜索主流程

```
老师输入查询
  → 判断是否为精准跳转意图（错题本/备课/词汇洞察）
    → 是：展示精准跳转卡，引导跳转目标页面
    → 否：进入意图识别
      → 判断是否可识别（语义有意义性检查）
        → 是：按意图规则匹配资源和功能入口
        → 否：进入基础搜索匹配
          → 有结果：展示搜索结果
          → 无结果/无法识别：展示兜底推荐
```

### 5.2 AI Loading 流程

老师提交查询后：

1. 主页面展示 AI Loading 动画
2. 加载步骤文案根据识别的意图动态生成：
   - 有识别意图：`正在理解「{意图标签}」的相关场景...` → `正在匹配相关功能和资源...` → `已为你整理相关结果。`
   - 未识别意图：`正在理解你的需求...` → `正在匹配相关功能和资源...` → `正在为你整理推荐结果...`
3. 加载完成后展示搜索结果

### 5.3 搜索理解文案

搜索结果顶部展示一条搜索理解文案，告知老师系统识别到了什么意图。例如：

- 搜索"听写"：`小天理解：你可能想布置「听写」练习，已为你整理听写入口、当前单元词汇和我的词表。`
- 搜索"试卷"：`小天理解：你可能想找「试卷」相关内容，已为你整理我的试卷和平台试卷资源。`

### 5.4 精准跳转卡

对以下意图，在搜索处理前展示精准跳转卡（不进入常规搜索结果页）：

| 意图 | 跳转卡内容 | 跳转目标 |
|------|-----------|---------|
| 错题/错题本 | 说明查看方式，提供「去错题本」按钮 | 错题本页面 |
| 备课/收藏 | 说明查看方式，提供「去我的备课」按钮 | 我的备课列表（平台现有功能页面） |
| 词汇洞察/薄弱 | 说明查看方式，提供「去词汇洞察」按钮 | 词汇洞察页 |

### 5.5 不同入口搜索结果一致性规则

无论老师从哪个入口发起搜索，搜索完成后的结果展示规则必须统一。

**适用入口**：

1. 首页右侧「小天 AI 智能助手」输入框；
2. 搜索全屏页 / 独立搜索页输入框；
3. 搜索全屏页 / 独立搜索页引导卡；
4. 历史搜索记录；
5. 兜底建议标签；
6. 其他能触发智能搜索的入口。

**统一规则**：

1. 所有入口提交搜索后，必须走同一套智能搜索意图识别、资源匹配、排序、分组和兜底规则；
2. 不允许首页搜索结果使用一套简化结果页，搜索全屏页使用另一套完整结果页；
3. 首页输入搜索后，跳转到搜索全屏页 / 独立搜索结果页，并自动执行搜索；
4. 搜索结果统一包含：搜索理解文案、智能匹配区、推荐关联区、分类筛选、资源卡片操作、兜底或替代推荐、历史记录更新；
5. 同一搜索词在不同入口得到的意图识别结果、资源排序、结果分组必须一致；
6. 如果某个入口为了空间限制只展示简化摘要，也必须提供「查看完整结果」入口，且不能替代正式搜索结果页；
7. 本期 demo 中首页搜索后直接展示完整智能搜索结果，不单独做简化版搜索结果页。

**禁止行为**：

1. 不允许首页搜索后只展示两个入口卡片；
2. 不允许首页搜索使用独立的简化搜索逻辑；
3. 不允许跳过智能匹配区 / 推荐关联区；
4. 不允许只返回功能入口而不展示关联资源；
5. 不允许结果排序和文档规则不一致。

## 6. 上下文识别规则

### 6.1 教学上下文

系统根据老师当前信息提供上下文理解：

- **当前教材**：如"人教版"
- **当前单元**：如"Unit 3"
- **当前班级**：如"2023级A18班"
- **当前年级**：如"七年级上"
- **当前地区**：如"广东"（用于区域试卷匹配）

### 6.2 上下文使用规则

1. 老师未明确指定范围时，优先使用当前上下文
2. 明确指定其他范围时，使用指定范围
3. 上下文不足时降级到通用匹配
4. 搜索结果中对匹配当前上下文的资源标注"当前单元"

- **课本**额外支持"进入"按钮，跳转到平台现有课本教学页面

### 8.3 资源分类边界规则

#### 读写同步
读写同步不作为独立分类展示，应按具体内容归类：
1. 读写同步中的试卷资源，如果属于"基础知识"，归入词汇；
2. 读写同步中的试卷资源，如果属于"综合练习"，根据内容归入写作和阅读理解；
3. 读写同步中的词汇内容归入词汇；
4. 读写同步中的写作内容归入写作；
5. 读写同步中的阅读理解内容归入阅读理解；
6. 不单独展示"读写同步"分类。

#### 真题 / 模拟
真题和模拟不归类到专项：
- 真题 → 走真题 / 试卷 / 套题相关分类
- 模拟题 → 走模拟 / 试卷 / 套题相关分类
- 专项 → 只承接题型专项、词汇专项、听力专项、写作专项、阅读专项、微技能等专项资源

#### 同步作文
同步作文不生成作文讲评。写作类资源只按平台现有布置能力处理。

## 9.3 搜索词归一化与关联识别

### 功能目的

老师输入搜索词时不要求完全命中平台标准名称。系统需要支持别名、简称、口语化表达、常见错别字、近音字等输入形式的关联识别，将老师表达的意图正确映射到对应的功能和资源。

### 识别类型

系统需要支持以下类型的关联识别：

- 标准名称识别
- 别名识别
- 简称识别
- 口语化表达识别
- 常见错别字识别
- 近音字 / 同音字识别
- 中英文大小写和空格容错
- Unit / 单元表达容错

### 归一化示例

| 用户输入 | 归一化后意图 | 说明 |
|---------|------------|------|
| 答题咔 / 达题卡 / 答题纸 | 答题卡 | 常见错别字、近音字、别名 |
| 听谢 / 听默 / 默单词 | 听写/默写 | 近音字、口语化表达 |
| 练习报表 / 报告 / 学情 / 完成率 / 未完成 | 本期不作为智能搜索意图 | 不触发报告跳转，走兜底或提示从原有入口进入 |
| 错词本 / 错题 | 错题/错词相关 | 关联入口 |
| 单词表 / 词表 / 生词表 | 我的词表/词汇 | 别名识别 |
| Unit3 / unit 3 / U3 / u3 / 第三单元 / 第3单元 | 当前或指定单元 | 单元表达容错 |

### 归一化后处理

1. 归一化后的结果进入后续意图识别和资源匹配流程。
2. 如果多个意图都可能命中，继续按意图优先级判断。
3. 如果归一化后仍无法判断，进入兜底推荐。
4. 低置信度表达（如输入过短的 `卡`、`题`、`写`）不应强行命中单一功能，应展示兜底或相关入口推荐。

### 词典维护

- demo 阶段可维护一份关键词别名表作为模拟
- 正式规则需结合平台搜索词库、历史搜索日志和产品确认的意图词典持续维护
- 每次新增资源分类或功能入口时，需要同步补充意图词典
- 不要把某个 demo 关键词表写成最终规则

## 10. 重点场景详细说明

### 10.1 搜索听写/默写

查询"听写"或"默写"时的结果排序：

1. **听写功能入口**（词汇听写、词句听写、自定义篇章默写）— 最优先
2. **当前单元词汇**（支持听写/跟读动作）
3. **我的词表**（自建词表，可复用于听写）
4. **推荐关联区**：相关词汇 / 听写练习资源

**入口一致性**：无论老师从首页搜索"听写"，还是在搜索全屏页搜索"听写"，结果都应按以上顺序展示。不允许只展示词汇听写和词句听写而省略自定义篇章默写、当前单元词汇和我的词表。

### 10.2 搜索当前单元资源并布置

查询"布置"或"练习"时：

1. 优先返回当前单元的综合练习、基础练习、单元检测
2. 补充展示课文跟读、听力练习等关联资源
3. 每个资源卡片支持直接布置

### 10.3 搜索作文

查询"作文"或"写作"时：

1. 展示应用文和读后续写相关自定义入口；
2. 如果当前学段有写作专项资源，应展示对应的写作专项试卷；
3. 明确搜索"应用文"时，优先展示自定义应用文入口 + 应用文写作专项试卷，关联推荐读后续写；
4. 明确搜索"读后续写/续写"时，优先展示自定义读后续写入口 + 读后续写专项试卷，关联推荐应用文；
5. 若当前学段无对应写作专项资源，则展示自定义入口或兜底推荐；
6. 不将写作相关内容简单命名为"批改入口"，应明确为自定义入口 + 写作专项试卷。

### 10.4 搜索听力与听说资源

**听力资源**：
1. 优先返回当前单元同步听力和听力练习；
2. 关联推荐听力专项和听力模拟；
3. 查询"听力模拟"独立处理，返回听力模考资源。

**听说资源**：
1. 搜索"听说/听说练习/口语听说"时：如果老师有听说资源，优先展示听说资源；如果老师没有听说资源，则展示听力资源作为替代推荐；
2. 搜索"听说专项"时：识别为专项资源，如果老师有听说专项资源，返回听说专项资源；如果没有，则展示听力专项或听力练习作为替代推荐。

**听说/听力替代规则**：
1. 不再根据地区预先判断听说/听力；
2. 听说资源不存在时，以听力资源替代；听力资源不存在时，以听说资源替代；
3. 替代推荐需要标注为替代资源，不能误认为是精确结果；
4. 是否有听说/听力资源，以平台资源可见性和资源检索结果为准。

### 10.5 搜索专项

- 泛搜"专项"时展示专项分类卡片（题型专项、词汇专项、听力专项、写作专项、阅读专项、微技能专项）
- 明确搜索"听力专项"时直接返回听力专项资源
- 明确搜索"听说专项"时，直接返回听说专项资源；"听说专项"识别为专项资源，不识别为普通听说；如果老师没有听说专项资源，则展示听力专项或听力练习作为替代推荐
- 专项资源仍按年级推断规则处理

### 10.6 练习报告/学情搜索处理

练习报告/学情/完成率/未完成等查询**本期不作为智能搜索意图**：

- 不触发练习报告精准跳转；
- 不进入练习报告搜索；
- 可进入兜底或提示使用平台原有报告入口。

老师仍可通过平台原有报告入口查看练习报告。

### 10.7 搜索词汇

查询"单词""词汇""当前单元词汇""Unit3 词汇""U3 单词"或具体英文单词（单个或多个）时，进入词汇相关搜索。

#### 词汇搜索结果排序

智能匹配区结果按以下优先级排列：

1. **当前单元词汇**（主结果，包含当前单元同步词汇资源和词汇快捷动作）
2. **听写与默写入口**（词汇听写、词句听写、自定义篇章默写等快捷操作入口）
3. **我的词表**（老师自建词表，作为老师自建内容入口）
4. **词汇专项或相关词汇资源**（推荐关联区）

#### 词表搜索结果排序

当老师明确搜索"词表""我的词表""单词表""生词表""词汇表""词单"时：

1. **我的词表**（主结果）
2. **听写与默写入口**（辅助入口）
3. **同步单元词汇**（推荐关联）

#### 英文单词搜索规则

- 用户输入英文单词或英文单词组合时（如 `restaurant`、`apple banana`），优先按词汇查询处理
- 不限制只能输入一个英文词，多个英文词也按词汇查询
- 系统判断时忽略标点和空格（如 `look, say, write` 视为英文词组合）
- 英文词场景下需将「讲词 / 单词教学入口」优先展示在主结果区
- 同时保留当前单元词汇、听写与默写入口、我的词表等词汇相关结果
- 不因识别为英文词而只展示讲词入口
- 不要误识别为普通资源搜索
- 英文大小写不影响识别

### 10.8 听写与词汇搜索的关系

1. 搜索"听写/默写"时，不等同于普通词汇搜索
2. 听写场景优先展示：词汇听写、词句听写、自定义篇章默写、当前单元词汇资源及快捷动作、我的词表推荐卡片
3. 搜索"词汇/单词/词表"时，优先展示词汇资源和词表，听写入口作为关联推荐
4. 听写和词汇互相关联，但主结果排序不同

### 10.9 专项资源年级推断

1. 搜索专项资源时，如果专项资源有年级层级，默认使用老师当前同步年级
2. 如果用户明确指定年级，使用用户指定年级
3. 如果专项资源本身不区分年级，不做年级过滤
4. 不因为专项不是同步资源，就完全忽略当前年级

### 10.10 AI 搜索与词汇复习方案边界

智能搜索一期不直接生成多天词汇复习方案。

当用户搜索"词汇复习方案""复习规划""期末词汇复习""高三一轮词汇复习""错词复习方案"：

1. 如果用户意图是查看班级词汇问题，推荐进入「词汇洞察」
2. 如果用户意图是阶段复习，推荐进入「阶段词汇复习方案」
3. 不在智能搜索结果中直接生成多天词汇复习方案
4. 不绕过词汇洞察页或阶段方案弹窗的确认流程
5. 不直接发布练习

### 10.11 试卷名称搜索

试卷名称搜索是独立于普通资源搜索的搜索类型，用于老师通过地区、年份、考试类型等信息查找指定试卷。

**触发条件**：搜索词包含地区/省份、年份、考试类型或试卷关键词（如真题、试卷、考题、试题等）。

**识别能力**：

1. **地区/省份识别**：可识别省份全名（如"山东省"）、简称（如"山东"）、主要城市名称（如"北京"），正式范围以平台地区数据为准；
2. **年份识别**：支持 4 位年份（如 2024）和 2 位年份（如 24 年）；
3. **考试类型识别**：中考、高考、期中、期末、模拟，以及其他平台已有考试类型。

**匹配度判定**：

1. 地区 + 年份 + 考试类型全部命中：**精确匹配**；
2. 命中其中 2 个维度：**相近匹配**；
3. 命中 1 个维度 + 试卷关键词：**相近匹配**；
4. 仅命中试卷关键词：**相关推荐**；
5. 具体排序由平台搜索能力处理。

**上下文豁免**：试卷名称搜索不受当前教材/单元上下文限制。当前教学上下文仍可展示供老师参考，但不限制试卷搜索范围。

**结果展示**：精确匹配优先展示，相近匹配作为补充，试卷卡片展示试卷标题、地区、年份、考试类型等关键信息。

### 10.12 课本名称搜索

课本名称搜索是独立于普通资源搜索的搜索类型，用于老师通过教材版本、年级、单元等信息查找课本。

**触发条件**：搜索词包含教材版本（如"人教版"、"外研版"）、年级（如"七年级"、"八年级上"）、单元（如"Unit 3"）或课本关键词（如"课本"、"教材"、"课文"）。

**识别能力**：

1. **教材版本识别**：可识别常见教材版本名称和简称（如"人教版"、"外研版"、"牛津版"等），正式范围以平台已有教材版本为准；
2. **年级识别**：支持年级全称（如"七年级上册"）、简称（如"七上"）；
3. **单元识别**：支持 Unit + 数字、第X单元等表达。

**匹配度判定**：

1. 教材版本 + 年级 + 单元全部命中：**精确匹配**；
2. 命中其中 2 个维度：**相近匹配**；
3. 命中 1 个维度 + 课本关键词：**相近匹配**；
4. 仅命中课本关键词：**相关推荐**；
5. 具体排序由平台搜索能力处理。

**上下文豁免**：课本名称搜索不受当前教材/单元上下文限制。但当老师未指定教材版本或年级时，可优先使用当前上下文匹配。

**结果展示与操作**：

- 精确匹配课本优先展示，相近匹配作为补充；
- 课本卡片展示课本名称、教材版本、年级、单元等关键信息；
- 课本卡片提供两个操作按钮：「布置」和「进入」；
- 「布置」：进入布置确认流程，将课本内容布置为练习任务；
- 「进入」：跳转到平台现有课本教学页面（课本详情/教学页面），老师可在该页面使用课本的完整功能。

**课本资源来源**：课本资源来自平台已授权课本，搜索结果只展示平台已收录的课本。搜索匹配方式为模糊匹配 + 精准匹配，具体搜索实现由平台搜索能力处理。

**补充规则**：
1. 如果搜索文案可以和课本名称匹配，课本要展示出来；
2. 精准匹配课本名称时，课本作为优先推荐；
3. 部分匹配课本名称时，课本作为相关推荐；
4. 课本也可在试卷搜索或普通资源搜索中作为相关推荐出现；
5. 课本资源不按班级过滤；
6. 课本资源来自平台已授权课本。

### 10.13 Unit + 资源类型组合搜索

当老师输入包含具体单元编号（如"Unit 3"、"U3"、"第三单元"）+ 资源类型关键词时：

| 输入示例 | 处理规则 |
|---------|---------|
| Unit 3 听力 | 返回指定单元的听力资源 |
| Unit 3 词汇 / 单词 | 返回指定单元的词汇资源 |
| Unit 3 课文 | 返回指定单元的课文资源 |
| Unit 3 作文 / 写作 | 返回指定单元的写作相关资源 |
| Unit 3 阅读 | 返回指定单元的阅读资源 |
| Unit 3 语法 | 返回指定单元的语法资源 |
| Unit 3 练习 / 资源 / 综合 | 返回指定单元的综合资源 |
| 仅 Unit 3（无资源类型） | 返回指定单元的综合资源或单元资源总览 |

**规则**：
1. 老师明确指定 Unit 时，优先使用指定单元；
2. 老师未指定 Unit 时，使用当前上下文单元；
3. 指定单元无对应资源时，进入替代推荐。

### 10.14 功能入口识别与排序

当老师搜索的是平台功能而不是资源时，系统需进一步区分具体入口：

**答题卡相关**：三方卡 → 第三方答题卡；答题卡/制卡/快速制卡 → 答题卡制作入口。

**词表相关**：词表/我的词表/单词表等（不含"导入"）→ 我的词表在前，导入词表在后；导入词表 → 导入词表在前。

**听写/默写相关**：词句听写 → 词句听写入口；词汇听写 → 词汇听写入口；听写（泛指）→ 词汇听写入口在前，词句听写入口在后；篇章默写 → 篇章默写入口。

**写作相关**：应用文 → 自定义应用文入口 + 应用文写作专项试卷；读后续写 → 自定义读后续写入口 + 读后续写专项试卷；作文/写作/书面表达 → 应用文、读后续写相关入口 + 当前学段可用的写作专项试卷。不将写作相关内容简单命名为"批改入口"。

**听说相关**：听说/听说练习/口语听说 → 如果老师有听说资源，优先展示听说资源，无听说资源时展示听力资源替代；听说专项 → 展示听说专项资源，无听说专项资源时展示听力专项或听力练习替代。不再根据地区预先判断听说/听力。

**批改泛指**：展示所有批改类入口。

**导入试卷**：搜索"导入试卷/导入考卷/导入试题"时：
- 展示导入试卷入口；
- 展示我的试卷资源；
- 我的试卷默认展示前 10 条；
- 提供"更多"入口，支持跳转到平台现有我的试卷页面。

**英文单词**：可推荐"讲词/单词教学"入口，同时保留词汇资源相关结果。不限制只能输入一个英文词，多个英文词也按词汇查询处理。

### 10.15 卷库标签命中搜索

卷库标签命中是独立于普通关键词搜索的资源召回方式。当老师输入的内容命中卷库标签时，系统应返回该标签下的资源。

**标签类型**：卷库标签包括平台卷库中已配置的标签，例如题型、资源类型、考试类型、地区、年级、专题、专项、同步、模拟、真题等，具体标签范围以平台卷库配置为准。

**命中规则**：
1. 标签精确命中时，标签下资源可进入智能匹配区；
2. 标签部分命中或弱命中时，标签下资源进入推荐关联区；
3. 如果同时命中多个标签，按意图优先级、标签匹配度和资源相关性综合排序；
4. 如果标签下无资源，进入无结果替代推荐或兜底。

**示例**：

| 老师输入 | 命中标签 | 处理 |
|---------|---------|------|
| 中考真题 | 中考 / 真题 | 返回中考真题标签下资源 |
| 阅读专项 | 阅读 / 专项 | 返回阅读专项标签下资源 |
| 听说专项 | 听说 / 专项 | 返回听说专项标签下资源 |
| 期末卷 | 期末 / 试卷 | 返回期末试卷相关资源 |
| 语法填空 | 语法填空 / 题型 | 返回该题型标签下资源 |

卷库标签不作为固定前端枚举，正式范围以平台卷库标签配置为准。

## 11. 结果展示与操作

### 11.1 搜索结果结构

搜索结果分为两大区域：

**智能匹配区**：与查询最相关的结果，优先展示
**推荐关联区**：相关的补充资源，辅助展示

每个区域包含多个资源组，每组有标题、推荐说明和资源列表。

**结果结构统一要求**：所有入口触发的搜索结果必须包含以下完整结构：
- 搜索理解文案
- 智能匹配区
- 推荐关联区
- 分类筛选
- 资源卡片操作
- 兜底或替代推荐（无结果时）
- 历史记录更新
不允许因入口不同而省略上述任何结构。

### 11.2 分类筛选

搜索结果顶部提供分类标签筛选，显示每类资源的数量。老师点击标签后筛选对应资源类型。

### 11.3 资源卡片信息

每张资源卡片展示：

- 资源名称
- 资源类型标签
- 难度/时长/题量等元数据
- 匹配说明/推荐说明（如"匹配当前单元""与听写相关""同年级资源""课本名称匹配"等）
- 可用操作按钮（预览/布置/进入/加入备课）

### 11.4 同步词汇/课文内容选择

同步词汇和同步课文卡片为内容选择型：

- 展开后展示词汇、语块、固定搭配的分组
- 词汇不需要区分课标词和非课标词，统一展示在词汇列表里
- 语块和固定搭配作为单独分组或标签展示
- 支持逐词勾选和按分区全选
- 各分区支持全选，全选按钮文案统一为"全选"
- 老师选择具体内容后，选择使用方式（口语跟读/看英选中/单词默写/看中选英/单词听写/听音识词等），即表示选择布置方式
- 选择练习形式后，直接打开平台已有布置弹窗，不再生成布置草稿
- 课文默认按 Section / Passage 层级展示；搜索词含 topic/话题时按话题扁平展示
- 课文支持逐句跟读/整篇跟读/整篇背诵
- 未选择内容时，练习形式不可点击或点击后提示先选择内容

### 11.5 兜底展示

无法识别或完全无结果时：

- 展示兜底文案：`小天暂未准确理解「{查询}」，你可以换个说法试试，或从下方常用功能中快速进入。`
- 展示搜索建议标签（答题卡/词表/词汇听写/单元练习/作文/配音/专项/听力/课文）
- 展示常用功能入口（答题卡/词表/词汇听写/单元练习/作文/配音）

### 11.6 搜索结果过多处理

当搜索结果超过 50 条时：

1. 默认优先展示最相关结果；
2. 按资源类型分组展示，每组内超出默认数量时折叠；
3. 通过分类筛选标签引导老师缩小范围；
4. 不做传统分页（上一页/下一页）；
5. 展示提示文案："结果较多，已优先展示最匹配内容，可通过分类筛选继续缩小范围"；
6. 筛选标签上展示各类型结果数量，引导老师点击筛选。

### 11.7 无结果替代推荐

当有教学上下文但精确资源为空时（不同于完全无法识别），按层级展示替代推荐：

1. **当前单元可替代资源**（默认展开）：当前单元内的关联资源；
2. **同年级相关资源**（默认折叠）：同年级但非当前单元的通用资源；
3. **非当前单元相关资源**（默认折叠）：其他单元的资源，必须标注单元或年级信息；
4. **常用功能入口和搜索建议标签**：提供快速跳转和重新搜索入口。

完全无法识别时仍使用 §11.5 的兜底展示，不强行展示资源结果。

## 12. 布置流程

### 12.1 布置入口

资源卡片上的「布置」按钮。

### 12.2 同步资源布置流程

1. 老师选择内容范围（词汇分组/课文篇目）
2. 老师选择使用方式（口语跟读/单词默写/单词听写等），即表示选择布置方式
3. 选择练习形式后，直接打开平台已有布置弹窗，不再生成布置草稿
4. 老师在弹窗中确认班级、时间、截止时间等参数
5. 确认后发布
6. 未选择内容时，练习形式不可点击或点击后提示先选择内容

### 12.3 普通资源布置流程

1. 点击「布置」→ 选择课堂/课后
2. 设置布置时间窗口
3. 确认布置
4. 布置成功后反馈

### 12.4 加入备课

配音和同步视频等资源支持加入备课，供课堂教学使用。

### 12.5 布置确认规则

1. AI 搜索中点击「布置」后，不能直接发布
2. 必须进入布置确认流程
3. 可默认带入当前班级、当前单元、资源名称、发布时间等信息
4. 默认值需要老师确认
5. 多班级默认策略：老师有多个班级时，布置确认流程默认带入当前上下文班级（老师当前正在查看的班级）。如老师无当前上下文班级（如未选择班级），则不默认选中任何班级，要求老师手动选择。老师可在确认流程中切换班级。
6. 内容选择为空时不能布置
7. 布置成功后展示成功反馈

## 13. 空态与异常

| 场景 | 处理方式 |
|------|---------|
| 无搜索结果 | 展示兜底推荐（搜索建议 + 常用功能入口） |

## 14. 历史记录

- 老师每次搜索的记录保留在搜索历史中
- 搜索历史最多保留 20 条
- 新增搜索记录超过 20 条时，覆盖/删除最早的搜索记录
- 搜索历史按最近搜索时间倒序展示
- 空输入不记录
- 点击历史记录可重新发起搜索
- 相同意图的搜索词视为重复，保留最近一条（如"Unit 3 词汇"和"第三单元单词"意图相同，只保留最近搜索的那条）

## 15. 依赖的平台能力

以下能力需要在平台层面支持，具体实现由后端和平台团队设计：

1. **资源检索**：按关键词、资源类型、教材、单元等维度检索平台资源
2. **资源动作**：预览、布置、加入备课
3. **班级/教材/单元上下文**：获取老师当前的教材、单元、班级、年级、地区信息
4. **布置能力**：创建练习任务、设置布置参数、发布
5. **学情数据**：练习报告、完成情况、错题统计
6. **词汇数据**：错词记录、词表管理
7. **试卷数据**：自建试卷、平台试卷、区域试卷
8. **课本数据**：平台已授权课本数据，支持按课本名称、教材版本、年级、册次、单元检索；课本资源与班级无关，不按班级过滤。
9. **权限与资源可见性**：按教师账号、学校授权、地区、教材版本、年级、班级、资源状态过滤搜索结果

### 15.1 权限与资源可见性

正式环境中，搜索结果需要按老师的可见范围过滤：

| 过滤维度 | 说明 |
|---------|------|
| 教师账号 | 老师只能访问自己有权限的资源 |
| 学校资源授权 | 学校购买版权的资源才可见 |
| 地区限定 | 地区限定资源按老师所在地区展示，非所在地区不出现 |
| 教材版本 | 按老师当前使用的教材版本匹配 |
| 年级 | 按老师当前教授的年级匹配 |
| 班级 | 班级维度数据隔离，其他班级数据不出现 |
| 资源上下架状态 | 已下架资源不展示，或按平台能力仅展示不可用状态 |
| 资源可布置/可预览状态 | 不可布置/不可预览的资源按状态展示对应操作按钮 |

**规则**：
- 无权限资源不展示；
- 已下架资源不展示或标注不可用；
- 权限过滤依赖平台能力，如果平台权限能力暂未接入，不做前端自行判断；
- Demo 阶段可使用全量 mock 数据，不按权限过滤；
- 正式阶段必须接入平台权限能力。

## 16. 数据口径与计算规则

本章集中整理智能搜索页面上所有数据、排序、数量、标签的计算规则或取数口径。
完整口径细节见 `docs/spec/智能搜索_SPEC.md` §20。

### 16.1 搜索结果数量与分组

| 数据名称 | 计算 / 取数口径 | 空态处理 |
|---------|---------------|---------|
| 分类标签数量 | 当前搜索结果中各资源类型的结果数量，按次数降序，为 0 不展示 | 无结果时不展示 |
| 资源组数量 | 智能匹配区 + 推荐关联区的资源分组数量 | 无结果时为 0 |
| 每组展示数量 | 默认展示前 5 条，超过显示「查看更多」 | 不足按实际展示 |
| 搜索结果过多提示 | 结果总数超过 50 条时展示提示文案 | 不超过阈值不展示 |
| 试卷搜索匹配级别 | 精确匹配（三信号全中）/ 相近匹配（部分命中）/ 相关推荐（仅关键词） | — |
| 卷库标签命中 | 标签精确命中时资源进入智能匹配区；标签弱命中时进入推荐关联区；多标签时综合排序 | 标签下无资源时进入替代推荐或兜底 |
| 无结果 | 当前查询无可匹配资源或意图无法识别 | 展示兜底推荐 |
| 替代推荐 | 4 层：当前单元可替代→同年级→非当前单元→功能入口+搜索建议 | 精确匹配有结果时不展示 |

### 16.2 搜索排序

| 数据名称 | 排序规则 |
|---------|---------|
| 意图优先级 | 按文档 §9 定义的意图优先级从高到低判断；精准跳转最高优先级 |
| 智能匹配区 | 与查询最相关的结果，优先展示 |
| 推荐关联区 | 相关补充资源，在智能匹配区之后展示 |
| 听写排序 | 听写功能入口 → 当前单元词汇 → 我的词表 |
| 词汇搜索排序 | 当前单元同步词汇 → 当前单元词汇快捷动作 → 我的词表 → 听写/默写入口 → 词汇专项/相关练习 |
| 专项资源排序 | 精确专项优先；有年级层级时优先当前年级 |
| 兜底推荐排序 | 常用功能 + 当前上下文相关入口优先 |
| 试卷搜索排序 | 精确匹配 → 相近匹配 → 相关推荐 |
| 替代推荐层级排序 | 当前单元可替代 → 同年级 → 非当前单元 → 功能入口+搜索建议 |
| Unit+资源类型组合排序 | 先识别资源类型意图，再叠加单元编号精准匹配 |
| 卷库标签命中排序 | 标签精确命中优先进入智能匹配区；多标签时按意图优先级、标签匹配度和资源相关性综合排序 |

### 16.3 资源去重

1. 搜索结果中同一资源不应重复展示。
2. 资源去重按平台资源唯一标识进行。如同一资源被多个搜索条件命中，只在结果中展示一次。
3. 不同入口指向同一资源时，只展示一次，但可保留多个推荐理由。
4. 平台资源唯一标识由后端提供，前端不做自行判断去重。
5. demo 可 mock 去重，正式以平台资源标识为准。

### 16.4 匹配说明/推荐说明

1. 匹配说明/推荐说明来源于命中的意图、上下文、资源类型或使用场景。
2. 不应出现与搜索结果不一致的匹配说明/推荐说明。
3. 无法生成准确的匹配说明/推荐说明时，使用通用文案。
4. 匹配说明/推荐说明不参与排序，除非后续规则明确。

### 16.5 历史记录

| 数据名称 | 计算 / 取数口径 | 待确认项 |
|---------|---------------|---------|
| 搜索历史条数 | 最多 20 条 | — |
| 历史记录去重 | 相同意图的搜索词视为重复，保留最近一条 | — |
| 历史记录排序 | 按最近搜索时间倒序 | — |
| 空搜索 | 不记录 | — |

### 16.6 搜索全屏页 / 独立搜索页引导卡

1. 引导卡只在搜索全屏页 / 独立搜索页展示，首页不展示。
2. 每张引导卡对应固定搜索词和固定意图。
3. 点击等同老师输入对应搜索词，走完整搜索流程。
4. 引导卡不单独计算结果，结果取对应搜索词的搜索结果。
5. 引导卡点击失败时展示兜底或错误提示。
6. 引导卡点击结果必须纳入测试用例。
7. 默认展示前 3 张引导卡，其余收起；点击「查看更多功能」后展开全部 9 张；展开后可收起。
8. 默认状态不允许直接展示 9 张引导卡。

### 16.7 精准跳转卡

1. 在搜索处理前判断，优先级最高。
2. 跳转卡展示：标题（目标名称）+ 描述（支持的操作）+ 按钮（跳转目标）。
3. 跳转目标页面不可用时提示，不展示不可用跳转按钮。

## 17. 前端交互规则

本章定义智能搜索页面上的前端交互行为、状态流转、按钮启禁用、弹窗行为和失败反馈规则。
不包含 UI 样式、颜色、尺寸、间距、像素等视觉规范。

### 17.1 搜索输入交互

1. 老师在输入框输入内容后，点击发送按钮或按回车触发搜索。
2. 输入为空（trim 后为空字符串）时不触发搜索，保持当前页面状态。
3. 输入前后空格自动忽略（trim 处理）。
4. 搜索过程中展示 AI Loading 动画，搜索过程中防止重复提交（发送按钮不可用或等同处理）。
5. 搜索完成后展示搜索理解文案和搜索结果。
6. 搜索失败时展示错误提示，并允许重试（发送按钮恢复可用）。
7. 低置信输入（如过短的 `卡`、`题`、`写`）不强行命中单一功能，展示兜底或多个可能入口。

### 17.2 搜索全屏页 / 独立搜索页引导卡交互

1. 引导卡只在搜索全屏页 / 独立搜索页展示，首页不展示。
2. 默认只展示前 3 个引导卡，其余引导卡默认收起。
3. 展示「查看更多功能」入口，点击后展开全部 9 个引导卡。
4. 展开后保持 3×3 网格展示，提供「收起」按钮恢复只展示前 3 个。
5. 默认状态不允许直接展示 9 个引导卡。
6. 点击引导卡等同于输入固定搜索词并发起搜索。
7. 点击后进入对应意图的结果页或精准跳转卡，走完整搜索流程。
8. 引导卡结果为空时展示兜底推荐，不展示空白页面。
9. 引导卡文案调整时，需要同步更新意图词典和测试用例。
10. 引导卡点击后，搜索框可展示对应搜索词（非必须，以后续设计稿为准）。

### 17.3 分类筛选交互

1. 搜索结果出现后展示分类筛选标签。
2. 点击某个分类标签后，只展示对应分类的结果。
3. 点击「全部」恢复全部结果。
4. 分类数量为 0 的标签不展示。
5. 切换分类不重新发起搜索，只筛选当前已返回的结果。

### 17.4 资源卡片操作交互

1. 资源支持的操作才展示对应按钮。
2. 不支持的操作不展示对应按钮（不展示置灰按钮，具体形式以后续设计稿为准）。
3. 点击「预览」，进入资源预览（弹窗或新页面，具体形式以后续设计稿为准）。
4. 点击「布置」，进入布置确认流程，不能直接发布。
5. 点击「进入」（仅课本资源），跳转到平台现有课本教学页面（课本详情/教学页面）。
6. 点击「加入备课」，成功后反馈；失败时提示错误并允许重试。
7. 配音和同步视频支持「加入备课」，其他资源不默认展示「加入备课」按钮。
8. 写作类资源（应用文/读后续写）不支持预览，不展示「预览」按钮。

### 17.5 内容选择型资源交互

适用于同步词汇、同步课文等内容选择型资源。

1. 老师先展开资源内容（如展开词汇/语块/固定搭配分组）。
2. 选择具体词汇、语块、课文篇目等内容。
3. 选择使用方式（如口语跟读、看英选中、单词默写、看中选英、单词听写、听音识词等）。
4. 未选择内容时，布置按钮不可用（不可点击或点击后提示先选择内容）。
5. 切换使用方式时，不清空已选内容，除非该方式不支持当前已选内容。
6. 点击「布置」后进入布置确认流程。

### 17.6 精准跳转卡交互

1. 命中错题本、备课、词汇洞察等管理意图时，优先展示精准跳转卡（不进入常规搜索结果页）。
2. 精准跳转卡在搜索处理前判断，优先级最高。
3. 点击跳转按钮后进入目标页面。
4. 目标页面不可用时展示「暂不可用」提示，不展示跳转按钮或标注不可用，不跳转到错误页面。
5. 老师可从精准跳转卡返回继续搜索。

### 17.7 兜底推荐交互

1. 无结果或无法识别时展示兜底推荐。
2. 兜底推荐展示搜索建议标签（答题卡、词表、词汇听写、单元练习、作文、配音、专项、听力、课文）。
3. 兜底推荐展示常用功能入口（答题卡、词表、词汇听写、单元练习、作文、配音）。
4. 点击推荐词可重新发起搜索。
5. 点击常用功能入口可进入对应功能页面。
6. 兜底推荐不应强行命中单一功能。

### 17.8 搜索历史交互

1. 成功搜索后记录搜索词（trim 后的文本）。
2. 空输入不记录。
3. 点击历史记录重新发起搜索。
4. 历史记录按最近搜索时间倒序展示。
5. 历史记录最多保留 20 条，超出时覆盖最早的记录。
6. 相同意图的搜索词视为重复，保留最近一条（如"Unit 3 词汇"和"第三单元单词"意图相同，只保留最近搜索的那条）。

### 17.9 布置确认交互

1. AI 搜索中点击「布置」后，不能直接发布，必须进入布置确认流程。
2. 布置确认流程可默认带入当前班级、当前单元、资源名称、发布时间等信息。
3. 默认值需要老师确认后才可发布。
4. 布置成功后展示成功反馈（如 toast 或成功页面）。
5. 布置失败时展示错误提示，允许重试。

### 17.10 首页搜索交互规则

1. 老师在首页「小天 AI 智能助手」输入框输入搜索词后，点击发送或按回车触发搜索；
2. 系统不打开任何抽屉、弹层或覆盖层，而是跳转到搜索全屏页 / 独立搜索结果页；
3. 搜索页 URL 携带搜索词和自动搜索标识（如 `?query=听写&autoRun=1`）；
4. 搜索页自动执行搜索，搜索框中保留搜索词；
5. 展示的完整搜索结果必须与在搜索页内手动输入同一搜索词得到的结果一致；
6. 搜索成功后更新历史记录；
7. 输入为空（trim 后）时不触发搜索，保持首页状态；
8. 搜索过程中搜索页展示 Loading 动画。

**禁止行为**：
1. 不允许首页搜索后只展示两个入口卡片；
2. 不允许首页搜索使用独立的简化搜索逻辑或简化结果模板；
3. 不允许首页搜索后仍在首页（不跳转）展示结果。

## 19. 测试关注点

1. 各意图的识别准确率（尤其是相近意图的区分，如"试卷答题卡"vs"答题卡"，"听力模拟"vs"听力"）
2. 上下文变化时搜索结果是否正确联动
3. 精准跳转卡是否正确触发并跳转
4. 兜底场景展示是否正常
5. AI Loading 文案是否与意图匹配
6. 搜索理解文案是否与搜索结果一致
7. 资源卡片的操作按钮是否按类型正确展示
8. 布置流程各步骤是否完整
9. 空搜索/无上下文时的降级处理
10. 搜索词归一化：`答题咔`→答题卡、`达题卡`→答题卡、`听谢`→听写、`做文`→作文；`练习报表`/`报告`/`学情`→不触发报告搜索
11. 低置信表达（`卡`、`题`）是否正确走兜底
12. 英文单词（单个或多个）搜索是否优先按词汇处理，是否正确忽略标点和空格
13. 搜索全屏页/独立搜索页引导卡点击后搜索词和意图是否匹配
14. AI 搜索是否不直接生成多天词汇复习方案
15. 试卷名称搜索是否正确识别地区、年份、考试类型
16. 试卷搜索是否不受当前教学上下文限制
17. 无权限资源是否正确不展示
18. Unit + 资源类型组合搜索是否正确匹配指定单元
19. 搜索结果超过 50 条时是否正确展示提示
20. 无结果替代推荐是否按层级展示
21. 同步词汇各分区全选按钮文案是否统一为「全选」
22. 功能入口二级匹配是否按本文档规则执行
23. 输入"练习报告"时，不应触发练习报告精准跳转
24. 输入"学情"时，不应触发练习报告精准跳转
25. 输入"完成率/未完成"时，不应触发练习报告搜索
26. 报告相关输入应进入兜底或提示使用原有入口
27. 错题本/词汇洞察仍可正常触发精准跳转
28. 输入"未批阅"时，不作为精准跳转或搜索意图
29. 搜索历史最多保留 20 条，新增超过 20 条时覆盖最早记录
30. 搜索历史相同意图去重是否正确（如"Unit 3 词汇"和"第三单元单词"只保留最近一条）
31. 课本名称搜索是否正确识别教材版本、年级、单元
32. 课本搜索的精确匹配、相近匹配、相关推荐是否按规则判定
33. 课本卡片是否正确展示「布置」和「进入」两个按钮
34. 点击「进入」是否正确跳转到平台现有课本教学页面
35. 搜索英文单词组合（如"apple banana"）是否正确按词汇查询处理
36. 搜索单词时是否正确忽略标点和空格（如"look, say, write"）
37. 课本搜索是否不按班级过滤
38. 作文搜索是否展示写作专项试卷（当前学段有写作专项时）
39. 听说专项搜索是否正确返回听说专项资源
40. 导入试卷搜索是否正确展示我的试卷前 10 条和更多入口
41. 同步词汇是否不区分课标词/非课标词，统一展示词汇列表，并展示固定搭配分组
42. 同步布置流程是否不再生成草稿，点击练习形式后直接打开平台已有布置弹窗
43. 输入命中卷库标签时，是否返回标签下资源
44. 标签精确命中时，是否进入智能匹配区；弱命中时是否进入推荐关联区
45. 标签下无资源时，是否进入替代推荐或兜底
46. 多标签命中时，是否按意图优先级和资源相关性排序
47. 输入"扫描批改""拍照批改""纸质"是否识别为答题卡相关
48. 输入"卡"时是否作为候选推荐而不是强行精准命中
49. 输入"听说专项""写作专项"是否识别为专项资源
50. 输入"听默写/听/默写"是否识别为听写/默写
51. 输入"导入词表"是否识别为词表相关，且导入词表入口优先
52. 听写/默写入口是否不再写成"入库"
53. 应用文是否展示自定义应用文入口和应用文专项试卷
54. 读后续写是否展示自定义读后续写入口和读后续写专项试卷
55. 不再将写作相关内容简单命名为"批改入口"
56. 搜索"听说"且老师有听说资源时，是否优先展示听说资源
57. 搜索"听说"但无听说资源时，是否展示听力资源替代
58. 搜索"听说专项"但无听说专项资源时，是否展示听力专项或听力练习替代
59. 搜索"听力"但无听力资源、存在听说资源时，是否展示听说资源替代
60. 文档中是否不再使用"听说考试地区/非听说考试地区"作为判断规则
61. 首页输入"听写"后，结果是否与搜索全屏页输入"听写"一致
62. 首页输入"作文"后，结果是否与搜索全屏页输入"作文"一致
63. 首页输入"试卷"后，结果是否与搜索全屏页输入"试卷"一致
64. 首页搜索后是否跳转到完整搜索结果页
