## 2. 背景与目标

### 2.1 背景

中学英语老师需要了解班级词汇薄弱点的全貌：哪些词错得多、学生薄弱在哪些能力维度、主要错因是什么。在此基础上，老师需要两类解决方案：

1. **基于错词数据**：针对班级近期的高频错词，自动生成词汇巩固练习
2. **基于教学阶段**：面向期中、期末、高三一轮等复习场景，按教材/课标词生成复习方案

两类方案生成后，老师还需要查看方案执行效果和数据分析报告。

### 2.2 产品路线

产品分为两条独立路线：

**路线一：词汇洞察 → 词汇提升方案**
- 从首页「词汇能力洞察」入口进入词汇能力洞察页
- 查看班级近期词汇薄弱情况（错词、能力维度、学生洞察）
- 基于当前时间范围高频错词一键生成词汇提升方案
- 不需要老师选择年级、教材、周期

**路线二：阶段词汇复习方案**
- 从首页「阶段词汇能力提升方案」入口进入弹窗
- 基于教材/课标词和复习范围生成方案
- 需要老师确认年级、选择复习方式和周期
- 不基于错词数据

两条路线共享相同的：方案报告、干预记录和 AI Loading 机制。

### 2.3 目标

1. 老师能在 3 分钟内了解班级词汇薄弱全貌
2. 老师能一键生成错词巩固方案，不需额外配置
3. 老师能按教学阶段灵活生成复习方案
4. 方案生成后能查看完整的执行效果报告

## 7. 词汇能力维度

### 7.1 四个固定维度

1. **词汇识记**：对词汇音、形、义的基本识别与记忆
2. **语境理解**：在语篇、对话等语境中理解词汇含义
3. **词汇运用表达**：在写作、翻译等输出场景中正确运用词汇
4. **词汇学习策略**：学生自主规划、监控和调整词汇学习的能力

四个维度固定不变，不可增减。

### 7.2 计算规则

**DP 能力映射规则**：
- 词汇识记、语境理解、词汇运用表达三个能力维度基于 DP 老师确认的「题型 + 错因 + 学段 → 对应词汇能力」映射表计算
- 已覆盖的题型/错因/学段组合按 DP 确认表执行，不得由前端自行修改
- 未覆盖的题型/错因/学段组合不参与能力得分计算，不得由前端自行归类
- 后续新增题型由产品/教研确认后，再给技术补充映射，前端不得自行补归属
- 题型名称与平台题型库一致，同一题型在不同学段/错因下不存在不同能力归属
- DP 表中同名题型以题型 ID 为准区分规则维护

**得分与展示规则**：
- 词汇学习策略维度保留在雷达图中，但具体计算规则待教研老师确定
- 计算规则未确定前，不由前端自行计算
- 一个题型/错因组合可以对应一个或多个能力维度
- 一个题型/错因组合对应多个能力时，该题型的作答数据同时计入多个能力维度的分子和分母
- 得分公式：该维度下有效作答小题实际得分之和 ÷ 该维度下有效作答小题满分之和，最终转换为 0～100 分
- 缺数据维度不按 0 分处理
- 前台不展示"待完善"标签

**映射表影响范围**：
- 词汇能力雷达图
- 主要薄弱能力判断
- 方案报告能力对比
- 词汇掌握口径
- 词汇能力相关数据口径

DP 确认版完整映射表见 `docs/spec/AI词汇洞察_SPEC.md` §7.2。

### 7.3 展示规则

- 使用雷达图可视化四个维度的得分
- 数据点标注具体得分
- 多边形填充展示能力分布形态
- 前台不展示"待完善"标签

## 8. 高频错词规则

### 8.1 数据范围

高频错词统计范围跟随时间筛选变化。

### 8.2 去重规则

高频错词去重使用平台错词库/词汇中心现有去重规则，前端不自行去重。正式开发时由后端返回已聚合好的高频错词列表，前端仅展示和排序。

**平台能力依赖**：高频错词去重由平台错词库/词汇中心提供，前端不自行创造大小写归一、模糊合并、别名合并等新规则。

### 8.3 列表性质

高频错词列表展示的是按词汇聚合后的结果，不是原始错误记录。老师看到的是"每个词的综合表现"，不是"每一条错误"。

### 8.4 聚合后统计

同一个词的多条错误记录聚合后：
- 错误次数：累加
- 涉及学生数：按学生去重统计
- 错误率：使用平台已有错词错误率规则或平台返回值
- 错因：展示全部错因
- 错因排序：按照错误次数从多到少排列，错误次数多的错因展示在前
- 多个错音：全部展示，不只展示一个

### 8.5 错误率

- 只展示错误率，不计算、不展示得分率
- 错误率按照平台现有错词错误率计算规则或平台已返回值为准
- 前端不自行用 `100% − 得分率` 计算错误率
- 如果平台没有返回错误率，不展示错误率

### 8.6 排序规则

高频错词先按词聚合，再排序：
1. 错误率从高到低
2. 涉及学生数从多到少
3. 错误次数从多到少
4. 有效作答次数从多到少

### 8.7 展示数量

- 词汇洞察数据池：取 Top 50 高频错词
- 列表默认展示：Top 12（可滚动查看更多）
- 生成词汇提升方案：基于当前范围 Top 50
- 方案报告高频薄弱内容：展示 Top 50
- 不足对应数量时按实际数量展示，不硬凑重复词

### 8.8 错因筛选

列表顶部提供四个错因筛选标签：不会写、读不准、生词、不会用。老师可筛选特定错因类型的错词。

筛选口径：
- 只要某个词的错误记录中存在对应错因，该词就可以被筛选出来
- 筛选后列表排序仍沿用高频错词排序规则
- 如果筛选后无数据，展示空态
- 示例：某词存在"不会写"和"读不准"记录；当老师筛选"读不准"时，该词仍应出现在筛选结果中

### 8.9 错词严重程度分级

| 错误率范围 | 严重程度标签 |
|-----------|------------|
| 错误率 ≥ 70% | 极高 |
| 50% ≤ 错误率 < 70% | 高 |
| 30% ≤ 错误率 < 50% | 中 |
| 错误率 < 30% | 低 / 不突出展示 |

规则：
1. 错误率使用平台现有错词错误率规则或平台返回值
2. 严重程度只作为展示标签，不参与排序
3. 排序仍按错误率、涉及学生数、错误次数等规则
4. 若平台没有返回错误率，不展示严重程度标签

## 9. 高频错词详情

### 9.1 展示内容

右侧详情区展示：
1. 词汇信息：词文本 + 全部归因标签 + 错误率 + 受影响人数 + 错误次数 + 练习来源
2. 常见错误写法表格：每个错误写法、涉及学生数、出现次数
3. 学生作答示例：学生姓名、来源任务和日期、错误答案→正确答案、「查看原题」按钮

### 9.2 错音与错误写法区分

- 常见错误写法用于展示书写/拼写类错误
- 错音用于展示读音类错误
- 一个词存在多个错音时，应全部展示，不合并为一个
- 错音展示不替代常见错误写法
- 多个错音全部展示
- 错音不进入常见错误写法表

明确区分以下概念：
- 错因：不会写、读不准、生词、不会用等归因类型
- 错音：读音类错误的具体错误读音
- 常见错误写法：书写/拼写类错误作答

### 9.3 常见错误写法规则

1. 只统计书写/拼写类错误
2. 从学生作答中提取错误写法
3. 相同错误写法需要去重聚合
4. 展示错误写法、涉及学生数、出现次数
5. 错音不进入常见错误写法表

### 9.4 不展示内容

- 不展示"主因分析"长文案
- 错词详情只展示错因标签，不展示大段 AI 生成的归因分析文字
- 不使用"主归因 / 主错因 / 主要错因"这类字眼

### 9.5 右侧学生列表展示规则

右侧详情区学生列表展示数量不写固定条数：
1. 学生展示数量基于整个错词详情区域的可展示高度决定
2. 能展示全则展示全部学生
3. 展示不全时出现「查看更多」
4. 点击「查看更多」后展示完整学生列表或展开更多
5. 不写死固定 Top N

### 9.6 默认状态

页面首次加载或时间范围切换后，自动选中列表中第一个词展示详情。列表为空时展示「选择一个高频错词查看详情」。

### 9.7 查看原题

查看原题弹窗需展示以下内容：
1. 当前词汇
2. 作答日期
3. 错因标签
4. 练习名称
5. 题型名称
6. 错误次数（或受影响学生数）
7. 原题内容
8. 学生作答（需与正确答案有明确区分）
9. 正确答案（需与学生作答有明确区分）
10. 解析（如平台已有则展示）

规则：
- 点击后在当前页面弹窗展示，不跳转新页面
- 优先复用平台已有题目查看能力
- 无关联原题数据时不展示「查看原题」按钮

## 10. 学生洞察

### 10.1 词汇洞察页薄弱学生

**判定规则**：薄弱学生满足任一条件即可进入待提升学生列表：
1. 词汇错误率高于班级平均
2. 高频错词涉及数量较多

**不需要单独绝对阈值**，按以上条件判定即可。

**排序**：
1. 错误率高的优先
2. 高频错词涉及数量多的优先
3. 错误次数多的优先

**展示**：
- 左侧：待提升学生
- 右侧：好榜样学生（按错误率低、完成情况较好、涉及高频错词少等口径展示；具体判断阈值待确认）
- 概览：姓名、错误率、主要问题、涉及高频错词数量
- 展开：主要错词、错因、错音和错误明细

### 10.2 方案报告页待关注学生

**判定规则**（满足任一即进入）：
1. 未完成任一已发布词汇闯关
2. 整体正确率低于所在班级平均正确率

**排序**：
1. 未完成且正确率低的学生优先
2. 正确率越低越靠前
3. 未完成次数越多越靠前

**展示**：姓名、正确率、完成进度、状态标签和关注原因

### 10.3 版本范围

当前版本学生洞察只做问题查看。单学生的个性化练习布置属于后续能力，不在本期范围。

## 11. 词汇洞察生成词汇提升方案

### 11.1 入口

词汇能力洞察页顶部「生成词汇提升方案」按钮。

### 11.2 生成规则

- 基于当前时间范围的高频错词和薄弱学生数据一键生成
- **不展示**年级/教材/周期选择
- **不展示**版本（趣味版/基础版/进阶版/培优版）
- 以 50 词、50 题为基本单位，按高频错词数量计算练习份数：
  - 高频错词数 ≤ 50：生成 1 份练习，每份 50 题
  - 50 < 高频错词数 ≤ 100：生成 2 份练习，每份 50 题，词尽量平均分布
  - 高频错词数 > 100：每增加 50 个词增加 1 份练习，每份 50 题，词尽量平均分布
- 推题规则与一键组卷规则一致
- 词不足时允许重复考查，但题型要有差异
- 词多时随机选词满足要求
- 完整工程规则见 `docs/spec/AI词汇洞察_SPEC.md` §13

demo 兼容说明：demo 当前可暂按 2 份模拟，正式规则以 50 词/50 题为基本单位计算。

### 11.3 方案开始时间与发布规则

生成方案后，上方增加一个「方案开始时间」。

规则：
1. 方案开始时间默认是当前时间
2. 第一份练习发布时间 = 方案开始时间
3. 第二份练习发布时间 = 次日 08:00
4. 第三份练习发布时间 = 第三天 08:00
5. 第 N 份练习按照一天一份推算发布时间
6. 老师修改方案开始时间后，所有练习发布时间自动重新计算
7. 多份练习截止时间统一为方案开始后一周 23:59

### 11.4 后台生成规则（不展示给老师）

- 每份练习 50 题
- 词不足时重复考查（题型要有差异）
- 词多时随机选词
- 版本策略不前台展示，但后台按版本规则生成

### 11.5 重新生成规则

老师点击「重新生成」时，可以调整：
1. 不需要的题型
2. 作业次数
3. 每份题量

调整后：
- 词不足时重复考查，题型要有差异
- 词多时重新随机选词满足要求
- 未调整时按默认 50 词/50 题规则生成
- 重新生成也需要 AI Loading

**重新生成选词规则**：
- 重新生成时，根据 DP 老师给出的不同版本题型题量进行更换版本抽题
- 不是简单随机换词，而是按 DP 确认的不同版本题型题量规则切换或重抽
- 根据当前可用词与题型题量重新组题
- 词不足时允许重复考查，但题型要有差异
- 前台不展示复杂抽样规则

### 11.6 无数据/数据少

- 无数据（高频错词数 = 0 或有效作答 = 0）：不允许生成，引导切换时间范围
- 数据少（高频错词数 1～9 个）：允许生成，但提示数据较少
- 正常（高频错词数 ≥ 10 个）：正常生成

### 11.7 确认布置

点击「确认布置」后方案发布，形成方案记录，可在练习报告中查看方案报告。

## 12. 阶段词汇复习方案

### 12.1 入口与定位

首页右侧「阶段词汇能力提升方案」卡片，点击「阶段词汇能力提升方案」打开弹窗。

**与词汇洞察生成方案的区别**：
- 词汇洞察方案：基于错词数据，不需老师选择范围
- 阶段复习方案：基于教材/课标词，需要老师确认年级和范围

### 12.2 整体流程

1. 系统识别当前教学阶段，展示识别结果
2. 老师确认或手动修改年级
3. 老师选择复习方式（课标词 / 教材）
4. 按教材时，选择册次和单元（悬浮层选择）
5. 老师选择复习周期（1周/2周/3周/4周）
6. 老师选择练习时间（周一至周五 / 周六日）
7. 点击「开始生成」
8. 进入 AI Loading（必须走 Loading，不允许直接展示结果）
9. Loading 后展示生成结果

**生成流程**：当前按同步生成流程处理。点击生成后展示 AI Loading，Loading 结束后直接展示生成结果，不做后台异步任务状态轮询类流程。生成失败或超时提示重试。

### 12.3 识别与年级规则

系统优先使用老师最近一次手动确认的年级；无手动确认记录时，根据老师当前或最近使用的教材章节识别年级。

**初中年级识别**：根据教材章节第二级册次判断 — 七年级上册/下册 → 初一；八年级上册/下册 → 初二；九年级上册/下册/全一册/九全 → 初三。

**高中年级识别**：根据教材册次判断 — 必修册次 → 高一；选择性必修册次 → 高二（默认识别）；选修册次 → 高三。如果老师当前或最近选择到「选择性必修二」的最后一个单元（以平台教材章节树为判断依据），则认为已进入高三复习阶段，识别为高三。如果老师当前或最近选择到选择性必修三的最后一个册/最后一个单元（以平台教材章节树为判断依据），也识别为高三。

**记忆规则**：
- 老师手动修改年级后，系统按教师维度保存本次确认的年级
- 下次生成阶段词汇复习方案时，优先沿用该教师上次确认过的年级，减少重复误判
- 老师切换班级后，沿用上次确认年级
- 老师切换教材体系后，沿用上次确认年级
- 老师切换学段后，不清空年级记录；若切换学段导致年级与当前学段不一致，前台可提示老师确认，但不自动清空历史记录

- 年级根据老师账号学段展示：初中（初一/初二/初三），高中（高一/高二/高三）
- 识别结果不准确时老师可手动修改
- 修改年级后以下推荐值联动刷新：默认复习方式、默认册次、默认单元、默认难度、版本策略和复习范围摘要
- 正式产品不允许老师自由切换学段

完整规则见 `docs/spec/AI词汇洞察_SPEC.md` §15.2。

### 12.4 复习方式

- 初三默认选择「课标词复习」
- 高三默认选择「课标词复习」
- 其他年级默认选择「教材复习」
- **初三/高三允许切换为教材复习**：切换后展示册次和单元选择，复习范围按老师选择执行
- **按课标词复习**：不展示教材版本和册次选择
- **按教材复习**：系统根据当前日期、学段和年级推算默认册次和单元。初中按 2 周 1 个单元推算，高中按 3–4 周 1 个单元推算。通过浮层选择册次和单元
- 老师可手动调整系统推荐的册次和单元
- 开学时间统一按固定教学时间规则计算（9 月 1 日和农历正月十六），不按不同地区单独调整。若老师实际进度不同，可手动修改复习范围

完整默认单元推算规则见 `docs/spec/AI词汇洞察_SPEC.md` §16D。

### 12.5 册次与单元

- 高中教材册次：必修一/二/三、选必一/二/三（不使用高一上册等表述）
- 单元支持多选，默认按册次整册生成
- 不展示教材版本选择器

### 12.6 复习周期与练习时间

**基本规则**：
- 复习周期：1周/2周/3周/4周
- 练习份数：1周→2份，2周→4份，3周→6份，4周→8份，每份 50 题
- 每天最多一份，一周最多两份
- 练习时间：周一至周五 / 周六日
- 方案开始时间默认值由操作日期和练习时间选择共同决定（详见 SPEC §16F）

**默认周期与话术策略规则**：

默认周期根据老师当前识别年级和当前日期推算。老师可手动修改周期，修改后练习份数联动更新。默认周期只用于弹窗初始推荐，不限制老师修改。

如果时间段命中多个规则，优先使用更具体的年级/教学阶段规则。如果无法命中规则，默认 2 周，可由老师手动修改。

#### 初一/高一、初二/高二通用规则

### 12.7 生成结果页

- 上方展示方案摘要（自然语言描述）
- 方案开始练习时间放在结果页，默认值见上
- 修改开始时间后各练习发布时间自动重新计算
- 下方展示练习列表，每份练习卡片展示题量
- 题量字段可作为可交互信息展示：老师 hover / 悬停题量字段时，可以查看题型和题量组成
- 回滚题占比可在题量 hover 明细中展示"含回滚题"
- 第一份练习支持预览试题
- 重新生成不改变老师已选择的设置，重新生成也需要 AI Loading
- 确认布置后形成方案记录

### 12.8 排期规则

- 每天最多一份练习
- 一周最多两份练习
- 周一至周五选择的工作日排期；周六日选择的周末日排期
- 开始时间不在所选练习日时自动顺延

### 12.9 版本策略

#### 周一至周五

如果老师选择练习时间为周一至周五，只推送：
1. 基础版
2. 进阶版
3. 培优版

其中基础版去掉：
- 词汇跟读
- 词汇听写

基础版题量用以下题型补充：
- 中英检测 +10 题
- 词形变化 +10 题

#### 周六日

如果老师选择练习时间为周六日，推送：
1. 趣味版
2. 基础版
3. 进阶版
4. 培优版

#### 版本生成与重新生成

1. 推送版本根据老师选择的练习时间决定
2. 老师选择周一至周五时，不生成趣味版
3. 老师选择周六日时，可以生成趣味版
4. 点击「重新生成」时，在当前可用版本集合中切换到另一个版本
5. 多次重新生成时，在可用版本集合中循环生成不同版本
6. 不在前台展示"版本策略"复杂后台规则，只体现生成结果变化

#### 回滚题规则

从第 2 份练习开始，题量内容中包含 10% 回滚题。

规则：
1. 第 1 份练习不含回滚题
2. 第 2 份及以后，每份练习约 10% 为回滚题
3. 回滚题来自前序练习中需要巩固的词
4. 回滚题用于复查掌握变化
5. 回滚题占比属于后台生成规则，前台可在题量 hover 明细中展示"含回滚题"

### 12.10 年级与难度

- 高三 1–6 月只推送培优版方案
- 难度等级仅用于后台计算，不在前台展示
- 前台不展示"高考难度/高于高考难度"等文案
- 前台只展示老师可理解的复习范围、题量、周期和练习安排
- 年级与难度对应规则详见 SPEC §16B

## 13. 方案报告

### 13.1 入口

- 首页练习报告列表的「方案报告」按钮
- 干预记录的「报告」按钮
- 直接通过地址访问

### 13.2 报告结构

1. **报告头部**：方案名称 + 班级 + 状态 + 进度 + 更新时间 + 下载 PDF
2. **核心指标**：整体完成率 / 整体正确率 / 正确率变化 / 主要薄弱能力 / 待关注学生
3. **词汇能力表现**：雷达图展示方案前 vs 方案后/当前
4. **回滚词掌握变化**：回滚词数量、错误率变化、掌握改善/未改善词数
5. **练习表现趋势**：按词汇闯关顺序展示完成率和正确率变化
6. **待关注学生**：列表含原因说明
7. **高频薄弱内容**：高频错词 Top 50 + 薄弱题型
8. **下载 PDF**

### 13.3 方案报告头部规则

词汇提升方案报告和阶段词汇复习方案报告头部展示不同。

**词汇提升方案报告**展示：方案名称、班级、状态、完成进度、数据更新时间、下载 PDF。
不展示：复习范围、生成来源、方案版本。

**阶段词汇复习方案报告**展示：方案名称、班级、复习范围、状态、完成进度、数据更新时间、下载 PDF。
不展示：生成来源、方案版本。

### 13.4 方案报告状态联动

1. 方案已完成：展示方案前 vs 方案后
2. 方案进行中：展示方案前 vs 当前
3. 无历史基线：展示首次闯关 vs 当前/方案后
4. 待发布练习不参与完成率、正确率、趋势计算
5. 有已发布且有有效作答数据的词汇闯关时，趋势可以展示
6. 完全无有效作答数据时展示空态

### 13.5 词汇能力表现（雷达图动态对比）

1. 词汇能力表现使用雷达图展示，沿用词汇洞察页的能力维度
2. 不使用横向条形图作为主展示方式
3. 雷达图同一图中展示方案前 vs 方案后 / 当前，支持双多边形对比
4. 方案前：较弱视觉层级（虚线边框、浅灰色调）
5. 方案后：较强视觉层级（实线边框、品牌蓝色调）
6. 雷达图需要能体现各能力边的变化，页面加载后方案后多边形从方案前状态过渡展开（约 800ms）
7. 每个能力维度展示方案前得分、方案后得分和提升值（delta）
8. 方案进行中展示方案前 vs 当前
9. 方案完成后展示方案前 vs 方案后
10. 缺数据维度不按 0 分处理

### 13.6 回滚词掌握变化

方案报告中展示「回滚词掌握变化」。

展示内容：
1. 回滚词数量
2. 回滚词当前错误率
3. 回滚词较前次练习的错误率变化
4. 掌握改善词数
5. 掌握未改善词数
6. 样本不足提示

计算规则：
1. 回滚词指第 2 份及以后练习中重复考查的前序词
2. 单个回滚词掌握变化 = 前序练习该词错误率 − 当前回滚练习该词错误率
3. 变化值 > 0 表示错误率下降、掌握改善
4. 变化值 = 0 表示持平
5. 变化值 < 0 表示错误率上升、掌握变差
6. 只统计有前序基线和当前有效作答的回滚词
7. 有效回滚词数量少于 3 个时，不展示整体变化值，只展示样本不足
8. 有效回滚词数量达到 3 个及以上时，展示整体回滚词错误率变化
9. 整体回滚词错误率变化 = 前序基线回滚词平均错误率 − 当前回滚词平均错误率
10. 缺数据时展示空态，不按 0 计算

### 13.7 PDF 导出范围

PDF 导出完整报告内容，包括：
1. 核心指标

### 16.7 词汇掌握口径

「词汇掌握」不能作为泛化文案使用，必须对应以下明确口径之一：

| 口径名称 | 定义 | 计算公式 | 缺数据处理 |
|---------|------|---------|----------|
| 单个词掌握情况 | 用该词的错误率表示 | 错误率使用平台已有错词错误率规则或平台返回值 | 无有效作答时不展示或展示「-」 |
| 班级词汇能力掌握 | 用四个词汇能力维度得分表示 | 各维度得分 = 该维度有效作答小题实际得分之和 ÷ 该维度有效作答小题满分之和 × 100（基于 DP 确认版映射表）；如只有对/错结果可等价为正确小题数÷有效作答小题总数×100 | 缺数据维度不按 0 分处理，展示空态 |
| 学生词汇掌握 | 用学生在当前范围内词汇相关错误率表示 | 学生错误率使用平台已有错词错误率规则或平台返回值 | 无有效作答时不展示或展示「-」 |
| 方案报告整体掌握 | 用整体正确率、正确率变化、主要薄弱能力表示 | 参见方案报告口径 | 无有效作答时展示空态 |

使用约束：
1. 如果页面使用「掌握率」「词汇掌握情况」「掌握水平」等文案，必须对应上述口径之一
2. 缺数据时不按 0 分处理，展示「暂无数据」或不参与判断
3. 同一页面内多处出现同一文案时，口径必须一致

## 17. 前端交互规则

本章定义词汇洞察页、词汇提升方案、阶段词汇复习方案、方案报告的前端交互行为、状态流转、按钮启禁用、弹窗行为和失败反馈规则。
不包含 UI 样式、颜色、尺寸、间距、像素等视觉规范。

### 17.1 首页入口交互

1. 点击「词汇能力洞察」卡片 → 进入词汇能力洞察页（页面跳转）。
2. 点击「阶段词汇能力提升方案」卡片 → 打开阶段方案弹窗（不跳转页面），打开弹窗时需要展示 AI Loading。
3. 两个入口互不影响，各自独立。
4. 词汇能力洞察卡片无数据时只展示简短说明，不展示数字摘要。
5. 阶段方案卡片始终正常展示。

**AI Loading 规则**：
- 点击「词汇能力洞察 / 词汇提升方案」相关按钮打开弹窗时，需要展示 AI Loading
- 点击「阶段词汇能力提升方案」按钮打开弹窗时，也需要展示 AI Loading
- 不能点击按钮后直接展示结果
- Loading 后再展示对应弹窗内容或生成结果
- 重新生成也必须走 AI Loading
- 如果只是进入词汇能力洞察页面查看已加载数据，是否需要 Loading 按当前页面加载规则处理

### 17.2 时间筛选交互

1. 切换时间范围（近 7 天 / 14 天 / 30 天 / 当前单元）后，页面数据联动更新。
2. 联动更新范围：顶部总结+指标、雷达图、高频错词列表、高频错词详情（自动选中第一个词）、学生洞察、生成词汇提升方案的数据来源。
3. 切换后如果当前范围无数据，展示空态。
4. 干预记录默认不跟随右上角时间筛选变化。

### 17.3 高频错词列表交互

1. 点击某个错词后，右侧详情更新为该词的详情。
2. 切换错因筛选标签后，列表按筛选结果更新。
3. 筛选无结果时展示空态。
4. 切换时间范围后，自动重置为列表第一个词的详情。
5. 多个错音全部展示，不合并。

### 17.4 查看原题交互

1. 点击「查看原题」后，在当前页面打开原题弹窗。
2. 无关联原题记录时不展示「查看原题」入口。
3. 弹窗可关闭。
4. 原题加载失败时提示失败，允许重试或关闭弹窗。

### 17.5 学生洞察交互

1. 默认展示学生概览（姓名、错误率、主要问题、涉及高频错词数）。
2. 点击某个学生后展开学生明细（主要错词、错因、错音和错误明细）。
3. 本期不提供单学生个性化布置按钮。

### 17.6 生成词汇提升方案交互

1. 点击「生成词汇提升方案」按钮打开生成弹窗。
2. 弹窗内不展示年级/教材/周期/题量/题型/版本选择。
3. 无数据时（高频错词数 = 0 或有效作答 = 0），按钮不可用或点击后提示不可生成，引导切换时间范围。
4. 数据少时允许生成，但展示数据较少提示。
5. 打开弹窗后展示 AI Loading（三步文案），不允许跳过 Loading 直接展示结果。
6. Loading 后展示 N 份词汇闯关（按词数计算份数，每份 50 题）。
7. 点击「重新生成」，允许老师调整：不需要的题型、作业次数、每份题量。调整后再次进入 AI Loading。
8. 老师未调整时点击「重新生成」，按默认 50 词/50 题规则重新生成，也需 AI Loading。
9. 点击「确认布置」后发布方案。
10. 发布成功后展示成功反馈，形成方案记录，提供方案报告入口。
11. 生成失败或发布失败时提示错误，允许重试。生成超时按失败处理，展示超时提示并允许重试。

### 17.7 阶段词汇复习方案设置交互

1. 打开弹窗后先展示设置页（不是直接展示方案结果）。
2. 系统展示识别到的年级，老师可手动调整。
3. 修改年级后，复习方式、册次、单元、周期、练习时间等推荐值全部刷新。
4. 初三/高三默认选择「课标词复习」；其他年级默认选择「教材复习」。
5. 选择「按课标词」时，不展示册次和单元选择。
6. 选择「按教材」时，系统根据当前日期和年级推算默认册次和单元，允许通过浮层选择册次和单元。
7. 单元支持多选，未选择单元时按整册生成。
8. 选择复习周期（1 周 / 2 周 / 3 周 / 4 周）和练习时间（周一至周五 / 周六日）。
9. 设置页不展示方案开始练习时间（开始时间仅在结果页展示）。
10. 点击「开始生成」进入 AI Loading（必须 Loading，不允许跳过直接展示结果）。

### 17.8 阶段方案结果交互

1. AI Loading 后进入结果页。不允许跳过 Loading 直接展示结果页。
2. 结果页展示方案摘要、开始时间和练习列表。
3. 方案开始时间默认值由老师操作日期和练习时间选择决定（详见 SPEC §16F），老师可手动修改。
4. 修改开始时间后各练习发布时间自动重新计算。
5. 老师可查看每份练习的题型组成和题量（demo 当前通过题量区域悬浮提示查看）。
6. 第一份练习支持「预览试题」。
7. 点击「重新生成」，不改变老师已选择的设置，需 AI Loading，仅重新执行方案生成。
8. 点击「确认布置」后发布方案。
9. 发布成功后展示成功反馈和方案报告入口。
10. 生成失败、预览失败、发布失败时提示错误并允许重试。生成超时按失败处理，展示超时提示并允许重试。

### 17.9 方案报告交互

1. 从干预记录或练习报告列表点击「方案报告」进入方案报告页（页面跳转）。
2. 方案不存在时展示错误提示，不跳转错误页面。
3. 报告页加载失败时允许重试。
4. 点击「下载 PDF」导出完整报告。
5. PDF 导出失败时提示失败并允许重试。

## 18. 后台规则不展示清单

以下规则属于后台逻辑，不展示给老师：
- 回滚规则和补题逻辑
- 固定生成题 vs 回滚题的区分
- 版本策略（趣味版/基础版/进阶版/培优版）— 版本名称不一定前台展示，但后台生成规则需按 DP 确认的版本/题型/题量表执行
- 一个词对应多道题的内部处理（重复考查时题型要有差异）
- 教材版本的自动匹配逻辑
- 年级与难度对应规则
- 高三 1–6 月仅推送培优版的规则
- 默认单元推算逻辑
- 难度等级（仅后台计算，不在前台展示"高考难度/高于高考难度"等文案）
- 重新生成时按 DP 版本题型题量规则更换版本抽题的复杂抽样规则

13. **词汇洞察统计范围**：以平台错词本现有规则为准，前端不自行扩展统计范围
14. **同一学生同一题多次作答统计**：使用平台已有统计逻辑，前端不自行选择口径
